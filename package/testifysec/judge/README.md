# JUDGE

JUDGE is a commercial platform from TestifySec for software supply chain security and compliance. It
manages gates, policies and signed evidence for software builds.

## Key capabilities

- **Gates and policies:** Requires build, test and security evidence before changes are accepted.
- **Signed evidence:** Collects signed attestations about software builds.
- **Control evidence:** Connects test results to compliance controls.
