# Midmark CareFlow RTLS

Midmark CareFlow RTLS is a real-time locating system (RTLS) for healthcare from Midmark. It tracks
the location of staff, patients and equipment.

## Key capabilities

- **Locating technologies:** Combines Bluetooth Low Energy with room-level infrared.
- **Patient flow:** Uses location data to support patient flow in clinics and hospitals.
- **Asset tracking:** Locates equipment in real time.
- **Staff duress:** Provides a wearable duress button with real-time alerts.
- **Analytics and interfaces:** Shares location data with analytics and other enterprise systems.
