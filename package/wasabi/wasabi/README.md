# Wasabi Hot Cloud Storage

Wasabi Hot Cloud Storage is a cloud object storage service from Wasabi Technologies. It offers an
S3-compatible API.

## Key capabilities

- **Object storage:** Stores data as objects in buckets.
- **S3 compatibility:** Works with tools and applications that use the Amazon S3 API.
- **Immutability:** Supports object lock to protect data from changes.
