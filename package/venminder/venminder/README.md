# Venminder

Venminder is a third-party risk management platform. It helps organizations manage vendors,
contracts and vendor risk assessments.

## Key capabilities

- **Vendor management:** Keeps vendor records and documents in one place.
- **Risk assessments:** Runs vendor risk assessments and questionnaires.
- **Contract management:** Tracks vendor contracts.
- **Monitoring:** Monitors vendors for risk changes.
