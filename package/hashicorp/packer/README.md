# Packer

Packer is a HashiCorp tool for building identical machine images for multiple platforms from a
single template.

## Key capabilities

- **Image templates:** Defines image builds in HCL templates.
- **Builders:** Builds images for cloud providers, virtualization platforms and containers.
- **Provisioners:** Configures images with shell scripts and configuration management tools.
- **Post-processors:** Processes build output, for example to upload or tag images.
