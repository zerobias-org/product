# Terraform

Terraform is a HashiCorp infrastructure as code tool for building, changing and versioning cloud and
on-premises resources.

## Key capabilities

- **Declarative configuration:** Describes infrastructure in HCL configuration files.
- **Providers:** Manages resources on many platforms through provider plugins.
- **Plan and apply:** Shows planned changes before applying them.
- **State:** Tracks managed infrastructure in a state file.
