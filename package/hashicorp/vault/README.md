# Vault

Vault is a HashiCorp tool for managing secrets and protecting sensitive data based on identity.

## Key capabilities

- **Secrets storage:** Stores and controls access to secrets such as passwords and API keys.
- **Dynamic secrets:** Generates short-lived credentials for databases and cloud platforms.
- **Encryption as a service:** Encrypts and decrypts data without storing it.
- **Auth methods and policies:** Authenticates clients and controls access with policies.
