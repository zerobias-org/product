# Checkr

Checkr is a background check platform from Checkr, Inc. for employers.

## Key capabilities

- **Background checks:** Runs criminal, motor vehicle and other checks.
- **Verifications:** Verifies employment and education.
- **Continuous monitoring:** Monitors for new records after hire.
- **API:** Provides an API for ordering checks and receiving results.
