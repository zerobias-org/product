# SecurityScorecard

SecurityScorecard is a security ratings platform from SecurityScorecard, Inc. It rates the external
cybersecurity posture of organizations, including vendors and suppliers.

## Key capabilities

- **Security ratings:** Gives organizations A–F ratings across groups of risk factors.
- **Third-party risk:** Monitors the security posture of vendors and suppliers.
- **Issue findings:** Lists the findings behind each rating.
