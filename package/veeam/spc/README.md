# Veeam Service Provider Console

Veeam Service Provider Console is a management console from Veeam for service providers. It
monitors and manages customers' Veeam-protected workloads.

## Key capabilities

- **Central management:** Manages many customers' Veeam environments from one console.
- **Monitoring:** Tracks backup health, security and recovery readiness.
- **Billing:** Meters consumption and bills each tenant.
- **Self-service:** Gives tenants role-based self-service backup and restore.
