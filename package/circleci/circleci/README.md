# CircleCI

CircleCI is a continuous integration and delivery (CI/CD) platform from Circle Internet Services,
Inc.

## Key capabilities

- **Pipelines:** Defines build, test and deploy pipelines in YAML configuration.
- **Execution environments:** Runs jobs in Docker, Linux, macOS, Windows and other environments.
- **Orbs:** Reuses packaged configuration.
- **Self-hosted runners:** Runs jobs on the customer's own infrastructure.
