# LastPass

LastPass is a password manager from LastPass. It stores and fills passwords for individuals and
businesses.

## Key capabilities

- **Password vault:** Stores passwords, notes and other items in an encrypted vault.
- **Autofill:** Fills credentials in browsers and apps.
- **Sharing:** Shares passwords with other users and teams.
- **Business admin:** Gives admins policies, reporting and SSO options.
