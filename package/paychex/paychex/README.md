# Paychex

Paychex is a payroll and HR platform from Paychex, Inc. It serves small and mid-sized businesses.

## Key capabilities

- **Payroll:** Runs payroll and handles payroll tax filing.
- **HR:** Manages employee records and HR tasks.
- **Benefits:** Administers employee benefits and insurance.
- **APIs:** Offers developer APIs for integrations.
