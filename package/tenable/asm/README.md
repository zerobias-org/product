# Tenable Attack Surface Management

Tenable Attack Surface Management (formerly Tenable.asm) is a product from Tenable that maps and
monitors an organization's internet-facing assets. It is part of the Tenable One platform.

## Key capabilities

- **External asset discovery:** Finds internet-facing domains, IPs and services.
- **Continuous monitoring:** Tracks changes to the external attack surface.
- **Risk context:** Adds context to help prioritize exposed assets.
