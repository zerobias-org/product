# Tenable Vulnerability Management

Tenable Vulnerability Management (formerly Tenable.io) is a cloud-based vulnerability management
product from Tenable. It is part of the Tenable One platform.

## Key capabilities

- **Asset discovery:** Discovers and tracks assets.
- **Vulnerability scanning:** Scans with Nessus scanners, agents and connectors.
- **Prioritization:** Ranks vulnerabilities by risk.
- **APIs:** Offers APIs for automation and integration.
