# Tenable Nessus

Tenable Nessus is a vulnerability assessment scanner from Tenable.

## Key capabilities

- **Vulnerability scanning:** Finds vulnerabilities in hosts, network devices and applications.
- **Configuration audits:** Checks systems against configuration and compliance policies.
- **Plugins:** Uses regularly updated plugins to detect issues.
- **Reporting:** Produces scan reports and exports.
