# Tenable Security Center

Tenable Security Center (formerly Tenable.sc) is an on-premises vulnerability management product
from Tenable.

## Key capabilities

- **Vulnerability management:** Collects and analyzes vulnerability data from Nessus scanners and
  agents.
- **Dashboards and reports:** Shows risk with dashboards and reports.
- **Policy compliance:** Checks systems against configuration policies.
