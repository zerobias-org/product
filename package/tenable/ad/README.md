# Tenable Identity Exposure

Tenable Identity Exposure (formerly Tenable.ad) is a product from Tenable that finds and helps fix
weaknesses in Active Directory and Microsoft Entra ID. It is part of the Tenable One platform.

## Key capabilities

- **Exposure detection:** Finds misconfigurations and weaknesses in identity systems.
- **Attack detection:** Detects attacks against Active Directory as they happen.
- **No agents:** Works without agents or privileged accounts on domain controllers.
