# Tenable OT Security

Tenable OT Security (formerly Tenable.ot) is a product from Tenable for operational technology (OT)
and industrial control system environments. Tenable now also markets it as Tenable One OT Exposure.

## Key capabilities

- **Asset inventory:** Discovers and tracks OT and IT assets.
- **Threat detection:** Detects threats and anomalies in industrial networks.
- **Vulnerability management:** Identifies vulnerabilities in OT devices.
