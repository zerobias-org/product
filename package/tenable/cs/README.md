# Tenable Cloud Security

Tenable Cloud Security is a cloud security product from Tenable. It combines cloud security posture
management and vulnerability management for cloud environments.

## Key capabilities

- **Posture management:** Finds misconfigurations in cloud accounts.
- **Identity and entitlements:** Analyzes cloud identities and permissions.
- **Workload scanning:** Finds vulnerabilities in cloud workloads.
