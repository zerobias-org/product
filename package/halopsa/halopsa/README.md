# HaloPSA

HaloPSA is professional services automation (PSA) software for managed service providers, made by
Halo Service Solutions.

## Key capabilities

- **Ticketing:** Runs a service desk with tickets and SLA management.
- **Contracts and billing:** Manages contracts and automates billing.
- **Workflow automation:** Automates service processes with workflows.
- **Integrations and API:** Connects to other tools through integrations and a REST API.
