# CoSAI MCP Security

CoSAI MCP Security is a paper from the Coalition for Secure AI (CoSAI), an OASIS Open Project. It
analyzes threats to the Model Context Protocol (MCP) and describes security controls for it.

## Key capabilities

- **Threat analysis:** Describes threats to MCP clients, servers and tool integrations.
- **Security controls:** Lists controls that address the identified threats.
- **Agentic AI focus:** Covers secure design for agentic AI systems that use MCP.
