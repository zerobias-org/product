# Red Canary

Red Canary is a managed detection and response (MDR) service from Red Canary. It monitors
endpoints, cloud, identity and other telemetry for threats.

## Key capabilities

- **Managed detection and response:** Detects and investigates threats around the clock.
- **Broad telemetry:** Works with data from endpoints, cloud workloads, identity and SaaS apps.
- **Response:** Helps contain threats and guides remediation.
