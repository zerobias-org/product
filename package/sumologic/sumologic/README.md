# Sumo Logic

Sumo Logic is a cloud-native log analytics and security platform from Sumo Logic, Inc.

## Key capabilities

- **Log management:** Collects, stores and searches logs and metrics.
- **Monitoring:** Builds dashboards and alerts for applications and infrastructure.
- **Security analytics:** Provides SIEM capabilities for threat detection.
