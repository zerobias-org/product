# CrowdStrike Falcon LogScale

CrowdStrike Falcon LogScale (formerly Humio) is a log management product from CrowdStrike, part of
its Next-Gen SIEM offering.

## Key capabilities

- **Log ingestion:** Ingests large volumes of log data with an index-free architecture.
- **Search:** Searches data with a query language that supports filtering, aggregation and regex.
- **Dashboards and alerts:** Provides live and historical dashboards and alerts.
- **Deployment:** Runs in the cloud or self-hosted.
