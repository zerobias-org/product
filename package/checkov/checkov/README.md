# Checkov

Checkov is an open source static analysis tool for infrastructure as code, maintained by Prisma
Cloud by Palo Alto Networks. It finds misconfigurations before they are deployed.

## Key capabilities

- **IaC scanning:** Scans Terraform, CloudFormation, Kubernetes, Helm and other formats.
- **Built-in policies:** Ships with policies for common security and compliance issues.
- **Custom policies:** Supports policies written in Python or YAML.
- **CI/CD integration:** Runs in CI/CD pipelines and outputs several report formats.
