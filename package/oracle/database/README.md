# Oracle Database

Oracle Database is a multi-model database management system from Oracle Corporation. It runs
on premises and in Oracle Cloud Infrastructure, including as Oracle Autonomous Database.

## Key capabilities

- **Multi-model data:** Stores relational, JSON, spatial, graph and other data types in one database.
- **SQL and PL/SQL:** Uses SQL for queries and PL/SQL for stored program logic.
- **High availability:** Offers clustering and replication features such as Real Application Clusters
  and Data Guard.
- **Security:** Provides encryption, auditing and access control features.
