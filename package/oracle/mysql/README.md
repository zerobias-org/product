# MySQL

MySQL is an open-source relational database management system owned by Oracle Corporation. It is
available as a free Community Edition and as commercial editions.

## Key capabilities

- **Relational database:** Stores data in tables and queries it with SQL.
- **Storage engines:** Uses InnoDB as the default transactional storage engine.
- **Replication:** Replicates data between servers for read scaling and availability.
- **Wide support:** Runs on major operating systems and is supported by many languages and tools.
