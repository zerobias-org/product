# 1Password Device Trust

1Password Device Trust (formerly Kolide) is a device trust product from 1Password. It checks whether
devices meet security requirements before they can authenticate to apps.

## Key capabilities

- **Device checks:** Checks Mac, Windows and Linux devices against security requirements.
- **Authentication gate:** Blocks app sign-in from devices that fail checks.
- **End-user remediation:** Tells users how to fix failing checks themselves.
- **Agent:** Collects device data with the Device Trust agent.
