# Zendesk Live Chat

Zendesk Live Chat is the live chat capability in Zendesk. It lets support agents chat with
customers on websites and apps.

## Key capabilities

- **Real-time chat:** Connects customers with agents in real time.
- **Agent workspace:** Handles chats alongside other support channels.
- **API:** Offers a Live Chat API.
