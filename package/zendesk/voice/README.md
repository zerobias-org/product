# Zendesk Voice

Zendesk Voice (Zendesk Talk) is the cloud call center capability in Zendesk.

## Key capabilities

- **Phone support:** Handles inbound and outbound calls in Zendesk.
- **Call tickets:** Creates tickets from calls.
- **API:** Offers the Talk API.
