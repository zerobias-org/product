# Zendesk Custom Data

Zendesk Custom Data is a set of Zendesk features and APIs for storing custom business data, such as
custom objects, in Zendesk.

## Key capabilities

- **Custom objects:** Defines custom object types and records.
- **Relationships:** Links custom records to tickets, users and other objects.
- **APIs:** Manages custom data through APIs.
