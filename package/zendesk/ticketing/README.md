# Zendesk Ticketing

Zendesk Ticketing is the ticketing system in Zendesk. It tracks customer support requests from
many channels.

## Key capabilities

- **Ticket management:** Creates, assigns and tracks support tickets.
- **Omnichannel:** Brings requests from email, chat, voice and other channels into tickets.
- **Automation:** Routes and updates tickets with triggers and automations.
- **API:** Offers a Ticketing API.
