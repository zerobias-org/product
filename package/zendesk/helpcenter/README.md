# Zendesk Help Center

Zendesk Help Center is the knowledge base and self-service portal in Zendesk.

## Key capabilities

- **Knowledge base:** Publishes help articles organized by category and section.
- **Self-service:** Lets customers find answers and submit requests.
- **Community:** Supports community forums.
- **API:** Offers a Help Center API.
