# Cisco Meraki

Cisco Meraki is a cloud-managed networking product line from Cisco, including wireless, switching,
security appliances and cameras managed through the Meraki Dashboard.

## Key capabilities

- **Cloud management:** Manages devices through the web-based Meraki Dashboard.
- **Wireless and switching:** Provides cloud-managed access points and switches.
- **Security appliances:** Provides firewall and SD-WAN appliances.
- **API:** Provides a Dashboard API for automation.
