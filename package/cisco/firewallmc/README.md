# Cisco Secure Firewall Management Center

Cisco Secure Firewall Management Center is a centralized management product from Cisco for Cisco
Secure Firewall devices.

## Key capabilities

- **Centralized management:** Manages firewall policies and devices from one console.
- **Event analysis:** Collects and analyzes security events.
- **Threat defense policies:** Manages intrusion, malware and access control policies.
- **API:** Provides a REST API.
