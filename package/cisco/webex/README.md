# Webex

Webex is a collaboration product line from Cisco for meetings, messaging, calling and webinars.

## Key capabilities

- **Meetings:** Hosts video meetings with screen sharing.
- **Messaging:** Provides team messaging spaces.
- **Calling:** Provides cloud calling.
- **Webinars:** Hosts webinars and events.
- **APIs:** Provides APIs and SDKs for integrations.
