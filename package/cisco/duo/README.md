# Cisco Duo

Cisco Duo is an identity security and multi-factor authentication (MFA) product from Cisco.

## Key capabilities

- **Multi-factor authentication:** Verifies users with push, passcodes, security keys and other
  methods.
- **Single sign-on:** Provides SSO to cloud and on-premises applications.
- **Device trust:** Checks device health before granting access.
- **Access policies:** Applies adaptive policies per application and user group.
