# Cisco Umbrella

Cisco Umbrella is a cloud security service from Cisco that protects users with DNS-layer security
and secure web gateway functions.

## Key capabilities

- **DNS-layer security:** Blocks requests to malicious domains.
- **Secure web gateway:** Inspects and filters web traffic.
- **Cloud-delivered firewall:** Applies firewall policies in the cloud.
- **Reporting:** Reports on network activity and blocked threats.
