# Jira

Jira is a project and issue tracking tool from Atlassian. This package covers Jira Cloud, part of
Atlassian Cloud.

## Key capabilities

- **Work items:** Tracks work as issues with custom fields and types.
- **Workflows:** Moves work through configurable workflows.
- **Boards:** Supports Scrum and Kanban boards.
- **Reporting:** Provides dashboards and reports on work progress.
