# Bitbucket Cloud

Bitbucket Cloud is a Git repository hosting and CI/CD service from Atlassian, part of Atlassian
Cloud.

## Key capabilities

- **Git repositories:** Hosts Git repositories with branch permissions.
- **Pull requests:** Supports code review through pull requests.
- **Bitbucket Pipelines:** Runs built-in CI/CD pipelines.
- **Jira integration:** Links code changes to Jira work items.
