# Confluence

Confluence is a team workspace and wiki from Atlassian. This package covers Confluence Cloud, part
of Atlassian Cloud.

## Key capabilities

- **Pages and spaces:** Organizes content as pages in spaces.
- **Collaborative editing:** Lets several users edit and comment on pages.
- **Templates:** Provides page templates for common documents.
- **Permissions:** Controls access at the space and page level.
