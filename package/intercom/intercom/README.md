# Intercom

Intercom is a customer service platform from Intercom, Inc. It combines an AI agent, a help desk and
messaging channels for supporting customers.

## Key capabilities

- **AI agent:** Answers customer questions with the Fin AI agent.
- **Help desk:** Manages conversations and tickets in a shared inbox.
- **Messenger:** Provides an in-app and on-site Messenger for live chat.
- **Help center:** Hosts a knowledge base for self-service articles.
