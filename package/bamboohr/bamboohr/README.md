# BambooHR

BambooHR is a human resources information system (HRIS) from BambooHR for small and medium-sized
businesses.

## Key capabilities

- **Employee records:** Stores employee data in one system.
- **Hiring:** Provides applicant tracking.
- **Onboarding:** Runs onboarding tasks for new hires.
- **Time off and payroll:** Tracks time off and offers payroll in supported regions.
- **API:** Provides an API for integrations.
