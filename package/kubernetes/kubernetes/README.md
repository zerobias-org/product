# Kubernetes

Kubernetes is an open-source system for automating deployment, scaling and management of
containerized applications. It is a Cloud Native Computing Foundation (CNCF) project.

## Key capabilities

- **Container orchestration:** Schedules containers across a cluster of nodes.
- **Self-healing:** Restarts failed containers and replaces unhealthy pods.
- **Service discovery and load balancing:** Exposes workloads through Services and DNS.
- **Access control:** Controls API access with role-based access control (RBAC).
