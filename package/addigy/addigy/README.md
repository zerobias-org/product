# Addigy

Addigy is a cloud-based device management platform from Addigy for Apple devices. IT teams and
managed service providers use it to manage and secure macOS, iOS and iPadOS devices.

## Key capabilities

- **Live device monitoring:** Monitors devices in real time and raises alerts.
- **Remote support:** Provides remote screen sharing and command-line access for troubleshooting.
- **Policy enforcement:** Applies device policies and remediates configuration drift.
- **Software and OS updates:** Deploys software from a catalog and manages OS updates and patches.
- **Compliance benchmarks:** Includes CIS, NIST, CMMC and DISA STIG benchmarks with reporting.
