# Miro

Miro is an online visual collaboration platform from Miro. Teams use shared boards to plan,
brainstorm and diagram together.

## Key capabilities

- **Boards:** Provides an infinite canvas with sticky notes, shapes, diagrams and documents.
- **Collaboration:** Supports real-time and asynchronous work with comments and mentions.
- **Templates:** Offers templates for workshops, planning and diagramming.
- **Integrations:** Connects to other tools and provides a REST API.
