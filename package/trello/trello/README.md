# Trello

Trello is a visual project management tool from Atlassian. It organizes work on boards, lists and
cards.

## Key capabilities

- **Boards and cards:** Tracks tasks as cards in lists on a board.
- **Views:** Shows work as boards, tables, calendars and timelines.
- **Automation:** Automates tasks with built-in rules.
- **API:** Offers a REST API for integrations.
