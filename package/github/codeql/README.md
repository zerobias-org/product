# CodeQL

CodeQL is a code analysis engine from GitHub. It lets users query code as data to find
vulnerabilities and errors. It powers code scanning in GitHub.

## Key capabilities

- **Semantic analysis:** Builds a database from code and queries it.
- **Query packs:** Ships standard queries for security and quality issues.
- **Custom queries:** Supports writing queries in the QL language.
- **Code scanning:** Runs in GitHub code scanning and reports alerts on pull requests.
