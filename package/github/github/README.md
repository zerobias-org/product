# GitHub

GitHub is a software development platform from GitHub, Inc. for hosting Git repositories and
collaborating on code.

## Key capabilities

- **Repositories:** Hosts Git repositories.
- **Pull requests:** Supports code review and branch protection.
- **GitHub Actions:** Runs CI/CD workflows.
- **Security features:** Provides dependency, secret and code scanning.
- **APIs:** Provides REST and GraphQL APIs.
