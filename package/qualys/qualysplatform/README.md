# Qualys Enterprise TruRisk Platform

The Qualys Enterprise TruRisk Platform is the cloud platform from Qualys that runs its IT, security
and compliance applications. It was formerly known as the Qualys Cloud Platform.

## Key capabilities

- **Asset inventory:** Discovers and tracks IT assets.
- **Vulnerability management:** Detects and prioritizes vulnerabilities.
- **Compliance:** Assesses configurations and policy compliance.
- **Data collection:** Collects data with cloud agents, scanners and connectors.
