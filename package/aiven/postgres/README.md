# Aiven for PostgreSQL

Aiven for PostgreSQL is a fully managed PostgreSQL database service from Aiven. It runs on major
public clouds, and Aiven handles setup, maintenance and backups.

## Key capabilities

- **Managed PostgreSQL:** Runs open source PostgreSQL as a managed service.
- **Multi-cloud:** Deploys on several public cloud providers and regions.
- **Backups:** Takes automatic backups and supports point-in-time recovery.
- **High availability:** Offers plans with standby nodes and automatic failover.
