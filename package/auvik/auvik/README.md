# Auvik

Auvik is a cloud-based network management and monitoring platform from Auvik Networks.

## Key capabilities

- **Network discovery:** Discovers devices and maps network topology.
- **Monitoring and alerts:** Monitors device performance and sends alerts.
- **Configuration backup:** Backs up network device configurations.
- **Traffic insights:** Shows network traffic flows.
