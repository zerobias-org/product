# Apache Derby

Apache Derby is an open-source relational database implemented entirely in Java. It is a project of
the Apache Software Foundation, part of the Apache DB project.

## Key capabilities

- **Embedded mode:** Runs inside a Java application in the same JVM.
- **Network server mode:** Also runs as a client/server database over the network.
- **Standards:** Supports SQL and JDBC.
- **Small footprint:** Ships as a small set of JAR files.
