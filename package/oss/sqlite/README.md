# SQLite

SQLite is a self-contained, serverless SQL database engine written in C. It is in the public domain
and is embedded in many applications and devices.

## Key capabilities

- **Serverless:** Runs inside the application process with no separate server.
- **Single file:** Stores a full database in one cross-platform file.
- **Transactions:** Provides ACID transactions.
- **Zero configuration:** Needs no setup or administration.
