# Trino

Trino is an open-source distributed SQL query engine for big data analytics. It is developed by the
Trino open-source community.

## Key capabilities

- **Distributed SQL:** Runs SQL queries in parallel across a cluster.
- **Connectors:** Queries data where it lives, such as object storage, relational databases and other
  systems.
- **Federated queries:** Joins data from several sources in one query.
