# H2 Database Engine

H2 is an open-source relational database written in Java. It is often used embedded in Java
applications and for development and testing.

## Key capabilities

- **Embedded and server modes:** Runs inside an application or as a server.
- **In-memory databases:** Supports in-memory as well as disk-based databases.
- **JDBC and SQL:** Uses a JDBC API and standard SQL.
- **Browser console:** Includes a web-based console application.
