# MariaDB Server

MariaDB Server is an open-source relational database that started as a fork of MySQL. It is
developed by the MariaDB community, with the MariaDB Foundation as steward of the project.

## Key capabilities

- **Relational database:** Stores data in tables and queries it with SQL.
- **MySQL compatibility:** Keeps a high degree of compatibility with MySQL protocols and clients.
- **Storage engines:** Offers several storage engines, with InnoDB as the default.
- **Replication:** Supports replication and Galera-based clustering.
