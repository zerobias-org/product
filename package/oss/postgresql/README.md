# PostgreSQL

PostgreSQL is an open-source object-relational database system. It is developed by the PostgreSQL
Global Development Group.

## Key capabilities

- **SQL and transactions:** Supports SQL with ACID transactions.
- **Extensibility:** Supports custom data types, functions and extensions.
- **Data types:** Includes JSON, arrays and other advanced data types.
- **Replication:** Offers streaming and logical replication.
