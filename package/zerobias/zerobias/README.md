# ZeroBias

ZeroBias is a compliance automation and assessment platform from ZeroBias. It serves assessors and
organizations with cyber, digital and risk data and automation.

## Key capabilities

- **Evidence collection:** Collects evidence automatically from connected systems.
- **Compliance content:** Uses a catalog of frameworks, standards and products.
- **Assessment automation:** Supports automated control testing and reporting.
