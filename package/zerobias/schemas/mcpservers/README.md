# MCP Servers

This ZeroBias package catalogs Model Context Protocol (MCP) servers and their tools. MCP is an open
protocol for connecting AI applications to tools and data. This package is part of the ZeroBias
schemas suite.

## Key capabilities

- **Tools:** MCP servers expose tools that AI agents can call.
- **Resources and prompts:** Servers can also expose resources and prompt templates.
- **Standard protocol:** Clients and servers talk over the MCP specification.
