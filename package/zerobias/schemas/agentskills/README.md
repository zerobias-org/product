# Agent Skills

Agent Skills is an open format for giving AI agents new capabilities. A skill is a folder with a
SKILL.md file of instructions, defined by the agentskills.io specification. This ZeroBias package
catalogs it in the ZeroBias schemas suite.

## Key capabilities

- **SKILL.md format:** Describes a skill with metadata and instructions in one file.
- **Bundled resources:** Lets skills include scripts and reference files.
- **Portability:** Lets the same skill work across agents that support the format.
