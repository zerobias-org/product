# Kubescape

Kubescape is an open-source Kubernetes security platform and a Cloud Native Computing Foundation
(CNCF) project. It scans clusters, manifests and images for misconfigurations and vulnerabilities.

## Key capabilities

- **Posture scanning:** Checks clusters and YAML against frameworks such as NSA-CISA and CIS.
- **Vulnerability scanning:** Scans container images for known vulnerabilities.
- **CI/CD integration:** Runs in pipelines and IDEs to catch issues before deployment.
- **In-cluster operator:** Runs continuously in a cluster to monitor posture.
