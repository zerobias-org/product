# Venmo

Venmo is a mobile payment service owned by PayPal. It lets people in the United States send and
receive money.

## Key capabilities

- **Peer-to-peer payments:** Sends and requests money between users.
- **Business payments:** Lets businesses accept payments from Venmo users.
- **Venmo card:** Offers debit and credit cards linked to the account.
