# Avigilon Alta Access

Avigilon Alta Access is a cloud-based access control system from Avigilon, a Motorola Solutions
company. It is part of the Avigilon Alta product line.

## Key capabilities

- **Cloud management:** Manages users, doors and sites from a web portal.
- **Credentials:** Supports mobile credentials, key cards, fobs, PINs and guest passes.
- **Video integration:** Works with Avigilon Alta Video in one interface.
- **Integrations:** Provides an open API and integration apps.
