# Dropbox

Dropbox is a cloud file storage and sharing service from Dropbox, Inc.

## Key capabilities

- **File sync:** Syncs files across devices.
- **Sharing:** Shares files and folders with links and permissions.
- **Admin controls:** Lets team admins manage users and sharing settings.
- **API:** Provides APIs for files, sharing and team management.
