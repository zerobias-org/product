# BeyondTrust Remote Support

BeyondTrust Remote Support is a remote support product from BeyondTrust for service desks to access
and fix end-user devices and systems.

## Key capabilities

- **Remote sessions:** Gives support staff remote access to desktops, servers and mobile devices.
- **Session recording:** Records and logs support sessions for auditing.
- **Access controls:** Controls permissions for support representatives.
- **Integrations:** Integrates with service desk tools through APIs.
