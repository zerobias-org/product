# BeyondTrust Password Safe

BeyondTrust Password Safe is a privileged password and secrets management product from BeyondTrust.
It is documented with BeyondTrust BeyondInsight.

## Key capabilities

- **Credential vaulting:** Stores privileged account credentials and secrets.
- **Credential rotation:** Rotates passwords and keys automatically.
- **Session management:** Records and monitors privileged sessions.
- **Account discovery:** Finds privileged accounts across systems.
