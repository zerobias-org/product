# BeyondTrust Privileged Remote Access

BeyondTrust Privileged Remote Access (PRA) is a product from BeyondTrust for controlling and
auditing privileged remote access by employees and vendors.

## Key capabilities

- **Secure remote access:** Gives users access to systems without a VPN.
- **Credential injection:** Injects credentials into sessions without revealing them to users.
- **Session monitoring:** Records and audits privileged sessions.
- **Access policies:** Controls who can access which systems and when.
