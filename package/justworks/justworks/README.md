# Justworks

Justworks is HR and payroll software from Justworks, Inc. It runs payroll, benefits, HR and
compliance tasks for small and mid-sized businesses.

## Key capabilities

- **Payroll:** Runs payroll and handles payroll tax filings.
- **Benefits:** Offers access to health and other employee benefits.
- **HR tools:** Manages employee records, time off and onboarding.
- **Compliance support:** Helps with HR and payroll compliance tasks.
