# Microsoft SQL Server

Microsoft SQL Server is a relational database management system from Microsoft. It runs on Windows
and Linux and in containers.

## Key capabilities

- **Database engine:** Stores and processes relational data with Transact-SQL.
- **High availability:** Supports Always On availability groups and failover cluster instances.
- **Security:** Supports Transparent Data Encryption, Always Encrypted, auditing and row-level
  security.
- **Additional services:** Includes Integration Services, Analysis Services and Reporting Services.
