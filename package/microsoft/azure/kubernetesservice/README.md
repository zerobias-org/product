# Azure Kubernetes Service (AKS)

Azure Kubernetes Service (AKS) is a managed Kubernetes service from Microsoft Azure. Azure runs the
Kubernetes control plane; customers run their workloads on agent nodes.

## Key capabilities

- **Managed control plane:** Azure operates and maintains the Kubernetes control plane.
- **Node pools:** Runs workloads on node pools of Azure virtual machines, with autoscaling.
- **Identity integration:** Integrates with Microsoft Entra ID and Kubernetes RBAC.
- **Upgrades:** Supports cluster and node image upgrades.
