# Azure Relay

Azure Relay is a Microsoft Azure service that exposes services running in a corporate network to the
public cloud without opening firewall ports.

## Key capabilities

- **Hybrid Connections:** Relays WebSocket and HTTP traffic between endpoints.
- **WCF Relay:** Supports Windows Communication Foundation services.
- **No inbound ports:** Uses outbound connections so no inbound firewall changes are needed.
