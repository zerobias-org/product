# Azure Database Migration Service

Azure Database Migration Service is a Microsoft Azure service for migrating databases to Azure data
platforms.

## Key capabilities

- **Database migration:** Migrates SQL Server and other databases to Azure.
- **Online and offline modes:** Supports offline and minimal-downtime online migrations.
- **Tooling:** Works with Azure Data Studio and the Azure portal.
- **Assessment:** Assesses readiness before migration.
