# Azure Data Lake Storage

Azure Data Lake Storage (formerly Data Lake Storage Gen2) is a set of Microsoft Azure big data
analytics capabilities built on Azure Blob Storage.

## Key capabilities

- **Hierarchical namespace:** Organizes objects into directories and files.
- **Hadoop compatibility:** Works with Hadoop and Spark through the ABFS driver.
- **Access control:** Supports POSIX-like ACLs and Azure RBAC.
- **Blob features:** Uses Blob Storage tiers, redundancy and lifecycle policies.
