# Microsoft Cost Management and Billing

Microsoft Cost Management and Billing is a set of Microsoft tools for managing Azure invoices,
billing accounts and payments.

## Key capabilities

- **Billing accounts:** Manages billing accounts, profiles and invoice sections.
- **Invoices:** Views and downloads invoices.
- **Payment methods:** Manages payment methods.
- **Billing APIs:** Exposes billing data through REST APIs.
