# Azure Data Lake Storage

Azure Data Lake Storage is a Microsoft Azure storage service for big data analytics, built on Azure
Blob Storage.

## Key capabilities

- **Hierarchical namespace:** Organizes data into directories and files.
- **Access control:** Supports Azure RBAC and POSIX-like access control lists.
- **Analytics integration:** Works with Hadoop-compatible and Azure analytics services.
- **Blob Storage features:** Uses Blob Storage tiers, redundancy and lifecycle policies.
