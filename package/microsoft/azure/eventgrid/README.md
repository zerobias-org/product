# Azure Event Grid

Azure Event Grid is a Microsoft Azure event routing and MQTT broker service.

## Key capabilities

- **Event routing:** Routes events from Azure services and apps to handlers.
- **Filtering:** Filters events by type and subject.
- **MQTT broker:** Publishes and subscribes to MQTT messages.
- **Delivery:** Retries delivery and supports dead-lettering.
