# Azure Load Balancer

Azure Load Balancer is a Layer 4 (TCP and UDP) load balancer from Microsoft Azure. It distributes
inbound traffic across healthy backend instances.

## Key capabilities

- **Public and internal load balancing:** Balances internet-facing or private network traffic.
- **Health probes:** Sends traffic only to backend instances that pass health probes.
- **Outbound rules:** Provides outbound connectivity for backend instances.
- **Zone redundancy:** Supports zone-redundant and zonal frontends.
