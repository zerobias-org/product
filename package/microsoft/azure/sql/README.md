# Azure SQL

Azure SQL is a family of managed SQL Server database products on Microsoft Azure, built on the SQL
Server database engine.

## Key capabilities

- **Azure SQL Database:** A fully managed database service.
- **Azure SQL Managed Instance:** A managed instance with broad SQL Server compatibility.
- **SQL Server on Azure VMs:** SQL Server running in Azure virtual machines.
