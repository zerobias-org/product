# Azure App Configuration

Azure App Configuration is a Microsoft Azure service for central management of application settings
and feature flags.

## Key capabilities

- **Key-value store:** Stores application settings as key-values with labels.
- **Feature flags:** Turns features on and off without redeploying.
- **Key Vault references:** References secrets stored in Azure Key Vault.
- **Encryption:** Encrypts data at rest, with optional customer-managed keys.
