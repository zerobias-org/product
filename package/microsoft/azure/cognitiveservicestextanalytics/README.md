# Azure Language

Azure Language in Foundry Tools is a Microsoft Azure AI service for natural language processing. It
includes the features formerly offered as Text Analytics.

## Key capabilities

- **Sentiment analysis:** Detects sentiment and opinions in text.
- **Entity recognition:** Finds named entities and personal information (PII).
- **Key phrase extraction:** Extracts key phrases from text.
- **Language detection:** Detects the language of text.
