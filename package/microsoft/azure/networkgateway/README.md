# Azure VPN Gateway

Azure VPN Gateway is a Microsoft Azure service that sends encrypted traffic between an Azure virtual
network and on-premises locations or other virtual networks.

## Key capabilities

- **Site-to-site VPN:** Connects on-premises networks over IPsec/IKE tunnels.
- **Point-to-site VPN:** Connects individual client devices to a virtual network.
- **Local network gateways:** Represents on-premises VPN devices and their address spaces.
- **VNet-to-VNet:** Connects Azure virtual networks to each other.
