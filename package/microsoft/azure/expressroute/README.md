# Azure ExpressRoute

Azure ExpressRoute is a Microsoft Azure service for private connections between on-premises networks
and Microsoft cloud services.

## Key capabilities

- **Private connectivity:** Connects to Azure over a private connection, not the public internet.
- **Redundancy:** Provides redundant circuits.
- **Global Reach:** Links on-premises sites through ExpressRoute circuits.
- **Encryption:** Supports MACsec on ExpressRoute Direct.
