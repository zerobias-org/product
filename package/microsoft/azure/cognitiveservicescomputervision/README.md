# Azure Vision

Azure Vision in Foundry Tools (formerly Computer Vision) is a Microsoft Azure AI service that
analyzes images and video.

## Key capabilities

- **Image analysis:** Tags, captions and detects objects in images.
- **OCR:** Extracts printed and handwritten text from images.
- **Face:** Includes the Azure Face service for face detection.
- **API and SDKs:** Provides REST APIs and SDKs.
