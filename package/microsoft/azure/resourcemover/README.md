# Azure Resource Mover

Azure Resource Mover is a Microsoft Azure service for moving resources between Azure regions.

## Key capabilities

- **Cross-region moves:** Moves VMs, networking, SQL and other resources to another region.
- **Dependency analysis:** Identifies dependencies between resources being moved.
- **Move orchestration:** Prepares, initiates, commits and cleans up moves in steps.
