# Azure DNS

Azure DNS is a Microsoft Azure hosting service for DNS domains.

## Key capabilities

- **Public DNS:** Hosts public DNS zones on Azure name servers.
- **Private DNS:** Resolves names inside virtual networks.
- **Alias records:** Points records at Azure resources.
- **Access control:** Controls changes with Azure RBAC and resource locks.
