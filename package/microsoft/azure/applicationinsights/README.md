# Application Insights

Application Insights is the application performance monitoring (APM) feature of Azure Monitor, from
Microsoft.

## Key capabilities

- **Telemetry collection:** Collects requests, dependencies, exceptions and traces.
- **OpenTelemetry:** Accepts telemetry through the Azure Monitor OpenTelemetry distro.
- **Application map:** Shows components of an application and how they interact.
- **Availability tests:** Tests application endpoints from locations around the world.
