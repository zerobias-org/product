# Azure Data Share

Azure Data Share is a Microsoft Azure service for sharing data with other organizations. Microsoft
has announced its retirement on November 12, 2029.

## Key capabilities

- **Snapshot sharing:** Shares full or incremental snapshots of data.
- **In-place sharing:** Shares Azure Data Explorer data in place.
- **Governance:** Tracks who data is shared with and under what terms.
- **Scheduling:** Refreshes shared data on a schedule.
