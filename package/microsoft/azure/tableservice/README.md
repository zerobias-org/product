# Azure Table Storage

Azure Table Storage is a Microsoft Azure service that stores structured NoSQL data as key-attribute
entities in a schemaless design.

## Key capabilities

- **NoSQL storage:** Stores entities in tables inside an Azure storage account.
- **Keys:** Uses partition keys and row keys for fast lookups.
- **Access:** Accesses data through the REST API or Azure Tables client libraries.
