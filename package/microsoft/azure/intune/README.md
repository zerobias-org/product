# Microsoft Intune

Microsoft Intune is a cloud-based endpoint management service from Microsoft. It manages and secures
devices and apps used by an organization.

## Key capabilities

- **Device management:** Enrolls and manages Windows, macOS, iOS/iPadOS, Android and Linux devices.
- **App management:** Deploys apps and applies app protection policies, including on personal
  devices.
- **Compliance policies:** Defines device compliance rules that Microsoft Entra Conditional Access
  can enforce.
- **Configuration profiles:** Pushes settings and security baselines to managed devices.
