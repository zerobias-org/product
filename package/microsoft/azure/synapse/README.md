# Azure Synapse Analytics

Azure Synapse Analytics is a Microsoft Azure analytics service that combines data warehousing, big
data processing and data integration.

## Key capabilities

- **SQL pools:** Provides dedicated and serverless SQL pools.
- **Apache Spark:** Runs Apache Spark pools for big data processing.
- **Pipelines:** Integrates data with pipelines shared with Azure Data Factory.
- **Synapse Studio:** Provides one workspace for development and management.
