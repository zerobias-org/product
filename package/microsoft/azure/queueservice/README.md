# Azure Queue Storage

Azure Queue Storage is a Microsoft Azure service for storing large numbers of messages, used to
decouple application components.

## Key capabilities

- **Message queues:** Stores messages in queues inside an Azure storage account.
- **HTTP/HTTPS access:** Accesses messages through authenticated REST calls.
- **Asynchronous processing:** Builds backlogs of work for asynchronous processing.
