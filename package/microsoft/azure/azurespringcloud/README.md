# Azure Spring Apps

Azure Spring Apps (formerly Azure Spring Cloud) is a Microsoft Azure service for running Spring Boot
applications. Microsoft has announced its retirement on March 31, 2028 and recommends Azure
Container Apps.

## Key capabilities

- **Spring hosting:** Runs Spring Boot apps without managing infrastructure.
- **Spring Cloud components:** Provides config server and service registry options.
- **Scaling:** Scales app instances manually or automatically.
- **Monitoring:** Integrates with Application Insights and Azure Monitor.
