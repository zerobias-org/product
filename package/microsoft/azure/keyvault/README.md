# Azure Key Vault

Azure Key Vault is a Microsoft Azure service for storing and controlling access to secrets,
cryptographic keys and certificates.

## Key capabilities

- **Secrets management:** Stores tokens, passwords, API keys and other secrets.
- **Key management:** Creates and controls encryption keys, including HSM-protected keys.
- **Certificate management:** Provisions and manages TLS certificates.
- **Access control:** Controls access with Azure RBAC or vault access policies and logs usage.
