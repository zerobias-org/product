# Azure Serial Console

Azure Serial Console is a Microsoft Azure feature that gives text-based console access to virtual
machines and scale set instances, independent of the VM network state.

## Key capabilities

- **Console access:** Connects to the ttyS0 or COM1 serial port of a VM.
- **Troubleshooting:** Helps fix boot and network configuration problems.
- **Access control:** Requires the Virtual Machine Contributor role or higher.
