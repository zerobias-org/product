# Power BI Embedded

Power BI Embedded is a Microsoft Azure offering for embedding Power BI reports and dashboards in
applications, billed by Azure capacity.

## Key capabilities

- **Embedded analytics:** Embeds Power BI content in custom applications.
- **Capacity:** Provides dedicated capacity that can be scaled or paused.
- **APIs and SDKs:** Uses Power BI REST APIs and JavaScript client libraries.
