# Azure Stack Hub

Azure Stack Hub is a Microsoft hybrid cloud platform for running Azure services in an on-premises
datacenter. Operators manage it through admin APIs and the administrator portal.

## Key capabilities

- **On-premises Azure services:** Runs Azure IaaS and PaaS services on local hardware.
- **Operator administration:** Manages plans, offers, quotas and subscriptions.
- **Disconnected use:** Supports connected and disconnected deployments.
- **Marketplace:** Provides marketplace items for tenants.
