# Azure Data Explorer

Azure Data Explorer is a Microsoft Azure big data analytics service for log, telemetry and time
series data. It uses the Kusto Query Language (KQL).

## Key capabilities

- **Data ingestion:** Ingests streaming and batch data from many sources.
- **KQL queries:** Queries large data sets with the Kusto Query Language.
- **Time series analysis:** Provides built-in time series and anomaly functions.
- **Visualization:** Shows results in dashboards and connects to Power BI.
