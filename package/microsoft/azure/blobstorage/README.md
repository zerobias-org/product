# Azure Blob Storage

Azure Blob Storage is the Microsoft Azure object storage service for unstructured data such as
documents, images, backups and logs.

## Key capabilities

- **Object storage:** Stores unstructured data as blobs in containers.
- **Access tiers:** Offers hot, cool, cold and archive tiers.
- **Data protection:** Supports soft delete, versioning and immutable storage.
- **Encryption:** Encrypts data at rest by default.
