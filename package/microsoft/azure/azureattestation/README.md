# Azure Attestation

Azure Attestation is a Microsoft Azure service for remotely verifying the trustworthiness of a
platform and the integrity of the binaries running on it.

## Key capabilities

- **Remote attestation:** Verifies evidence from trusted execution environments.
- **Supported environments:** Attests Intel SGX enclaves, VBS enclaves, TPMs and confidential VMs.
- **Policies:** Evaluates evidence against customer-defined attestation policies.
- **Signed tokens:** Issues signed attestation tokens to relying parties.
