# Azure Virtual Desktop

Azure Virtual Desktop is a Microsoft Azure desktop and app virtualization service.

## Key capabilities

- **Virtual desktops:** Delivers full Windows desktops and remote apps.
- **Multi-session:** Runs Windows 11 and Windows 10 Enterprise multi-session.
- **Host pools:** Groups session hosts and scales them.
- **Identity:** Signs users in with Microsoft Entra ID.
