# Azure SQL Database

Azure SQL Database is a fully managed relational database service from Microsoft Azure, part of the
Azure SQL family.

## Key capabilities

- **Managed engine:** Handles patching, backups and monitoring.
- **Purchasing models:** Offers vCore and DTU purchasing models, including serverless.
- **High availability:** Provides built-in high availability and geo-replication.
- **Security:** Supports Microsoft Entra authentication, TDE, auditing and Defender for SQL.
