# Azure Arc-enabled servers

Azure Arc-enabled servers is a Microsoft Azure service for managing Windows and Linux machines
outside Azure from the Azure control plane. It uses the Microsoft.HybridCompute resource provider.

## Key capabilities

- **Hybrid inventory:** Represents non-Azure machines as Azure resources.
- **Policy:** Applies Azure Policy and machine configuration.
- **Extensions:** Deploys VM extensions to non-Azure machines.
- **Security:** Connects machines to Microsoft Defender for Cloud.
