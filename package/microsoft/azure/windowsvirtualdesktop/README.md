# Azure Virtual Desktop

Azure Virtual Desktop (formerly Windows Virtual Desktop) is a desktop and app virtualization service
from Microsoft that runs on Azure.

## Key capabilities

- **Multi-session Windows:** Runs Windows Enterprise multi-session on session hosts.
- **Host pools:** Groups session hosts and publishes desktops and RemoteApp apps.
- **Identity:** Integrates with Microsoft Entra ID and Active Directory Domain Services.
- **Scaling:** Scales session hosts with autoscale plans.
