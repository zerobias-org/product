# Azure Management Groups

Azure management groups are a Microsoft Azure governance feature. They organize subscriptions into a
hierarchy so policy and access can be applied across many subscriptions.

## Key capabilities

- **Hierarchy:** Groups subscriptions under a root management group and nested groups.
- **Policy inheritance:** Applies Azure Policy assignments to all subscriptions below a group.
- **Access inheritance:** Applies Azure RBAC role assignments down the hierarchy.
