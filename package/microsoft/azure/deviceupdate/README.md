# Device Update for IoT Hub

Device Update for IoT Hub is a Microsoft Azure service for deploying over-the-air updates to IoT
devices.

## Key capabilities

- **Over-the-air updates:** Deploys image and package updates to devices.
- **Groups:** Targets updates to device groups.
- **Compliance reporting:** Reports which devices have which updates.
- **IoT Hub integration:** Uses Azure IoT Hub for device communication.
