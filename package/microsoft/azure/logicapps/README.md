# Azure Logic Apps

Azure Logic Apps is a Microsoft Azure service for building automated workflows that integrate apps,
data and services, with little or no code.

## Key capabilities

- **Workflow designer:** Builds workflows from triggers and actions in a visual designer.
- **Connectors:** Provides prebuilt connectors for Microsoft and third-party services.
- **Hosting options:** Runs workflows in multitenant Consumption or single-tenant Standard plans.
- **Enterprise integration:** Supports B2B scenarios such as EDI and XML processing.
