# Azure Subscriptions

An Azure subscription is the Microsoft Azure unit for billing and access to resources. The
Subscription API (Microsoft.Subscription) creates and manages subscriptions programmatically.

## Key capabilities

- **Subscription creation:** Creates subscriptions for EA, MCA and MPA billing accounts.
- **Lifecycle:** Renames, cancels and enables subscriptions.
- **Aliases:** Manages subscription aliases.
