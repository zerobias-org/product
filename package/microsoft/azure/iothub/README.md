# Azure IoT Hub

Azure IoT Hub is a managed service from Microsoft Azure that acts as a central message hub for
communication between IoT applications and the devices they manage.

## Key capabilities

- **Bidirectional messaging:** Supports device-to-cloud telemetry and cloud-to-device messages.
- **Device identity:** Keeps a registry of device identities and authenticates each device.
- **Device twins:** Stores device state and metadata as JSON documents that apps can query.
- **Message routing:** Routes device messages to other Azure services based on rules.
