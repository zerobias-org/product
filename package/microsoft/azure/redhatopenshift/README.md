# Azure Red Hat OpenShift

Azure Red Hat OpenShift is a managed OpenShift service on Microsoft Azure, jointly engineered and
supported by Microsoft and Red Hat.

## Key capabilities

- **Managed clusters:** Provides OpenShift clusters operated by Microsoft and Red Hat.
- **Kubernetes platform:** Runs containerized applications on Red Hat OpenShift.
- **Azure integration:** Integrates with Azure networking, storage and identity.
