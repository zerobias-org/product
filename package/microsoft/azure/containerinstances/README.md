# Azure Container Instances

Azure Container Instances is a Microsoft Azure service for running containers without managing
virtual machines.

## Key capabilities

- **Serverless containers:** Runs Linux and Windows containers on demand.
- **Container groups:** Runs multiple containers together on one host.
- **Networking:** Deploys into virtual networks or with public IPs.
- **Confidential containers:** Runs containers in hardware-based trusted environments.
