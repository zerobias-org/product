# Azure Site Recovery

Azure Site Recovery is a Microsoft Azure disaster recovery service. It replicates workloads to a
secondary location and fails them over when needed.

## Key capabilities

- **Replication:** Replicates Azure VMs, on-premises VMs and physical servers.
- **Failover and failback:** Fails over to a secondary location and back.
- **Recovery plans:** Orchestrates failover of multi-tier applications.
- **DR drills:** Runs test failovers without affecting production.
