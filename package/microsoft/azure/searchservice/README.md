# Foundry IQ (Azure AI Search)

Foundry IQ (Azure AI Search), formerly Azure Cognitive Search, is a managed search and retrieval
service from Microsoft Azure. It indexes content and serves it to applications, AI agents and
retrieval-augmented generation (RAG) workloads.

## Key capabilities

- **Full-text search:** Indexes content and runs full-text queries.
- **Vector and hybrid search:** Supports vector search and hybrid keyword and vector queries.
- **Indexers:** Pulls content from Azure data sources into indexes.
- **Knowledge bases:** Provides knowledge source and knowledge base APIs for agentic retrieval.
- **Security:** Supports Microsoft Entra authentication and private endpoints.
