# Azure Resource Manager

Azure Resource Manager (ARM) is the deployment and management service for Microsoft Azure. Every
request to create, update or delete Azure resources goes through it.

## Key capabilities

- **Resource groups:** Organizes resources into resource groups.
- **Templates:** Deploys resources declaratively with ARM templates and Bicep.
- **Access control:** Applies Azure RBAC, locks and tags to resources.
- **Consistent API:** Provides one management layer for the portal, CLI, PowerShell and SDKs.
