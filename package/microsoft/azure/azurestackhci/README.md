# Azure Local

Azure Local (formerly Azure Stack HCI) is a Microsoft hybrid infrastructure solution that runs
virtual machines and containers on validated on-premises hardware, managed through Azure Arc.

## Key capabilities

- **Hyperconverged infrastructure:** Combines compute, storage and networking on local servers.
- **Azure Arc management:** Manages clusters and VMs from the Azure portal.
- **Virtual machines:** Runs Windows and Linux VMs on premises.
- **Azure services:** Runs services such as AKS and Azure Virtual Desktop on premises.
