# Foundry Tools

Foundry Tools (formerly Azure AI services and Azure Cognitive Services) is a set of Microsoft Azure
AI APIs for vision, speech, language, translation and document tasks. It is part of Microsoft
Foundry.

## Key capabilities

- **Prebuilt AI APIs:** Provides APIs for vision, speech, language, translation and documents.
- **Multi-service resource:** Accesses several services with one resource and key.
- **Security:** Supports Microsoft Entra ID authentication and private endpoints.
- **SDKs:** Offers SDKs for common programming languages.
