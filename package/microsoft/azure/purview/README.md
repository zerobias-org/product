# Microsoft Purview

Microsoft Purview is a set of data governance, data security and risk and compliance solutions from
Microsoft. It includes the data governance service formerly called Azure Purview.

## Key capabilities

- **Data governance:** Maps and catalogs data across on-premises, multicloud and SaaS sources.
- **Information protection:** Classifies and labels sensitive data.
- **Data loss prevention:** Applies policies to prevent sharing of sensitive data.
- **Compliance:** Supports audit, eDiscovery and compliance management.
