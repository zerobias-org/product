# Azure Backup

Azure Backup is a Microsoft Azure service for backing up and restoring data in the Microsoft cloud.

## Key capabilities

- **Workload coverage:** Backs up Azure VMs, SQL Server and SAP HANA in VMs, Azure Files and more.
- **Vaults:** Stores backups in Recovery Services vaults and Backup vaults.
- **Security:** Supports soft delete, immutable vaults and encryption.
- **Backup center:** Manages backups at scale from one place.
