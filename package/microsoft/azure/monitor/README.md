# Azure Monitor

Azure Monitor is a Microsoft Azure service for collecting, analyzing and acting on monitoring data
from cloud and on-premises environments.

## Key capabilities

- **Metrics and logs:** Collects platform metrics, resource logs and activity logs.
- **Log analysis:** Stores logs in Log Analytics workspaces and queries them with KQL.
- **Alerts:** Raises alerts on metrics, logs and activity, and runs action groups.
- **Insights:** Provides curated views such as Application Insights and VM insights.
