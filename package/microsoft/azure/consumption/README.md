# Microsoft Cost Management (Consumption API)

The Azure Consumption API is part of Microsoft Cost Management. It gives programmatic access to
Azure usage, charges, budgets and reservation data.

## Key capabilities

- **Usage details:** Returns resource usage and cost records.
- **Budgets:** Creates and reads budgets.
- **Reservations:** Returns reservation summaries and details.
- **Price sheets:** Returns prices for a billing period.
