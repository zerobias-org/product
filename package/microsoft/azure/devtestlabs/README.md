# Azure DevTest Labs

Azure DevTest Labs is a Microsoft Azure service for creating and managing development and test
environments.

## Key capabilities

- **Lab VMs:** Creates VMs from images, formulas and artifacts.
- **Cost control:** Sets policies, quotas and auto-shutdown.
- **Environments:** Deploys multi-VM environments from ARM templates.
- **Self-service:** Lets developers create VMs within policies.
