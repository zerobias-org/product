# Azure Advisor

Azure Advisor is a Microsoft Azure service that gives personalized recommendations for Azure
resources.

## Key capabilities

- **Recommendations:** Recommends changes for reliability, security, performance, cost and
  operations.
- **Advisor Score:** Scores how well deployments follow best practices.
- **Alerts:** Notifies when new recommendations appear.
- **Retirement tracking:** Shows Azure service retirements that affect your resources.
