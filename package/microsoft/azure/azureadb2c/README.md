# Azure Active Directory B2C

Azure Active Directory B2C (Azure AD B2C) is a Microsoft customer identity and access management
service. It handles sign-up and sign-in for customer-facing apps.

## Key capabilities

- **Customer sign-in:** Provides sign-up, sign-in and profile flows for apps.
- **Social identity providers:** Federates with social and enterprise identity providers.
- **Custom policies:** Customizes identity flows with user flows and custom policies.
- **Branding:** Customizes the look of sign-in pages.
