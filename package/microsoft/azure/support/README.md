# Azure Support

Azure Support covers Microsoft Azure technical and billing support. The Support API
(Microsoft.Support) creates and manages support tickets programmatically.

## Key capabilities

- **Support tickets:** Creates, lists and updates support tickets.
- **Communications:** Adds and reads communications on tickets.
- **Service classification:** Lists services and problem classifications for tickets.
