# Azure Recovery Services vaults

A Recovery Services vault is a Microsoft Azure storage entity that holds backup data and recovery
points. It is used by Azure Backup and Azure Site Recovery.

## Key capabilities

- **Backup storage:** Stores backup data for Azure VMs, SQL Server, Azure Files and more.
- **Replication:** Holds replication configuration for Azure Site Recovery.
- **Security features:** Supports soft delete, immutability and multi-user authorization.
- **Redundancy:** Offers locally redundant, zone-redundant and geo-redundant storage.
