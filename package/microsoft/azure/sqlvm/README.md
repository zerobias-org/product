# SQL Server on Azure Virtual Machines

SQL Server on Azure Virtual Machines lets you run full versions of SQL Server in virtual machines on
Microsoft Azure.

## Key capabilities

- **Full SQL Server:** Runs SQL Server with operating system-level access.
- **SQL IaaS Agent extension:** Adds automated patching, backup and portal management.
- **Licensing:** Supports pay-as-you-go and bring-your-own-license models.
