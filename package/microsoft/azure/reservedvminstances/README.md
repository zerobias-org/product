# Azure Reserved Virtual Machine Instances

Azure Reserved Virtual Machine Instances are Microsoft Azure reservations that lower the cost of
virtual machines in exchange for a one-year or three-year commitment.

## Key capabilities

- **Discounted compute:** Applies a billing discount to matching virtual machine usage.
- **Scope:** Applies the discount to a subscription, resource group or shared scope.
- **Flexibility:** Supports instance size flexibility, exchanges and refunds within limits.
