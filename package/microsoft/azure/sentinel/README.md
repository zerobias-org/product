# Microsoft Sentinel

Microsoft Sentinel (formerly Azure Sentinel) is a cloud-native SIEM and SOAR solution from
Microsoft.

## Key capabilities

- **Data collection:** Collects security data through data connectors.
- **Detection:** Detects threats with analytics rules.
- **Investigation:** Groups alerts into incidents for investigation and hunting.
- **Automation:** Automates response with automation rules and playbooks.
