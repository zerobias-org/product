# Microsoft Defender for Cloud

Microsoft Defender for Cloud (formerly Azure Security Center) is a cloud-native application
protection platform from Microsoft for Azure, multicloud and hybrid environments.

## Key capabilities

- **Security posture:** Assesses resources and provides a secure score and recommendations.
- **Regulatory compliance:** Maps resource state to compliance standards.
- **Workload protection:** Provides Defender plans for servers, containers, databases and more.
- **Multicloud:** Connects AWS and Google Cloud environments.
