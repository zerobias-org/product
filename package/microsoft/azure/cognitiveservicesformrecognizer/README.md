# Azure Document Intelligence

Azure Document Intelligence (formerly Form Recognizer) is a Microsoft Azure AI service that extracts
text, key-value pairs, tables and structure from documents. It is now part of Azure Content
Understanding in Foundry Tools.

## Key capabilities

- **Prebuilt models:** Extracts data from invoices, receipts, ID documents and more.
- **Layout:** Extracts text, tables and document structure.
- **Custom models:** Trains models for custom document types.
- **Studio:** Tests models in Document Intelligence Studio.
