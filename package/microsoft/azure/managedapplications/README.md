# Azure Managed Applications

Azure Managed Applications is a Microsoft Azure feature that lets publishers offer cloud solutions
that customers deploy and the publisher manages.

## Key capabilities

- **Service catalog:** Publishes approved solutions for use inside an organization.
- **Marketplace offers:** Publishes managed applications to Azure Marketplace.
- **Managed resource group:** Deploys resources to a group the publisher can manage.
- **Access control:** Limits what the customer can change in the managed resources.
