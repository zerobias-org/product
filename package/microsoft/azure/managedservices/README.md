# Azure Lighthouse

Azure Lighthouse is a Microsoft Azure service for managing resources across tenants. Service
providers and enterprises use it to manage customer or subsidiary environments from one tenant.

## Key capabilities

- **Delegated resource management:** Delegates subscriptions or resource groups to another tenant.
- **Role-based access:** Grants access through Azure built-in roles.
- **Onboarding:** Onboards customers with ARM templates or Azure Marketplace offers.
- **Visibility:** Lets customers see and remove delegations and review activity.
