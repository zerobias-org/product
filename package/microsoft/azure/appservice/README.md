# Azure App Service

Azure App Service is a Microsoft Azure platform for hosting web apps, REST APIs and mobile back
ends.

## Key capabilities

- **Web hosting:** Runs apps in .NET, Java, Node.js, Python, PHP and containers.
- **Scaling:** Scales up and out manually or automatically.
- **Deployment slots:** Deploys to staging slots and swaps into production.
- **Authentication:** Adds built-in sign-in with Microsoft Entra ID and other providers.
