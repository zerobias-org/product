# Azure Custom Resource Providers

Azure Custom Resource Providers is a Microsoft Azure feature for extending Azure Resource Manager
with custom resource types and actions.

## Key capabilities

- **Custom resources:** Adds custom resource types to Azure Resource Manager.
- **Custom actions:** Adds custom actions on resources.
- **Endpoints:** Routes requests to your own REST endpoints.
- **Templates:** Uses custom resources in ARM templates.
