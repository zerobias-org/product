# Azure Event Hubs

Azure Event Hubs is a Microsoft Azure event streaming service for ingesting large volumes of events.

## Key capabilities

- **Event ingestion:** Ingests millions of events per second.
- **Kafka compatibility:** Accepts Apache Kafka clients.
- **Capture:** Saves event streams to Azure storage.
- **Partitions:** Scales consumers with partitions and consumer groups.
