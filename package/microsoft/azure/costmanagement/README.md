# Microsoft Cost Management

Microsoft Cost Management is a set of Microsoft tools for analyzing, monitoring and optimizing cloud
costs.

## Key capabilities

- **Cost analysis:** Analyzes costs by service, resource, tag and time.
- **Budgets:** Sets budgets and alerts on spending.
- **Exports:** Exports cost data to storage on a schedule.
- **Recommendations:** Shows cost optimization recommendations from Azure Advisor.
