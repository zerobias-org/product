# Azure Import/Export

The Azure Import/Export service from Microsoft Azure transfers large amounts of data to and from
Azure Storage by shipping disk drives to an Azure datacenter.

## Key capabilities

- **Import jobs:** Imports data from shipped drives into Azure Blob Storage and Azure Files.
- **Export jobs:** Exports data from Azure Blob Storage to drives.
- **Encryption:** Requires BitLocker encryption on the drives.
