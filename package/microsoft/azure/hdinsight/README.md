# Azure HDInsight

Azure HDInsight is a Microsoft Azure managed service for open-source analytics frameworks such as
Apache Spark, Hadoop, Kafka and HBase.

## Key capabilities

- **Managed clusters:** Runs Spark, Hadoop, Kafka, HBase and Interactive Query clusters.
- **Enterprise Security Package:** Adds Active Directory integration and Apache Ranger.
- **Storage:** Uses Azure Storage and Data Lake Storage Gen2.
- **Monitoring:** Integrates with Azure Monitor.
