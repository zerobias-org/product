# Azure Analysis Services

Azure Analysis Services is a Microsoft Azure platform service for enterprise-grade tabular data
models. Client tools such as Power BI and Excel query the models.

## Key capabilities

- **Tabular models:** Hosts tabular semantic models in the cloud.
- **Data sources:** Connects to cloud and on-premises data sources.
- **Scaling:** Scales up, down or out with query replicas.
- **Security:** Uses Microsoft Entra ID authentication and role-based security.
