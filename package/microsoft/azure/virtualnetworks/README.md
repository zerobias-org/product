# Azure Virtual Network

Azure Virtual Network is the Microsoft Azure service for private networks in Azure. It lets Azure
resources communicate with each other, the internet and on-premises networks.

## Key capabilities

- **Address spaces and subnets:** Segments networks with custom IP ranges and subnets.
- **Traffic filtering:** Filters traffic with network security groups.
- **Peering:** Connects virtual networks with virtual network peering.
- **Service endpoints and Private Link:** Connects privately to Azure PaaS services.
