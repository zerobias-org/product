# Azure NetApp Files

Azure NetApp Files is a Microsoft Azure file storage service built on NetApp technology. It provides
NFS and SMB volumes for enterprise workloads.

## Key capabilities

- **File protocols:** Serves NFS, SMB and dual-protocol volumes.
- **Service levels:** Offers Standard, Premium and Ultra performance tiers.
- **Snapshots:** Takes point-in-time snapshots of volumes.
- **Replication:** Replicates volumes across zones and regions.
