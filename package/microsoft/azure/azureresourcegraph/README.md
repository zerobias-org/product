# Azure Resource Graph

Azure Resource Graph is a Microsoft Azure service for querying resources at scale across
subscriptions.

## Key capabilities

- **Resource queries:** Queries resources with the Kusto Query Language.
- **Scale:** Queries across subscriptions and management groups.
- **Change tracking:** Shows resource changes over time.
- **Explorer:** Runs queries in the Azure portal Resource Graph Explorer.
