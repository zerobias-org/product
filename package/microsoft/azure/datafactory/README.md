# Azure Data Factory

Azure Data Factory is a Microsoft Azure cloud data integration (ETL and ELT) service.

## Key capabilities

- **Pipelines:** Orchestrates data movement and transformation.
- **Connectors:** Connects to many cloud and on-premises data stores.
- **Data flows:** Transforms data with visual mapping data flows.
- **Integration runtimes:** Runs work in Azure, self-hosted or SSIS runtimes.
