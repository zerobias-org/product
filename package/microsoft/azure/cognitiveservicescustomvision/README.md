# Azure Custom Vision

Azure Custom Vision is a Microsoft Azure AI service for training custom image classification and
object detection models. Microsoft has announced its retirement on September 25, 2028.

## Key capabilities

- **Image classification:** Trains models that assign labels to images.
- **Object detection:** Trains models that find object locations in images.
- **Export:** Exports models to run on devices.
- **Portal and APIs:** Trains and tests models in a web portal or through APIs.
