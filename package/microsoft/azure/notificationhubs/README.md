# Azure Notification Hubs

Azure Notification Hubs is a Microsoft Azure push notification service for sending notifications to
mobile and desktop apps from any back end.

## Key capabilities

- **Cross-platform push:** Sends through Apple, Google, Windows and other push services.
- **Tags and templates:** Targets devices by tag and sends platform-independent templates.
- **Scale:** Broadcasts to large numbers of devices.
