# Azure SignalR Service

Azure SignalR Service is a managed Microsoft Azure service for adding real-time web functionality to
applications using ASP.NET Core SignalR.

## Key capabilities

- **Real-time messaging:** Pushes content updates to connected clients.
- **Connection scaling:** Manages client connections so the app server does not have to.
- **Serverless mode:** Works with Azure Functions in serverless mode.
