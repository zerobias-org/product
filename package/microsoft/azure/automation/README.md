# Azure Automation

Azure Automation is a Microsoft Azure service for process automation and configuration management
across Azure and non-Azure environments.

## Key capabilities

- **Runbooks:** Runs PowerShell and Python runbooks on a schedule or on demand.
- **Hybrid Runbook Worker:** Runs runbooks on machines outside Azure.
- **Shared resources:** Stores credentials, certificates and variables for runbooks.
- **Webhooks:** Starts runbooks from external HTTP calls.
