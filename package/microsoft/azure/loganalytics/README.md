# Log Analytics

Log Analytics is a tool in Azure Monitor from Microsoft. It stores log data in Log Analytics
workspaces and lets you query it with the Kusto Query Language (KQL).

## Key capabilities

- **Workspaces:** Collects log data from Azure resources and other sources into workspaces.
- **KQL queries:** Queries and analyzes log data with the Kusto Query Language.
- **Alerts and workbooks:** Uses query results in log alerts, workbooks and dashboards.
- **Access control:** Controls data access with workspace and table-level permissions.
