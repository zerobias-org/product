# Azure Batch

Azure Batch is a Microsoft Azure service for running large-scale parallel and high-performance
computing (HPC) jobs. This package covers the Batch service (data plane) API.

## Key capabilities

- **Job scheduling:** Runs large-scale parallel and HPC jobs as jobs and tasks.
- **Compute pools:** Manages pools of VMs that scale automatically.
- **Applications:** Deploys application packages to compute nodes.
- **Low-priority capacity:** Uses Spot VMs to lower cost.
