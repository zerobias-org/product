# Azure VMware Solution

Azure VMware Solution is a Microsoft Azure service that runs VMware private clouds on dedicated
bare-metal Azure hosts.

## Key capabilities

- **VMware stack:** Provides vSphere, vCenter, vSAN and NSX on Azure hardware.
- **Migration:** Moves VMware workloads to Azure with VMware HCX.
- **Azure integration:** Connects private clouds to Azure services over private networking.
- **Scaling:** Adds or removes hosts in clusters.
