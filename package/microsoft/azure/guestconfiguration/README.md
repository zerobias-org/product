# Azure Machine Configuration

Azure Machine Configuration (formerly Azure Policy Guest Configuration) is a Microsoft Azure feature
that audits and configures operating system settings on machines.

## Key capabilities

- **OS auditing:** Audits settings inside Azure and Arc-enabled machines.
- **Configuration:** Applies settings with PowerShell DSC-based packages.
- **Azure Policy integration:** Reports compliance through Azure Policy.
- **Hybrid support:** Works with Azure Arc-enabled servers.
