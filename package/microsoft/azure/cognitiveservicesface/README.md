# Azure Face

The Azure Face service is a Microsoft Azure AI service, part of Azure Vision in Foundry Tools, that
detects and recognizes human faces in images. Access to face identification and verification is
limited under Microsoft's Responsible AI policy.

## Key capabilities

- **Face detection:** Detects faces and returns their locations.
- **Verification and identification:** Compares faces for limited-access customers.
- **Liveness detection:** Checks that a face is a live person.
- **API and SDKs:** Provides REST APIs and SDKs.
