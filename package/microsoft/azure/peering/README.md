# Azure Peering Service

Azure Peering Service is a Microsoft Azure networking service that improves customer connectivity to
Microsoft cloud services through partner internet service providers.

## Key capabilities

- **Optimized routing:** Routes traffic to Microsoft over partner networks.
- **Prefix registration:** Registers customer IP prefixes with a connection provider.
- **Monitoring:** Monitors latency and routing for registered prefixes.
