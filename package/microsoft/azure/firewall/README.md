# Azure Firewall

Azure Firewall is a Microsoft Azure managed, cloud-based network firewall service.

## Key capabilities

- **Network and application rules:** Filters traffic by IP, port, FQDN and protocol.
- **Threat intelligence:** Blocks traffic to known malicious IPs and domains.
- **Premium features:** Adds TLS inspection, IDPS and URL filtering in Premium.
- **Central management:** Manages policies with Azure Firewall Manager.
