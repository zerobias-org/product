# Azure IoT Central

Azure IoT Central is a managed IoT application platform from Microsoft Azure. It lets you connect,
monitor and manage IoT devices without building the underlying cloud infrastructure.

## Key capabilities

- **Device connectivity:** Connects devices using device templates that describe their capabilities.
- **Monitoring:** Shows device telemetry and properties in dashboards and applies rules to it.
- **Device management:** Manages devices at scale with jobs, commands and property updates.
- **Data export:** Exports device data to other Azure services and external destinations.
