# Azure Service Bus

Azure Service Bus is a managed enterprise message broker from Microsoft Azure, with message queues
and publish-subscribe topics.

## Key capabilities

- **Queues:** Delivers messages to one consumer in order.
- **Topics and subscriptions:** Delivers messages to multiple subscribers.
- **Advanced features:** Supports sessions, dead-lettering, scheduled delivery and transactions.
- **Security:** Supports Microsoft Entra ID, private endpoints and encryption.
