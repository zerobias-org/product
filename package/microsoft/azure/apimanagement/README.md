# Azure API Management

Azure API Management is a Microsoft Azure service for publishing, securing and managing APIs.

## Key capabilities

- **API gateway:** Routes API calls to backends and enforces policies.
- **Policies:** Applies rate limits, authentication and transformations.
- **Developer portal:** Publishes API documentation for developers.
- **Analytics:** Monitors API usage and performance.
