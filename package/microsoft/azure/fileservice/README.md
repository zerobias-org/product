# Azure Files

Azure Files is a Microsoft Azure service for fully managed file shares accessed over SMB, NFS and
REST.

## Key capabilities

- **File shares:** Provides SMB and NFS file shares in the cloud.
- **Azure File Sync:** Caches Azure file shares on Windows servers.
- **Identity-based access:** Supports Active Directory and Microsoft Entra authentication.
- **Backup:** Protects shares with snapshots and Azure Backup.
