# Azure Stack Edge and Azure Data Box Gateway

Azure Stack Edge (formerly Data Box Edge) is a Microsoft Azure edge computing appliance, and Azure
Data Box Gateway is a virtual appliance for transferring data to Azure. Both are managed through the
Microsoft.DataBoxEdge resource provider.

## Key capabilities

- **Edge compute:** Runs containers, VMs and AI inference on Azure Stack Edge hardware.
- **Network data transfer:** Moves data to Azure storage over the network.
- **Local shares:** Exposes SMB and NFS shares that upload to Azure.
- **Azure management:** Manages devices from the Azure portal.
