# Azure Service Fabric

Azure Service Fabric is a distributed systems platform from Microsoft for packaging, deploying and
managing microservices and containers.

## Key capabilities

- **Microservices:** Runs stateless and stateful services.
- **Clusters:** Runs on Azure, on-premises or other clouds.
- **Managed clusters:** Offers a managed cluster resource type on Azure.
- **Lifecycle management:** Handles rolling upgrades, health checks and failover.
