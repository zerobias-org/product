# Azure Lab Services

Azure Lab Services is a Microsoft Azure service for creating managed lab environments of virtual
machines, used for classes, training and hackathons.

## Key capabilities

- **Lab plans:** Defines the settings and resources that labs are created from.
- **Template VMs:** Builds a template virtual machine that is copied to each lab user.
- **Cost control:** Limits usage with schedules, quotas and automatic shutdown.
- **User management:** Invites users to labs and assigns them virtual machines.
