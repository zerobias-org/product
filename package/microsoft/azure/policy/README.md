# Azure Policy

Azure Policy is a Microsoft Azure governance service that evaluates resources against rules and
enforces organizational standards.

## Key capabilities

- **Policy definitions:** Describes rules with built-in or custom policy definitions.
- **Initiatives:** Groups related policies, including regulatory compliance initiatives.
- **Compliance reporting:** Reports the compliance state of resources.
- **Remediation:** Fixes non-compliant resources with remediation tasks.
