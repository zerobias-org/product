# Azure Machine Learning

Azure Machine Learning is a Microsoft Azure service for building, training, deploying and managing
machine learning models.

## Key capabilities

- **Workspaces:** Organizes data, compute, experiments and models in a workspace.
- **Training:** Trains models on managed compute, including automated ML.
- **Deployment:** Deploys models to managed online and batch endpoints.
- **MLOps:** Tracks models and runs, and supports pipelines for repeatable workflows.
