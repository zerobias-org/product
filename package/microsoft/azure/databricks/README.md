# Azure Databricks

Azure Databricks is a data analytics and AI platform on Microsoft Azure, built on the Databricks
platform and Apache Spark.

## Key capabilities

- **Spark processing:** Runs data engineering and analytics on Apache Spark.
- **Lakehouse:** Stores data in Delta Lake tables.
- **Unity Catalog:** Governs data and AI assets.
- **Machine learning:** Builds and serves machine learning models.
