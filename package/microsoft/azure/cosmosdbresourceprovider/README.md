# Azure Cosmos DB

Azure Cosmos DB is a Microsoft Azure fully managed NoSQL and relational database service. This
package covers the Cosmos DB resource provider (management) API.

## Key capabilities

- **Multiple APIs:** Supports NoSQL, MongoDB, Apache Cassandra, Gremlin and Table APIs.
- **Global distribution:** Replicates data across Azure regions.
- **Scaling:** Scales throughput and storage, including serverless mode.
- **Consistency levels:** Offers five consistency levels.
