# Apache Spark in Azure HDInsight

Apache Spark in Azure HDInsight is the Microsoft Azure managed Apache Spark cluster type on
HDInsight.

## Key capabilities

- **Spark clusters:** Runs managed Apache Spark clusters.
- **Notebooks:** Supports Jupyter and Zeppelin notebooks.
- **Livy:** Submits jobs through the Apache Livy REST API.
- **Storage:** Reads and writes Azure Storage and Data Lake Storage Gen2.
