# Azure Maintenance Configurations

Maintenance Configurations is a Microsoft Azure feature that lets you control when platform and
guest updates are applied to virtual machines and other resources.

## Key capabilities

- **Maintenance windows:** Schedules updates in a defined maintenance window.
- **Scopes:** Covers host, OS image and guest updates.
- **Assignments:** Assigns a configuration to individual resources or by dynamic scope.
- **Update tracking:** Reports the status of applied updates.
