# Azure Database for PostgreSQL

Azure Database for PostgreSQL is a managed PostgreSQL database service from Microsoft Azure, based
on the community edition of PostgreSQL.

## Key capabilities

- **Flexible server:** Runs PostgreSQL with control over configuration and maintenance.
- **High availability:** Offers zone-redundant and same-zone high availability.
- **Backup and restore:** Takes automatic backups with point-in-time restore.
- **Authentication:** Supports PostgreSQL and Microsoft Entra authentication.
