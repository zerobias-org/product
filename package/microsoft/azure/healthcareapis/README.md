# Azure Health Data Services

Azure Health Data Services is a Microsoft Azure set of managed services for health data in FHIR and
DICOM formats. It uses the Microsoft.HealthcareApis resource provider.

## Key capabilities

- **FHIR service:** Stores and exchanges clinical data with the FHIR standard.
- **DICOM service:** Stores and accesses medical imaging data.
- **MedTech service:** Ingests data from medical devices into FHIR.
- **Security:** Uses Microsoft Entra ID and Azure RBAC for access.
