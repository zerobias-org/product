# Azure Cache for Redis

Azure Cache for Redis is a managed in-memory data store from Microsoft Azure, based on Redis.

## Key capabilities

- **Caching:** Provides a low-latency cache for application data and sessions.
- **Tiers:** Offers Basic, Standard, Premium and Enterprise tiers.
- **Network isolation:** Supports private endpoints and virtual network deployment.
- **Persistence and replication:** Supports data persistence and geo-replication in higher tiers.
