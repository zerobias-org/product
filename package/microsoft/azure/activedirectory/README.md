# Microsoft Entra ID

Microsoft Entra ID (formerly Azure Active Directory) is a cloud identity and access management
service from Microsoft. It signs users in and controls access to Microsoft 365, Azure and other
apps.

## Key capabilities

- **Single sign-on:** Signs users in to cloud and on-premises apps.
- **Multifactor authentication:** Adds MFA and passwordless sign-in methods.
- **Conditional Access:** Grants or blocks access based on user, device and risk signals.
- **Identity governance:** Manages access reviews and entitlement lifecycle.
