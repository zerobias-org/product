# Azure HDInsight Kafka REST Proxy

The Kafka REST Proxy is a feature of Apache Kafka clusters on Azure HDInsight. It lets clients
produce and consume Kafka messages over HTTPS.

## Key capabilities

- **REST access:** Produces and consumes Kafka messages over HTTPS.
- **Microsoft Entra authentication:** Authorizes calls with Microsoft Entra ID.
- **Topic operations:** Lists and manages topics through REST.
- **Managed Kafka:** Runs on HDInsight managed Kafka clusters.
