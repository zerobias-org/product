# Azure Kubernetes Service (AKS)

Azure Kubernetes Service (AKS) is a managed Kubernetes service from Microsoft Azure. Azure runs the
Kubernetes control plane; customers run workloads on node pools.

## Key capabilities

- **Managed control plane:** Runs and upgrades the Kubernetes control plane.
- **Node pools:** Runs workloads on Linux and Windows node pools with autoscaling.
- **Identity:** Integrates with Microsoft Entra ID and Azure RBAC.
- **Networking:** Supports Azure CNI networking and network policies.
