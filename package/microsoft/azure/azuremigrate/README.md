# Azure Catalyst

Azure Catalyst (formerly Azure Migrate) is a Microsoft Azure service for discovering, assessing,
migrating and modernizing workloads. Existing Azure Migrate projects continue to work in Azure
Catalyst.

## Key capabilities

- **Discovery:** Discovers servers, applications and databases and maps dependencies.
- **Assessment:** Assesses readiness, sizing and cost in Azure.
- **Planning:** Plans migration waves and target architectures.
- **Migration and modernization:** Migrates servers and databases and modernizes code with GitHub
  Copilot.
