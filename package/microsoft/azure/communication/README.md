# Azure Communication Services

Azure Communication Services is a Microsoft Azure platform of APIs for adding voice, video, chat,
SMS and email to applications.

## Key capabilities

- **Voice and video:** Adds calling and video to apps.
- **Chat:** Adds real-time chat.
- **SMS and email:** Sends SMS and email messages.
- **Phone numbers:** Provisions phone numbers for calls and SMS.
