# Azure IoT Hub Device Provisioning Service

The Azure IoT Hub Device Provisioning Service (DPS) is a helper service for Azure IoT Hub from
Microsoft Azure. It provisions devices to the right IoT hub without manual setup.

## Key capabilities

- **Zero-touch provisioning:** Registers devices with an IoT hub on first connection.
- **Attestation:** Authenticates devices with X.509 certificates, TPM or symmetric keys.
- **Enrollments:** Groups devices into individual and group enrollments.
- **Allocation policies:** Assigns devices across multiple IoT hubs by policy.
