# Azure Front Door

Azure Front Door is a Microsoft Azure global content delivery network (CDN) and application delivery
service.

## Key capabilities

- **Global load balancing:** Routes users to the fastest available backend.
- **CDN:** Caches content at edge locations.
- **Web Application Firewall:** Protects apps with WAF policies.
- **Private Link origins:** Connects to origins through Private Link in Premium.
