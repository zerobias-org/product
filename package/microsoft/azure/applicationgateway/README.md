# Azure Application Gateway

Azure Application Gateway is a Microsoft Azure web traffic load balancer that works at the
application layer (layer 7).

## Key capabilities

- **Layer 7 load balancing:** Routes requests by URL path and host header.
- **Web Application Firewall:** Protects web apps with an optional WAF.
- **TLS termination:** Terminates TLS and supports end-to-end TLS.
- **Autoscaling:** Scales with traffic load.
