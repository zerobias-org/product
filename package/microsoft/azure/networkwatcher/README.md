# Azure Network Watcher

Azure Network Watcher is a Microsoft Azure service with tools to monitor, diagnose and view metrics
for resources in an Azure virtual network.

## Key capabilities

- **Connection troubleshooting:** Tests connectivity between resources.
- **Flow logs:** Logs IP traffic through network security groups and virtual networks.
- **Packet capture:** Captures packets on virtual machines.
- **Topology:** Shows the resources in a virtual network and their relationships.
