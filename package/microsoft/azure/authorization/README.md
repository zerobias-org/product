# Azure role-based access control (Azure RBAC)

Azure role-based access control (Azure RBAC) is the Microsoft Azure authorization system for
managing who can access Azure resources and what they can do.

## Key capabilities

- **Role assignments:** Assigns roles to users, groups and service principals at a scope.
- **Built-in and custom roles:** Provides built-in roles and supports custom role definitions.
- **Deny assignments:** Blocks specific actions even when a role grants them.
- **Scopes:** Applies at management group, subscription, resource group and resource level.
