# Azure Resource Health

Azure Resource Health is part of Azure Service Health from Microsoft. It reports the current and
past health of individual Azure resources.

## Key capabilities

- **Health status:** Shows whether a resource is available, unavailable, degraded or unknown.
- **History:** Keeps a history of health events for a resource.
- **Alerts:** Sends alerts when resource health changes.
