# Azure Compute (Microsoft.Compute)

Microsoft.Compute is the Microsoft Azure resource provider for compute resources such as virtual
machines, virtual machine scale sets and managed disks.

## Key capabilities

- **Virtual machines:** Creates and manages Windows and Linux VMs.
- **Scale sets:** Runs groups of identical VMs that scale automatically.
- **Managed disks:** Provides block storage for VMs.
- **Images and galleries:** Shares VM images through Azure Compute Gallery.
