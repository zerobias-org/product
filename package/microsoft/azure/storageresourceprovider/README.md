# Azure Storage resource provider

The Azure Storage resource provider (Microsoft.Storage) is the Microsoft Azure management API for
storage accounts and their services.

## Key capabilities

- **Storage accounts:** Creates, updates and deletes storage accounts.
- **Keys and access:** Manages account keys, network rules and encryption settings.
- **Blob containers:** Manages containers, legal holds and immutability policies.
- **File shares, queues and tables:** Manages the other storage services in an account.
