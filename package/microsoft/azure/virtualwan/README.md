# Azure Virtual WAN

Azure Virtual WAN is a Microsoft Azure networking service that brings networking, security and
routing together in a hub-and-spoke architecture.

## Key capabilities

- **Virtual hubs:** Provides Microsoft-managed hubs in Azure regions.
- **Connectivity:** Combines site-to-site VPN, point-to-site VPN and ExpressRoute.
- **Routing:** Routes traffic between branches, virtual networks and users.
- **Security:** Integrates Azure Firewall through secured virtual hubs.
