# Azure Database for MySQL

Azure Database for MySQL is a managed MySQL database service from Microsoft Azure, based on the
MySQL Community Edition.

## Key capabilities

- **Flexible server:** Runs MySQL with control over configuration and maintenance windows.
- **High availability:** Offers zone-redundant and same-zone high availability.
- **Backup and restore:** Takes automatic backups with point-in-time restore.
- **Network security:** Supports private access through virtual networks and firewall rules.
