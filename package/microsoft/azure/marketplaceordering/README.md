# Azure Marketplace Ordering

Marketplace Ordering is a Microsoft Azure API (Microsoft.MarketplaceOrdering) for viewing and
accepting the legal terms of Azure Marketplace offers before deploying them programmatically.

## Key capabilities

- **Agreement terms:** Gets the marketplace terms for a publisher, offer and plan.
- **Accept and cancel:** Signs or cancels agreement terms for a subscription.
- **Programmatic deployment:** Enables deploying Marketplace images through the API and tools.
