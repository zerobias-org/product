# Microsoft Graph

Microsoft Graph is a single REST API endpoint from Microsoft for data and services across Microsoft
365, Microsoft Entra ID, Windows and Enterprise Mobility + Security.

## Key capabilities

- **Unified endpoint:** Exposes users, groups, mail, calendars, files and more at one endpoint.
- **Identity and access:** Manages Microsoft Entra users, groups, apps and directory roles.
- **Change notifications:** Notifies apps when resources change.
- **SDKs:** Provides SDKs for common programming languages.
