# Azure Maps

Azure Maps is a Microsoft Azure service that provides geospatial APIs and SDKs for adding maps,
search, routing and location data to applications.

## Key capabilities

- **Map rendering:** Provides map tiles and web and mobile map controls.
- **Search:** Geocodes addresses and searches for points of interest.
- **Routing:** Calculates routes and travel times.
- **Authentication:** Supports Microsoft Entra ID, shared keys and SAS tokens.
