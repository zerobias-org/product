# Azure Traffic Manager

Azure Traffic Manager is a DNS-based traffic load balancer from Microsoft Azure that distributes
traffic across global Azure regions and external endpoints.

## Key capabilities

- **Routing methods:** Routes by priority, weight, performance, geography, subnet or multivalue.
- **Endpoint monitoring:** Checks endpoint health and fails over automatically.
- **Endpoint types:** Supports Azure, external and nested endpoints.
