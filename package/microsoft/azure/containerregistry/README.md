# Azure Container Registry

Azure Container Registry is a Microsoft Azure private registry for container images and OCI
artifacts.

## Key capabilities

- **Private registry:** Stores container images, Helm charts and OCI artifacts.
- **Geo-replication:** Replicates registries across regions.
- **ACR Tasks:** Builds and patches images in Azure.
- **Access control:** Controls access with Microsoft Entra ID and Azure RBAC.
