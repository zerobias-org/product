# Azure Stream Analytics

Azure Stream Analytics is a managed real-time stream processing service from Microsoft Azure.

## Key capabilities

- **SQL queries:** Processes streaming data with a SQL-based query language.
- **Inputs and outputs:** Reads from Event Hubs and IoT Hub and writes to many Azure services.
- **Windowing:** Supports tumbling, hopping, sliding and session windows.
