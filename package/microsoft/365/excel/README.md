# Microsoft Excel

Microsoft Excel is a spreadsheet application from Microsoft, part of Microsoft 365. It runs on
desktop, web and mobile.

## Key capabilities

- **Spreadsheets:** Organizes data in workbooks with formulas and functions.
- **Analysis:** Analyzes data with PivotTables, charts and Power Query.
- **Co-authoring:** Lets several people edit a workbook at the same time.
- **Automation:** Automates tasks with VBA macros and Office Scripts.
