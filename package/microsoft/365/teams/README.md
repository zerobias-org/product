# Microsoft Teams

Microsoft Teams is a collaboration app from Microsoft, part of Microsoft 365. It combines chat,
meetings, calling and file sharing.

## Key capabilities

- **Chat:** Supports one-to-one, group and channel chat.
- **Meetings:** Hosts online meetings and webinars.
- **Calling:** Provides phone calling through Teams Phone.
- **Apps:** Extends Teams with apps, bots and workflows.
