# Microsoft OneDrive

Microsoft OneDrive is a cloud file storage service from Microsoft, part of Microsoft 365. It stores,
syncs and shares files across devices.

## Key capabilities

- **File storage:** Stores files in the cloud.
- **Sync:** Syncs files between the cloud and Windows, macOS and mobile devices.
- **Sharing:** Shares files and folders with links and permissions.
- **Admin controls:** Gives admins sharing, sync and retention controls.
