# Microsoft SharePoint

Microsoft SharePoint is a content management and collaboration service from Microsoft, part of
Microsoft 365. Organizations use it to build sites and store and share documents.

## Key capabilities

- **Sites:** Builds team and communication sites.
- **Document libraries:** Stores documents with versioning and metadata.
- **Permissions:** Controls access to sites, libraries and items.
- **Integration:** Underlies file storage in Microsoft Teams.
