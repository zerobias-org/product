# Microsoft Defender XDR

Microsoft Defender XDR is an extended detection and response suite from Microsoft, part of the
Microsoft Defender family. It coordinates detection and response across endpoints, identities, email
and apps.

## Key capabilities

- **Unified incidents:** Correlates alerts from Defender products into incidents.
- **Advanced hunting:** Hunts across data with KQL queries.
- **Automated investigation:** Investigates and remediates threats automatically.
- **Coverage:** Includes Defender for Endpoint, Office 365, Identity and Cloud Apps.
