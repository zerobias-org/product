# Active Directory Domain Services

Active Directory Domain Services (AD DS) is the directory service in Windows Server from Microsoft.
It stores information about users, computers and other objects on a network.

## Key capabilities

- **Directory:** Stores objects such as users, groups and computers in a hierarchical structure.
- **Authentication:** Authenticates users and computers with Kerberos and NTLM.
- **Group Policy:** Applies configuration and security settings to domain members.
- **Replication:** Replicates directory data between domain controllers.
