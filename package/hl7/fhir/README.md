# HL7 FHIR

HL7 FHIR (Fast Healthcare Interoperability Resources) is a standard from Health Level Seven
International (HL7) for exchanging healthcare information electronically.

## Key capabilities

- **Resources:** Defines resource types for clinical, administrative and infrastructure data.
- **RESTful API:** Specifies a RESTful API for reading and writing resources.
- **Data formats:** Represents resources in JSON, XML and RDF.
- **Profiles:** Lets implementers constrain and extend resources for specific uses.
