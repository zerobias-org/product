# Sophos Firewall

Sophos Firewall is a next-generation firewall from Sophos. It is available as hardware, virtual and
cloud appliances.

## Key capabilities

- **Network protection:** Filters traffic with firewall rules and intrusion prevention.
- **Web and app control:** Controls web access and application use.
- **VPN:** Provides site-to-site and remote access VPN.
- **Central management:** Can be managed through Sophos Central.
