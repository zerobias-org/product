# ProCuity

ProCuity (LEX and ZX) is a family of smart, connected hospital bed systems from Stryker for
medical-surgical (MedSurg) care.

## Key capabilities

- **Fall prevention:** Supports fall-prevention protocols, including low bed heights.
- **Electric brakes:** Sets brakes from the touchscreen or siderails.
- **Connectivity:** Connects to hospital clinical systems.
- **Scalability:** The ZX model can be upgraded toward ICU use.
