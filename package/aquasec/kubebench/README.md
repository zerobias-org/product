# kube-bench

kube-bench is an open source tool from Aqua Security. It checks whether Kubernetes is deployed
securely by running the checks in the CIS Kubernetes Benchmark.

## Key capabilities

- **CIS Benchmark checks:** Runs checks from the CIS Kubernetes Benchmark against cluster nodes.
- **Version detection:** Selects the benchmark version that matches the Kubernetes version.
- **Flexible deployment:** Runs as a binary, a container or a Kubernetes job.
- **Reports:** Outputs results as text or JSON.
