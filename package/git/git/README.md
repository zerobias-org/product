# Git

Git is a free and open source distributed version control system.

## Key capabilities

- **Distributed repositories:** Gives every clone the full project history.
- **Branching and merging:** Supports lightweight branches and merges.
- **Data integrity:** Identifies content by cryptographic hashes.
- **Staging area:** Lets users choose which changes go into a commit.
