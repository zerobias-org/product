# Cryptographic Module Validation Program

The Cryptographic Module Validation Program (CMVP) is a joint program of NIST and the Canadian
Centre for Cyber Security. It validates cryptographic modules against FIPS 140-2 and FIPS 140-3.

## Key capabilities

- **Module validation:** Validates cryptographic modules tested by accredited laboratories.
- **Validated modules list:** Publishes certificates for validated modules.
- **Modules in process:** Lists modules currently in the validation process.
