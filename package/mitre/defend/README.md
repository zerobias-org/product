# MITRE D3FEND

MITRE D3FEND is a knowledge graph of cybersecurity countermeasure techniques. It aims to standardize
the vocabulary used to describe defensive cybersecurity functions.

## Key capabilities

- **Countermeasure techniques:** Catalogs defensive techniques by tactic.
- **Digital artifacts:** Models the artifacts that defensive and offensive techniques act on.
- **ATT&CK mapping:** Relates defensive techniques to MITRE ATT&CK techniques.
- **Ontology:** Publishes the knowledge graph as an ontology for reuse.
