# CAPEC

Common Attack Pattern Enumeration and Classification (CAPEC) is a catalog of common attack patterns
maintained by MITRE.

## Key capabilities

- **Attack patterns:** Describes how adversaries exploit known weaknesses.
- **Views:** Organizes patterns by mechanism of attack and by domain.
- **CWE mapping:** Links attack patterns to related CWE weaknesses.
- **Downloads:** Publishes the catalog in XML and CSV formats.
