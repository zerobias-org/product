# MITRE ATT&CK

MITRE ATT&CK is a globally accessible knowledge base of adversary tactics and techniques based on
real-world observations, maintained by MITRE.

## Key capabilities

- **Matrices:** Covers Enterprise, Mobile and ICS environments.
- **Tactics and techniques:** Describes adversary goals and the techniques used to reach them.
- **Groups and software:** Documents threat groups and the software they use.
- **Mitigations and detections:** Lists mitigations and detection guidance per technique.
