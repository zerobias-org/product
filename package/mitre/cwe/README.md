# CWE

Common Weakness Enumeration (CWE) is a community-developed list of software and hardware weakness
types, maintained by MITRE.

## Key capabilities

- **Weakness catalog:** Defines software and hardware weakness types with IDs.
- **Views:** Groups weaknesses by research concepts, development concepts and more.
- **Top 25:** Publishes a list of the most dangerous software weaknesses.
- **Downloads:** Publishes the list in XML and CSV formats.
