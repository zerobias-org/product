# Box Platform

Box Platform is the developer platform from Box. It gives applications API access to content stored
in Box.

## Key capabilities

- **Content API:** Manages files, folders and metadata through REST APIs.
- **SDKs:** Provides SDKs for common programming languages.
- **Authentication:** Supports OAuth 2.0, JWT and client credentials authentication.
- **Webhooks:** Notifies applications about changes to content.
