# Rippling

Rippling is a workforce management platform. It manages HR, IT and finance tasks for employees in
one system.

## Key capabilities

- **HR and payroll:** Runs payroll, benefits and HR records.
- **IT management:** Manages employee devices and app access.
- **Spend management:** Handles expenses and corporate cards.
- **APIs:** Offers developer APIs for integrations.
