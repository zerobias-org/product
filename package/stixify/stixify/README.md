# Stixify

Stixify is a threat intelligence tool from DOGESEC. It extracts machine-readable intelligence from
unstructured threat reports.

## Key capabilities

- **Extraction:** Extracts indicators of compromise (IoCs) and TTPs from uploaded reports.
- **STIX 2.1 output:** Stores extracted intelligence as STIX 2.1 objects.
- **ATT&CK mapping:** Maps report content to MITRE ATT&CK and Attack Flow.
- **APIs:** Offers a REST API and a TAXII 2.1 API.
