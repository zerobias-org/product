# Chainguard

Chainguard offers a set of software supply chain security products, including Chainguard Containers
and Chainguard Libraries.

## Key capabilities

- **Chainguard Containers:** Provides minimal, hardened container images.
- **Chainguard Libraries:** Provides a vetted catalog of open source language packages.
- **Chainguard Actions:** Provides hardened CI/CD actions.
