# N-able N-central

N-central is a remote monitoring and management (RMM) platform from N-able. Managed service
providers and IT teams use it to monitor, manage and secure devices.

## Key capabilities

- **Monitoring:** Monitors servers, workstations and network devices.
- **Automation:** Automates maintenance tasks with scripts and policies.
- **Patch management:** Manages operating system and third-party patches.
- **Remote control:** Provides remote access to managed devices.
