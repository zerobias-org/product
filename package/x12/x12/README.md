# X12

X12 is a set of electronic data interchange (EDI) standards from the Accredited Standards Committee
X12 (ASC X12). The standards include the healthcare transactions used under HIPAA.

## Key capabilities

- **EDI transactions:** Defines standard transaction sets for exchanging business documents.
- **Healthcare transactions:** Includes claims (837), remittance (835) and other HIPAA transactions.
- **Code lists:** Maintains external code lists such as claim adjustment reason codes.
