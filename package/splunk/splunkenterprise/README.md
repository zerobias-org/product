# Splunk Enterprise

Splunk Enterprise is a self-managed platform from Splunk, a Cisco company, for searching, monitoring
and analyzing machine data.

## Key capabilities

- **Data ingestion:** Collects and indexes logs and other machine data.
- **Search:** Searches and analyzes data with the Search Processing Language (SPL).
- **Dashboards and alerts:** Builds dashboards, reports and alerts.
- **Apps:** Extends functionality with apps and add-ons.
