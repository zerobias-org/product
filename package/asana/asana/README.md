# Asana

Asana is a work management platform from Asana, Inc. Teams use it to plan, organize and track
projects and tasks.

## Key capabilities

- **Tasks and projects:** Organizes work as tasks in projects with list, board, timeline and
  calendar views.
- **Portfolios and goals:** Tracks groups of projects and organizational goals.
- **Workflow automation:** Automates routine steps with rules.
- **API:** Provides a REST API for integrations.
