# DNSimple

DNSimple is a domain registration and DNS hosting service from DNSimple.

## Key capabilities

- **Domain registration:** Registers and renews domain names.
- **DNS hosting:** Hosts authoritative DNS records.
- **SSL certificates:** Issues SSL/TLS certificates.
- **API:** Provides an API for automating domain and DNS management.
