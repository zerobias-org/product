# IBM Targetprocess

IBM Targetprocess (formerly Apptio Targetprocess) is an enterprise agile planning tool from Apptio,
an IBM company.

## Key capabilities

- **Portfolio planning:** Plans and tracks work across portfolios, programs and teams.
- **Agile scaling:** Supports scaled agile practices across many teams.
- **Financial integration:** Connects planned work with technology spend data from Apptio.
- **Resource management:** Plans team capacity against demand.
