# ClickUp

ClickUp is a work management and productivity platform from ClickUp.

## Key capabilities

- **Tasks and projects:** Organizes work into spaces, folders, lists and tasks.
- **Views:** Shows work as lists, boards, calendars, Gantt charts and more.
- **Docs:** Includes collaborative documents.
- **API:** Provides a public API.
