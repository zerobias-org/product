# Ivanti Neurons for Discovery

Ivanti Neurons for Discovery is an IT asset discovery product from Ivanti. It finds hardware and
software across a network and builds an inventory of assets.

## Key capabilities

- **Asset discovery:** Discovers devices using active scans, passive scans and agents.
- **Inventory:** Builds a normalized inventory of hardware and software.
- **Service mapping:** Maps relationships between assets and services.
- **Integrations:** Feeds discovered asset data to Ivanti service and asset management tools.
