# VMware vSphere

VMware vSphere is a server virtualization platform from Broadcom, part of VMware's cloud
infrastructure portfolio. It combines the ESXi hypervisor with vCenter management.

## Key capabilities

- **Virtualization:** Runs virtual machines on the ESXi hypervisor.
- **Central management:** Manages hosts and VMs with vCenter.
- **Availability:** Provides features such as vMotion and High Availability.
