# VMware vCenter

VMware vCenter is the centralized management server for VMware vSphere environments. It is a
Broadcom product, part of VMware's cloud infrastructure portfolio.

## Key capabilities

- **Central management:** Manages ESXi hosts and virtual machines from one place.
- **Resource management:** Pools resources into clusters with features such as DRS and HA.
- **Access control:** Controls access with roles and permissions.
- **APIs:** Offers APIs for automation.
