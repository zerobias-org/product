# Omnissa Workspace ONE

Omnissa Workspace ONE (formerly VMware Workspace ONE) is a digital workspace platform from Omnissa.
It manages devices and gives employees access to apps.

## Key capabilities

- **Unified endpoint management:** Manages mobile devices, desktops and other endpoints.
- **App access:** Gives users a catalog of apps with single sign-on.
- **Security:** Applies access and compliance policies to devices.
