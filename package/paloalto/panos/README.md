# PAN-OS

PAN-OS is the operating system that runs Palo Alto Networks next-generation firewalls. It runs on
hardware firewalls and on virtual and cloud firewalls.

## Key capabilities

- **App-ID:** Identifies applications in traffic regardless of port or protocol.
- **User-ID:** Applies policy based on users and groups.
- **Threat prevention:** Inspects traffic for threats through security subscriptions.
- **Central management:** Can be managed with Panorama or Strata Cloud Manager.
