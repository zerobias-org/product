# Datadog

Datadog is a monitoring and security platform for cloud applications from Datadog, Inc.

## Key capabilities

- **Infrastructure monitoring:** Collects metrics from hosts, containers and cloud services.
- **APM and tracing:** Traces requests across applications.
- **Log management:** Collects, searches and analyzes logs.
- **Security:** Provides cloud security and SIEM products.
- **Integrations:** Offers integrations with many technologies.
