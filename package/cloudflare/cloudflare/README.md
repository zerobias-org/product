# Cloudflare

Cloudflare is a connectivity cloud platform from Cloudflare, Inc. It provides network, security and
performance services delivered from Cloudflare's global network.

## Key capabilities

- **CDN and DNS:** Caches content and provides authoritative DNS.
- **Application security:** Provides DDoS protection, a web application firewall and bot management.
- **Zero Trust:** Provides access control and secure web gateway services.
- **Developer platform:** Runs code and stores data with Cloudflare Workers and related services.
