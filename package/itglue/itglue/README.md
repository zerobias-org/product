# IT Glue

IT Glue is IT documentation software for IT teams and managed service providers (MSPs). It stores
configurations, passwords, procedures and relationships between IT assets.

## Key capabilities

- **Documentation:** Stores standard procedures, configurations and asset records.
- **Password management:** Keeps shared credentials with access controls.
- **Relationships:** Links related assets, contacts and documents.
- **REST API:** Exposes documentation data through a REST API.
