# Anchore Enterprise

Anchore Enterprise is a software supply chain security platform from Anchore. It is built around
software bills of materials (SBOMs).

## Key capabilities

- **SBOM management:** Generates, imports and stores SBOMs for source code and container images.
- **Vulnerability scanning:** Scans SBOMs for vulnerabilities, secrets and malware.
- **Policy enforcement:** Applies policy checks in build pipelines, including policy packs for NIST,
  FedRAMP and DISA requirements.
- **API:** Exposes its functions through an API.
