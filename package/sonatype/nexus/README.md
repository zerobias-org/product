# Sonatype Nexus Repository

Sonatype Nexus Repository is an artifact repository manager from Sonatype. It stores and proxies
build artifacts and packages.

## Key capabilities

- **Artifact storage:** Hosts private build artifacts and components.
- **Proxying:** Caches components from public repositories.
- **Many formats:** Supports formats such as Maven, npm, PyPI, NuGet and Docker.
