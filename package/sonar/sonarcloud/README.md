# SonarQube Cloud

SonarQube Cloud (formerly SonarCloud) is a cloud-based code quality and security analysis service
from Sonar (SonarSource).

## Key capabilities

- **Static analysis:** Finds bugs, code smells and vulnerabilities in many languages.
- **Quality gates:** Blocks merges or releases that fail quality conditions.
- **Pull request analysis:** Analyzes pull requests in common DevOps platforms.
