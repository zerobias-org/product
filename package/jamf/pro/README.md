# Jamf Pro

Jamf Pro is an Apple device management product from Jamf. It manages Mac, iPhone, iPad and Apple TV
devices for organizations.

## Key capabilities

- **Device management:** Enrolls and configures Apple devices with configuration profiles.
- **Inventory:** Collects hardware and software inventory from managed devices.
- **Software deployment:** Deploys apps, packages, scripts and OS updates.
- **Self Service:** Gives users a portal to install approved apps.
- **APIs:** Exposes management data through the Jamf Pro API and Classic API.
