# Jamf Now

Jamf Now is a cloud mobile device management (MDM) product from Jamf for small businesses. It
manages iPhone, iPad and Mac devices.

## Key capabilities

- **Device enrollment:** Enrolls Apple devices, including through Apple Business Manager.
- **Configuration:** Applies settings, Wi-Fi and restrictions through blueprints.
- **App deployment:** Distributes apps to managed devices.
- **Security commands:** Locks or wipes lost devices remotely.
