# Jamf Connect

Jamf Connect is a Mac identity and access product from Jamf. It links Mac login to a cloud identity
provider and secures access to work apps.

## Key capabilities

- **Cloud identity login:** Lets users sign in to a Mac with cloud identity provider credentials.
- **Account provisioning:** Creates local Mac accounts from identity provider accounts.
- **Password sync:** Keeps the local password in sync with the identity provider password.
- **Zero Trust access:** Controls access to work apps based on device and user.
