# Snowflake

Snowflake is a cloud data platform from Snowflake Inc. It is delivered as a service and runs on
major public clouds.

## Key capabilities

- **Data warehousing:** Stores and queries structured and semi-structured data with SQL.
- **Separate compute and storage:** Scales compute warehouses independently from storage.
- **Data sharing:** Shares data across accounts without copying it.
