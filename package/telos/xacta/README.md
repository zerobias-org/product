# Xacta

Xacta is a cyber governance, risk and compliance (GRC) platform from Telos Corporation. It automates
security compliance work against frameworks such as those from NIST.

## Key capabilities

- **Compliance automation:** Automates assessment and authorization tasks for security frameworks.
- **Continuous monitoring:** Tracks control status and risk over time.
- **Documentation:** Produces compliance documentation and evidence.
- **AI assistance:** Xacta.ai adds AI-assisted compliance features.
