# Hexnode UEM

Hexnode UEM is a unified endpoint management product from Hexnode for managing and securing mobile
devices, desktops and other endpoints.

## Key capabilities

- **Device management:** Enrolls and manages devices on several operating systems.
- **App management:** Installs, updates and restricts apps on managed devices.
- **Security policies:** Applies passcode, restriction and compliance policies.
- **Kiosk mode:** Locks devices to selected apps.
