# AWS IAM Identity Center

AWS IAM Identity Center is a service from Amazon Web Services (AWS) for managing workforce access to
AWS accounts and applications. It was formerly called AWS Single Sign-On.

## Key capabilities

- **Workforce identities:** Creates users or connects an external identity provider.
- **Multi-account access:** Assigns access to accounts in AWS Organizations.
- **Permission sets:** Defines account permissions with permission sets.
- **Application access:** Provides single sign-on to AWS and SAML applications.
