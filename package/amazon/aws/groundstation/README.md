# AWS Ground Station

AWS Ground Station is a managed service from Amazon Web Services (AWS) for communicating with
satellites. It controls satellites and downlinks and processes satellite data.

## Key capabilities

- **Antenna access:** Schedules contacts with AWS-operated ground station antennas.
- **Mission profiles:** Defines how contacts are configured and where data goes.
- **Data delivery:** Delivers satellite data to Amazon EC2 or Amazon S3.
- **Pay per use:** Charges for antenna time used.
