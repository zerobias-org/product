# AWS Global Accelerator

AWS Global Accelerator is a networking service from Amazon Web Services (AWS). It routes user
traffic to applications through the AWS global network.

## Key capabilities

- **Static anycast IPs:** Provides static IP addresses as a fixed entry point to applications.
- **Global routing:** Routes traffic to the closest healthy endpoint.
- **Health checks:** Monitors endpoint health and fails over automatically.
- **Endpoint types:** Supports Application Load Balancers, Network Load Balancers, EC2 instances and
  Elastic IPs.
