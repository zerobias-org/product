# Amazon Redshift Data API

The Amazon Redshift Data API is an API from Amazon Web Services (AWS) for running SQL statements on
Amazon Redshift without managing database connections.

## Key capabilities

- **SQL over HTTPS:** Runs SQL statements through an API call.
- **Asynchronous queries:** Runs statements asynchronously and fetches results later.
- **Authentication:** Authenticates with AWS Secrets Manager or temporary credentials.
- **Serverless support:** Works with provisioned clusters and Redshift Serverless.
