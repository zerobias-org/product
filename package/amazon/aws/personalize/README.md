# Amazon Personalize

Amazon Personalize is a machine learning service from Amazon Web Services (AWS) for building
personalized recommendations.

## Key capabilities

- **Recommendations:** Generates personalized item recommendations.
- **Datasets:** Trains on interaction, user and item data.
- **Real-time events:** Updates recommendations from live user events.
- **Batch inference:** Generates recommendations in batches.
