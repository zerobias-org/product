# AWS Fault Injection Service

AWS Fault Injection Service (AWS FIS) is a managed service from Amazon Web Services (AWS) for
running fault injection experiments on AWS workloads. It was formerly called AWS Fault Injection
Simulator.

## Key capabilities

- **Experiment templates:** Defines actions, targets and stop conditions for experiments.
- **Fault actions:** Injects faults such as stopping instances or adding network latency.
- **Stop conditions:** Stops an experiment when an Amazon CloudWatch alarm is triggered.
- **Access control:** Controls experiments with IAM roles and policies.
