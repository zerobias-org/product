# AWS Audit Manager

AWS Audit Manager is a service from Amazon Web Services (AWS) that continuously audits AWS usage to
help assess risk and compliance with regulations and industry standards.

## Key capabilities

- **Prebuilt frameworks:** Provides frameworks that map AWS resources to standards such as CIS, PCI
  DSS and GDPR.
- **Automated evidence:** Collects evidence from AWS Config, Security Hub, CloudTrail and API calls.
- **Custom frameworks:** Lets you build custom controls and frameworks.
- **Assessment reports:** Generates audit-ready assessment reports.
