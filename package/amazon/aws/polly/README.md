# Amazon Polly

Amazon Polly is a text-to-speech service from Amazon Web Services (AWS).

## Key capabilities

- **Text to speech:** Converts text into speech audio.
- **Voices and languages:** Offers voices in many languages.
- **Voice engines:** Supports standard, neural and generative voices.
- **SSML:** Controls speech output with SSML.
