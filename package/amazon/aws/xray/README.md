# AWS X-Ray

AWS X-Ray is a distributed tracing service from Amazon Web Services (AWS). It collects data about
requests as they travel through an application.

## Key capabilities

- **Tracing:** Records traces of requests across services.
- **Service map:** Shows the services in an application and how they connect.
- **Analytics:** Filters and analyzes traces to find errors and latency.
- **Integrations:** Works with AWS services such as AWS Lambda and Amazon API Gateway.
