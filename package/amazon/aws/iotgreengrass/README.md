# AWS IoT Greengrass

AWS IoT Greengrass is an edge runtime and cloud service from Amazon Web Services (AWS). It builds,
deploys and manages software on IoT devices.

## Key capabilities

- **Edge runtime:** Runs software components on edge devices.
- **Components:** Packages applications as components that can be deployed.
- **Deployments:** Deploys components to devices and groups of devices.
- **Local processing:** Processes data on devices and syncs with the cloud.
