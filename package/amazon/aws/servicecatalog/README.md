# AWS Service Catalog

AWS Service Catalog is a service from Amazon Web Services (AWS) for creating and managing catalogs
of approved IT services, such as AWS CloudFormation templates, for use on AWS.

## Key capabilities

- **Portfolios and products:** Organizes approved products into portfolios shared with users and
  accounts.
- **Constraints:** Limits how products can be launched, for example by launch role or allowed
  parameters.
- **Self-service provisioning:** Lets end users launch approved products themselves.
- **AppRegistry:** Records applications and their associated resources.
