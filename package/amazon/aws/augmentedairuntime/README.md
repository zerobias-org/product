# Amazon Augmented AI

Amazon Augmented AI (Amazon A2I) is a service from Amazon Web Services (AWS) for adding human review
to machine learning predictions. The A2I Runtime API starts and manages human review loops.

## Key capabilities

- **Human review workflows:** Defines workflows that send predictions to human reviewers.
- **Built-in integrations:** Works with Amazon Textract and Amazon Rekognition use cases.
- **Custom workflows:** Supports custom ML models and task types.
- **Reviewer workforces:** Uses a private workforce, vendors or Amazon Mechanical Turk.
