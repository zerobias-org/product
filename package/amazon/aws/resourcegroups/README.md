# AWS Resource Groups

AWS Resource Groups is a service from Amazon Web Services (AWS) for organizing AWS resources into
groups.

## Key capabilities

- **Tag-based groups:** Groups resources that share tags.
- **CloudFormation groups:** Groups resources from a CloudFormation stack.
- **Group operations:** Lets other services act on all resources in a group.
- **Tag Editor:** Finds and tags resources across Regions.
