# AWS CloudHSM

AWS CloudHSM is a service from Amazon Web Services (AWS) that provides dedicated hardware security
modules (HSMs) in the AWS Cloud for generating and using encryption keys.

## Key capabilities

- **Dedicated HSMs:** Provides single-tenant HSMs that you control.
- **FIPS validation:** Uses FIPS 140 validated hardware.
- **Standard APIs:** Supports PKCS #11, JCE and OpenSSL integrations.
- **Clusters:** Groups HSMs into clusters for high availability.
