# AWS DataSync

AWS DataSync is an online data transfer service from Amazon Web Services (AWS). It moves data
between on-premises storage, other clouds and AWS storage services.

## Key capabilities

- **Data transfer:** Copies data to and from services such as Amazon S3, Amazon EFS and Amazon FSx.
- **Agents:** Uses agents to access on-premises and other cloud storage.
- **Data verification:** Verifies data integrity during transfer.
- **Scheduling:** Runs transfer tasks on a schedule.
