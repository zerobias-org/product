# AWS Quick Sight

AWS Quick Sight is a business intelligence service from Amazon Web Services (AWS), part of AWS
Quick. It was formerly called Amazon QuickSight.

## Key capabilities

- **Dashboards:** Builds interactive dashboards and visualizations.
- **Data sources:** Connects to AWS data sources, databases and files.
- **SPICE:** Stores data in the SPICE in-memory engine.
- **Embedding:** Embeds dashboards in applications.
