# AWS HealthLake

AWS HealthLake is a HIPAA-eligible service from Amazon Web Services (AWS) for storing and analyzing
health data in the FHIR format.

## Key capabilities

- **FHIR data stores:** Stores health data in FHIR R4 data stores.
- **FHIR API:** Reads and writes resources through a FHIR REST API.
- **Import and export:** Imports and exports bulk FHIR data from Amazon S3.
- **Encryption:** Encrypts data at rest with AWS KMS keys.
