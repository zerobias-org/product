# AWS Signer

AWS Signer is a code-signing service from Amazon Web Services (AWS). It signs code and container
images so their integrity and origin can be verified.

## Key capabilities

- **Signing profiles:** Defines signing configurations used to sign code.
- **AWS Lambda code signing:** Signs Lambda deployment packages so only trusted code is deployed.
- **Container image signing:** Signs container images for verification before deployment.
- **Revocation:** Revokes signatures and signing profiles.
