# Amazon Elastic Kubernetes Service

Amazon Elastic Kubernetes Service (Amazon EKS) is a managed Kubernetes service from Amazon Web
Services (AWS).

## Key capabilities

- **Managed control plane:** Runs and scales the Kubernetes control plane.
- **Compute options:** Runs workloads on managed node groups, AWS Fargate and other options.
- **Kubernetes conformance:** Runs upstream Kubernetes, compatible with standard tooling.
- **IAM integration:** Maps AWS IAM identities to Kubernetes access.
