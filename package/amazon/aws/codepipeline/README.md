# AWS CodePipeline

AWS CodePipeline is a fully managed continuous delivery service from Amazon Web Services (AWS). It
automates the build, test and deploy stages of release pipelines.

## Key capabilities

- **Pipelines:** Models release processes as stages and actions.
- **Integrations:** Works with CodeBuild, CodeDeploy, CloudFormation and third-party tools.
- **Triggers:** Starts pipelines on source changes.
- **Approvals:** Adds manual approval actions.
