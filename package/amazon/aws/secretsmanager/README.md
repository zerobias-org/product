# AWS Secrets Manager

AWS Secrets Manager is a service from Amazon Web Services (AWS) for storing and managing secrets
such as database credentials and API keys.

## Key capabilities

- **Secret storage:** Stores secrets encrypted with AWS Key Management Service (AWS KMS) keys.
- **Rotation:** Rotates secrets on a schedule, including built-in rotation for supported databases.
- **Access control:** Controls access with IAM and resource-based policies.
- **Auditing:** Records API activity in AWS CloudTrail.
