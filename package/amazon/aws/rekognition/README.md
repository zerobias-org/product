# Amazon Rekognition

Amazon Rekognition is a computer vision service from Amazon Web Services (AWS) for analyzing images
and videos.

## Key capabilities

- **Object and scene detection:** Detects objects, scenes and activities.
- **Face analysis:** Detects, analyzes and compares faces.
- **Content moderation:** Detects inappropriate content.
- **Text detection:** Detects text in images and videos.
