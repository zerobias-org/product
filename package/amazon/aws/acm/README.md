# AWS Certificate Manager

AWS Certificate Manager (ACM) is a service from Amazon Web Services (AWS) that provisions and
manages public and private SSL/TLS certificates for use with AWS services.

## Key capabilities

- **Public certificates:** Issues public SSL/TLS certificates for domains you control.
- **Managed renewal:** Renews ACM-issued certificates automatically.
- **Integrated services:** Deploys certificates to services such as Elastic Load Balancing,
  CloudFront and API Gateway.
- **Certificate import:** Imports certificates issued by third-party certificate authorities.
