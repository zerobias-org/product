# AWS Resource Groups Tagging API

The AWS Resource Groups Tagging API is an API from Amazon Web Services (AWS) for tagging and finding
tagged resources across services.

## Key capabilities

- **Tag resources:** Adds and removes tags on resources across services.
- **Find resources:** Lists resources that match tag filters.
- **Tag keys and values:** Lists tag keys and values in use.
- **Tag policy compliance:** Reports compliance with tag policies.
