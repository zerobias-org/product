# Amazon GameLift Servers

Amazon GameLift Servers is a managed service from Amazon Web Services (AWS) for hosting dedicated
game servers. It was formerly called Amazon GameLift.

## Key capabilities

- **Game server hosting:** Deploys and runs dedicated game servers on managed fleets.
- **Matchmaking:** Groups players into game sessions with FlexMatch.
- **Scaling:** Scales fleet capacity to match player demand.
- **Session placement:** Places game sessions across Regions with queues.
