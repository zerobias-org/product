# AWS Application Discovery Service

AWS Application Discovery Service is a service from Amazon Web Services (AWS) that collects data
about on-premises servers and applications to help plan migrations to AWS. It is no longer open to
new customers.

## Key capabilities

- **Agentless discovery:** Collects server and performance data from VMware environments.
- **Agent-based discovery:** Collects system configuration, performance and network connection data
  with an agent.
- **Dependency mapping:** Shows relationships between servers.
- **Data export:** Exports discovered data for analysis.
