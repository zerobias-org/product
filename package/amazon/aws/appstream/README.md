# Amazon WorkSpaces Applications

Amazon WorkSpaces Applications, formerly Amazon AppStream 2.0, is a fully managed application
streaming service from Amazon Web Services (AWS). It streams desktop applications to users' web
browsers.

## Key capabilities

- **Application streaming:** Streams desktop applications to a web browser without local
  installation.
- **Fleets:** Runs applications on managed fleets of streaming instances.
- **Image builders:** Creates images that contain the applications to stream.
- **Authentication:** Supports SAML 2.0 federation and a user pool.
