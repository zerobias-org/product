# AWS Config

AWS Config is a service from Amazon Web Services (AWS) that records and evaluates the configurations
of AWS resources.

## Key capabilities

- **Configuration recording:** Records resource configurations and changes over time.
- **Config rules:** Evaluates resources against desired configurations.
- **Conformance packs:** Deploys packaged collections of rules and remediation actions.
- **Aggregation:** Aggregates data across accounts and Regions.
