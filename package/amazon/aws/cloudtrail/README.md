# AWS CloudTrail

AWS CloudTrail is a service from Amazon Web Services (AWS) that records user activity and API calls
in AWS accounts for auditing, governance and compliance.

## Key capabilities

- **Event history:** Keeps a viewable history of management events.
- **Trails:** Delivers event logs to Amazon S3 and CloudWatch Logs.
- **CloudTrail Lake:** Stores events in a managed data lake queryable with SQL.
- **Log file integrity:** Validates that log files have not been changed.
- **Insights:** Detects unusual API activity.
