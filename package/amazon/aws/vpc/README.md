# Amazon Virtual Private Cloud

Amazon Virtual Private Cloud (Amazon VPC) is a service from Amazon Web Services (AWS) for launching
AWS resources in a logically isolated virtual network.

## Key capabilities

- **Subnets and routing:** Divides a VPC into subnets with route tables.
- **Security groups and network ACLs:** Filters traffic at the resource and subnet level.
- **Connectivity:** Connects to the internet, other VPCs and on-premises networks through gateways,
  peering and VPN.
- **Flow logs:** Captures information about IP traffic in the VPC.
