# AWS Organizations

AWS Organizations is a service from Amazon Web Services (AWS) for managing multiple AWS accounts
centrally.

## Key capabilities

- **Account management:** Creates and groups accounts into organizational units.
- **Policies:** Applies service control policies and other policy types.
- **Consolidated billing:** Combines billing across accounts.
- **Service integration:** Enables AWS services across the organization.
