# Amazon WorkMail

Amazon WorkMail is a managed business email and calendar service from Amazon Web Services (AWS).

## Key capabilities

- **Email and calendars:** Hosts mailboxes, calendars and contacts.
- **Client support:** Works with desktop and mobile clients, including Microsoft Outlook.
- **Directory integration:** Integrates with AWS Directory Service and Active Directory.
- **Mobile device management:** Applies policies to mobile devices.
