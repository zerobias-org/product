# Amazon Simple Workflow Service

Amazon Simple Workflow Service (Amazon SWF) is a workflow coordination service from Amazon Web
Services (AWS). It tracks the state of tasks run by application components called workers and
deciders.

## Key capabilities

- **Workflow state tracking:** Keeps the execution history and state of each workflow.
- **Task coordination:** Assigns activity tasks to workers and decision tasks to deciders.
- **Timers and signals:** Supports timers and external signals in workflows.
