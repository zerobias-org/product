# AWS Cost Explorer

AWS Cost Explorer is a tool from Amazon Web Services (AWS) for viewing and analyzing AWS costs and
usage. The Cost Explorer API gives programmatic access to the same data.

## Key capabilities

- **Cost and usage reports:** Shows cost and usage data over time with filters and grouping.
- **Forecasting:** Forecasts future costs and usage.
- **Reservation and Savings Plans data:** Reports utilization and coverage and gives purchase
  recommendations.
- **Cost anomaly detection:** Detects unusual spend.
