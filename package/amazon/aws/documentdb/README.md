# Amazon DocumentDB (with MongoDB compatibility)

Amazon DocumentDB (with MongoDB compatibility) is a fully managed JSON document database service
from Amazon Web Services (AWS).

## Key capabilities

- **MongoDB compatibility:** Supports MongoDB APIs, drivers and tools.
- **Storage:** Separates compute from storage that grows automatically.
- **Read replicas:** Scales reads with up to 15 replicas.
- **Backups:** Provides continuous backups with point-in-time recovery.
