# AWS Storage Gateway

AWS Storage Gateway is a hybrid storage service from Amazon Web Services (AWS). It gives on-premises
applications access to storage in AWS.

## Key capabilities

- **Amazon S3 File Gateway:** Stores files as objects in Amazon S3 through NFS and SMB.
- **Tape Gateway:** Presents virtual tapes to backup applications and stores them in AWS.
- **Volume Gateway:** Presents block storage volumes backed by AWS.
- **Local caching:** Caches frequently used data on premises.
