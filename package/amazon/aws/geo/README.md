# Amazon Location Service

Amazon Location Service is a location-based service from Amazon Web Services (AWS). It adds maps,
places, routes and tracking to applications.

## Key capabilities

- **Maps:** Renders interactive maps in applications.
- **Places:** Searches for places and converts addresses to coordinates.
- **Routes:** Calculates routes and travel times.
- **Trackers and geofences:** Tracks device positions and detects geofence events.
