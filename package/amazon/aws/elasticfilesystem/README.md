# Amazon Elastic File System

Amazon Elastic File System (Amazon EFS) is a serverless, elastic file storage service from Amazon
Web Services (AWS) that uses the NFS protocol.

## Key capabilities

- **Shared file storage:** Lets many compute resources access a file system at once.
- **Elastic capacity:** Grows and shrinks storage as files are added and removed.
- **Storage classes:** Offers storage classes with lifecycle management.
- **Encryption:** Encrypts data at rest and in transit.
