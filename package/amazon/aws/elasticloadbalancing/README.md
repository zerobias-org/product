# Elastic Load Balancing (Classic Load Balancer)

Elastic Load Balancing from Amazon Web Services (AWS) distributes incoming traffic across targets.
This package covers the original Elastic Load Balancing API, which manages Classic Load Balancers.

## Key capabilities

- **Traffic distribution:** Distributes traffic across EC2 instances in multiple Availability Zones.
- **Health checks:** Routes traffic only to healthy instances.
- **TLS termination:** Handles SSL/TLS termination.
