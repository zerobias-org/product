# AWS Glue

AWS Glue is a serverless data integration service from Amazon Web Services (AWS). It discovers,
prepares and combines data for analytics and machine learning.

## Key capabilities

- **Data Catalog:** Stores table and schema metadata in the AWS Glue Data Catalog.
- **Crawlers:** Scans data stores and infers schemas.
- **ETL jobs:** Runs extract, transform and load jobs on Apache Spark or Python.
- **Workflows:** Orchestrates crawlers and jobs with triggers and workflows.
