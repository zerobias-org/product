# Amazon Kendra

Amazon Kendra is an intelligent enterprise search service from Amazon Web Services (AWS). It is no
longer open to new customers.

## Key capabilities

- **Natural language search:** Answers natural language questions over indexed content.
- **Connectors:** Indexes content from data sources such as S3, SharePoint and databases.
- **Access control:** Filters search results by user and group access.
- **Retrieval:** Provides a Retrieve API for retrieval augmented generation.
