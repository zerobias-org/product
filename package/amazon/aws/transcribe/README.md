# Amazon Transcribe

Amazon Transcribe is an automatic speech recognition service from Amazon Web Services (AWS) that
converts speech to text.

## Key capabilities

- **Batch and streaming:** Transcribes stored audio files and live audio streams.
- **Speaker identification:** Labels speech from different speakers.
- **Custom vocabularies:** Improves accuracy for domain-specific terms.
- **Content redaction:** Redacts personally identifiable information from transcripts.
