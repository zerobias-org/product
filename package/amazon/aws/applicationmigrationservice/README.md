# AWS Application Migration Service

AWS Application Migration Service (AWS MGN) is a service from Amazon Web Services (AWS) for
lift-and-shift migration of servers and applications to AWS.

## Key capabilities

- **Block-level replication:** Continuously replicates source servers to AWS.
- **Test launches:** Launches test instances before cutover.
- **Cutover:** Launches converted servers natively on Amazon EC2.
- **Broad source support:** Migrates physical, virtual and cloud-based servers.
