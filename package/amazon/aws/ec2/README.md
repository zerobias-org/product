# Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) is a service from Amazon Web Services (AWS) that provides
resizable compute capacity in the cloud as virtual servers called instances.

## Key capabilities

- **Instance types:** Offers many instance types with different CPU, memory, storage and networking.
- **AMIs:** Launches instances from Amazon Machine Images.
- **Networking:** Runs instances in Amazon VPC with security groups.
- **Pricing options:** Supports On-Demand, Spot, Savings Plans and Reserved Instances.
