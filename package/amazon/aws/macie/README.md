# Amazon Macie

Amazon Macie is a data security service from Amazon Web Services (AWS). It discovers sensitive data
in Amazon S3 using machine learning and pattern matching.

## Key capabilities

- **Sensitive data discovery:** Detects sensitive data such as personal information in S3.
- **Bucket inventory:** Evaluates S3 buckets for security and access controls.
- **Custom identifiers:** Supports custom data identifiers.
- **Findings:** Sends findings to AWS Security Hub and Amazon EventBridge.
