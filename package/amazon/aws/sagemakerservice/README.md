# Amazon SageMaker AI

Amazon SageMaker AI (formerly Amazon SageMaker) is a managed machine learning service from Amazon
Web Services (AWS). It is used to build, train and deploy machine learning models.

## Key capabilities

- **Notebooks and studio:** Provides managed development environments for building models.
- **Training:** Runs managed training jobs on AWS compute.
- **Deployment:** Hosts trained models on managed endpoints for real-time or batch inference.
- **MLOps:** Supports pipelines and a model registry for managing the model lifecycle.
