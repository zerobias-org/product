# Amazon Redshift

Amazon Redshift is a managed data warehouse service from Amazon Web Services (AWS).

## Key capabilities

- **Data warehousing:** Runs SQL analytics on structured and semi-structured data.
- **Serverless:** Runs analytics without managing clusters with Redshift Serverless.
- **Data lake queries:** Queries data in Amazon S3 with Redshift Spectrum.
- **Security:** Supports encryption, VPC isolation and fine-grained access control.
