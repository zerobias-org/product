# AWS AppConfig

AWS AppConfig is a capability of AWS Systems Manager from Amazon Web Services (AWS). It creates,
manages and deploys application configuration data and feature flags.

## Key capabilities

- **Feature flags:** Manages feature flags to turn features on or off without new code deployments.
- **Validation:** Validates configuration data with JSON schemas or Lambda functions before
  deployment.
- **Controlled deployments:** Rolls out configuration changes gradually.
- **Rollback:** Rolls back deployments automatically when CloudWatch alarms fire.
