# AWS Resource Explorer

AWS Resource Explorer is a resource search and discovery service from Amazon Web Services (AWS).

## Key capabilities

- **Resource search:** Searches resources by name, tag and other properties.
- **Indexes:** Builds local and aggregator indexes of resources in Regions.
- **Views:** Controls which resources and properties searches return.
- **Multi-account search:** Searches across accounts in AWS Organizations.
