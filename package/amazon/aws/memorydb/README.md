# Amazon MemoryDB

Amazon MemoryDB is a durable in-memory database service from Amazon Web Services (AWS). It is
compatible with Valkey and Redis OSS.

## Key capabilities

- **In-memory performance:** Stores the full dataset in memory.
- **Durability:** Stores data in a Multi-AZ transaction log.
- **Compatibility:** Supports Valkey and Redis OSS data structures and APIs.
- **Security:** Supports encryption, VPC isolation and access control lists.
