# Amazon Detective

Amazon Detective is a security service from Amazon Web Services (AWS) that helps analyze and
investigate the root cause of security findings and suspicious activity.

## Key capabilities

- **Behavior graph:** Builds a graph from log data such as CloudTrail, VPC Flow Logs and GuardDuty
  findings.
- **Investigations:** Visualizes activity related to resources and findings.
- **Finding groups:** Groups related findings to show the scope of an issue.
- **Integrations:** Works with Amazon GuardDuty and AWS Security Hub.
