# Amazon Neptune

Amazon Neptune is a managed graph database service from Amazon Web Services (AWS).

## Key capabilities

- **Graph models:** Supports property graph and RDF graph models.
- **Query languages:** Supports Gremlin, openCypher and SPARQL.
- **High availability:** Replicates storage across Availability Zones with read replicas.
- **Neptune Analytics:** Analyzes graph data in memory.
