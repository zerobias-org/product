# Amazon WorkSpaces

Amazon WorkSpaces is a managed virtual desktop service from Amazon Web Services (AWS).

## Key capabilities

- **Virtual desktops:** Provisions Windows and Linux desktops in AWS.
- **Client access:** Supports access from client applications and web browsers.
- **Directory integration:** Integrates with AWS Directory Service and Active Directory.
- **Billing options:** Offers monthly or hourly billing.
