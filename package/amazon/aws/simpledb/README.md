# Amazon SimpleDB

Amazon SimpleDB is a non-relational data store from Amazon Web Services (AWS). It stores structured
data as items with attributes in domains and supports queries over that data.

## Key capabilities

- **Domains and items:** Stores data as items with attribute-value pairs inside domains.
- **Automatic indexing:** Indexes item attributes automatically for queries.
- **Select queries:** Queries data with a SQL-like Select expression.
- **Export to Amazon S3:** Exports domain data to Amazon S3.
