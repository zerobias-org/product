# Amazon Relational Database Service

Amazon Relational Database Service (Amazon RDS) is a managed relational database service from Amazon
Web Services (AWS).

## Key capabilities

- **Database engines:** Supports Aurora, PostgreSQL, MySQL, MariaDB, Oracle, SQL Server and Db2.
- **Managed operations:** Handles provisioning, patching and backups.
- **High availability:** Supports Multi-AZ deployments and read replicas.
- **Encryption:** Encrypts data at rest with AWS KMS keys.
