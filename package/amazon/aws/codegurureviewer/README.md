# Amazon CodeGuru Reviewer

Amazon CodeGuru Reviewer is a service from Amazon Web Services (AWS) that uses program analysis and
machine learning to find defects and security issues in code.

## Key capabilities

- **Code reviews:** Comments on pull requests with recommendations.
- **Security detection:** Detects security vulnerabilities in code.
- **Repository analysis:** Scans full repositories as well as pull requests.
- **Repository integrations:** Works with repositories such as GitHub, Bitbucket and CodeCommit.
