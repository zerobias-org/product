# AWS Auto Scaling

AWS Auto Scaling scaling plans are a feature from Amazon Web Services (AWS) for configuring
automatic scaling of the resources that make up an application from one place.

## Key capabilities

- **Scaling plans:** Configures scaling for multiple resources in an application together.
- **Resource discovery:** Finds scalable resources through CloudFormation stacks or tags.
- **Predictive scaling:** Forecasts load and schedules EC2 capacity ahead of demand.
- **Dynamic scaling:** Uses target tracking to adjust capacity to demand.
