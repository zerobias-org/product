# AWS Directory Service

AWS Directory Service is a set of directory services from Amazon Web Services (AWS) that run
Microsoft Active Directory in AWS or connect AWS to an existing Active Directory.

## Key capabilities

- **AWS Managed Microsoft AD:** Runs a managed Microsoft Active Directory in AWS.
- **AD Connector:** Redirects directory requests to an on-premises Active Directory.
- **Simple AD:** Provides a basic Active Directory-compatible directory.
- **Trusts:** Creates trust relationships with existing domains.
