# Amazon Connect Customer

Amazon Connect Customer, formerly Amazon Connect, is a cloud contact center service from Amazon Web
Services (AWS).

## Key capabilities

- **Omnichannel contacts:** Handles voice, chat and task contacts.
- **Contact flows:** Designs customer experiences with a visual flow editor.
- **Routing:** Routes contacts to agents with queues and routing profiles.
- **Analytics:** Provides real-time and historical metrics and reports.
