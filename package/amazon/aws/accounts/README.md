# AWS Account Management

AWS Account Management is the AWS service and API for managing the settings of AWS accounts. It
covers account details, contacts and Regions for single accounts and accounts in AWS Organizations.

## Key capabilities

- **Account information:** Views and updates account names and contact information.
- **Alternate contacts:** Manages billing, operations and security contacts.
- **Regions:** Enables and disables opt-in AWS Regions for an account.
- **Organizations support:** Manages member accounts centrally from AWS Organizations.
