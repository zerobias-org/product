# AWS Serverless Application Repository

The AWS Serverless Application Repository is a managed repository from Amazon Web Services (AWS) for
publishing, finding and deploying serverless applications.

## Key capabilities

- **Publishing:** Lets authors publish applications defined with the AWS Serverless Application
  Model (AWS SAM).
- **Discovery:** Lets users browse and search public applications.
- **Deployment:** Deploys applications into an AWS account through AWS CloudFormation.
- **Sharing:** Shares applications privately with specific accounts or publicly.
