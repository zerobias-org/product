# AWS Health

AWS Health is a service from Amazon Web Services (AWS) that reports events affecting AWS resources
and services. It shows service issues, scheduled changes and account notifications.

## Key capabilities

- **Health events:** Reports service events, scheduled changes and account notifications.
- **Affected resources:** Lists the resources affected by an event.
- **Organizational view:** Aggregates events across accounts in AWS Organizations.
- **Event integration:** Sends events to Amazon EventBridge for automation.
