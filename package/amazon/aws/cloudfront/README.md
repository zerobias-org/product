# Amazon CloudFront

Amazon CloudFront is a content delivery network (CDN) service from Amazon Web Services (AWS). It
delivers web content and APIs through a global network of edge locations.

## Key capabilities

- **Edge caching:** Caches content at edge locations close to viewers.
- **HTTPS:** Serves content over HTTPS with custom TLS certificates.
- **Security:** Integrates with AWS WAF and AWS Shield.
- **Edge compute:** Runs code at the edge with CloudFront Functions and Lambda@Edge.
