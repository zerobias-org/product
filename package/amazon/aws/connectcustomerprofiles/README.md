# Customer Profiles in Amazon Connect Customer

Customer Profiles is a feature of Amazon Connect Customer from Amazon Web Services (AWS). It gives
contact center agents a unified view of customer information.

## Key capabilities

- **Unified profiles:** Combines customer data from multiple applications into one profile.
- **Data connectors:** Imports data from sources such as Salesforce, ServiceNow and Amazon S3.
- **Identity resolution:** Detects and merges duplicate profiles.
- **Agent view:** Shows profile data to agents during contacts.
