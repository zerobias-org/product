# EC2 Image Builder

EC2 Image Builder is a service from Amazon Web Services (AWS) that automates the creation,
management and deployment of virtual machine and container images.

## Key capabilities

- **Image pipelines:** Builds images automatically on a schedule or on demand.
- **Components:** Customizes images with build and test components.
- **Testing:** Tests images before distribution.
- **Distribution:** Shares images across accounts and Regions.
