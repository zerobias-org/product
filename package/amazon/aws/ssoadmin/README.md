# AWS IAM Identity Center Admin API

The administration API of AWS IAM Identity Center (formerly AWS Single Sign-On), a workforce
identity service from Amazon Web Services (AWS). It manages Identity Center instances, permission
sets and account assignments.

## Key capabilities

- **Permission sets:** Creates and manages permission sets that define access to AWS accounts.
- **Account assignments:** Assigns users and groups to accounts through permission sets.
- **Applications:** Manages applications connected to IAM Identity Center.
- **Attribute-based access control:** Configures user attributes used for access control.
