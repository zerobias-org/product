# Amazon Cognito

Amazon Cognito is a customer identity and access management service from Amazon Web Services (AWS)
for web and mobile applications.

## Key capabilities

- **User pools:** Provides user directories with sign-up and sign-in.
- **Federation:** Supports sign-in through social and enterprise identity providers.
- **Identity pools:** Gives users temporary AWS credentials.
- **Security:** Supports multi-factor authentication and threat protection.
