# AWS Well-Architected Tool

The AWS Well-Architected Tool is a service from Amazon Web Services (AWS) for reviewing workloads
against the AWS Well-Architected Framework.

## Key capabilities

- **Workload reviews:** Answers framework questions for a workload and records the results.
- **Lenses:** Applies the framework and specialty or custom lenses.
- **Improvement plans:** Lists identified risks and recommended improvements.
- **Milestones:** Saves the state of a review over time.
