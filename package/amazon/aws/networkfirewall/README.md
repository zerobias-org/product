# AWS Network Firewall

AWS Network Firewall is a managed network firewall service from Amazon Web Services (AWS) for Amazon
VPCs.

## Key capabilities

- **Stateful inspection:** Inspects traffic with stateful rules.
- **Stateless filtering:** Filters packets with stateless rules.
- **Suricata rules:** Supports Suricata-compatible intrusion prevention rules.
- **Logging:** Logs alerts and flows to S3, CloudWatch Logs or Firehose.
