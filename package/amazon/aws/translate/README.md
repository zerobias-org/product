# Amazon Translate

Amazon Translate is a neural machine translation service from Amazon Web Services (AWS).

## Key capabilities

- **Real-time translation:** Translates text through a synchronous API.
- **Batch translation:** Translates documents stored in Amazon S3.
- **Custom terminology:** Controls how specific terms are translated.
- **Automatic language detection:** Detects the source language.
