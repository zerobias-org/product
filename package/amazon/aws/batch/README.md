# AWS Batch

AWS Batch is a fully managed service from Amazon Web Services (AWS) for running batch computing
workloads.

## Key capabilities

- **Job scheduling:** Queues and schedules batch jobs.
- **Compute provisioning:** Provisions compute resources based on job requirements.
- **Compute options:** Runs jobs on Amazon EC2, EC2 Spot, AWS Fargate and Amazon EKS.
- **Job dependencies:** Supports array jobs and job dependencies.
