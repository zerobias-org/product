# AWS Elastic Beanstalk

AWS Elastic Beanstalk is a service from Amazon Web Services (AWS) for deploying and running web
applications without managing the underlying infrastructure.

## Key capabilities

- **Managed platforms:** Runs applications on platforms such as Java, .NET, Node.js, Python, PHP,
  Ruby, Go and Docker.
- **Provisioning:** Sets up capacity, load balancing and auto scaling.
- **Health monitoring:** Reports environment and application health.
- **Managed updates:** Applies platform updates during maintenance windows.
