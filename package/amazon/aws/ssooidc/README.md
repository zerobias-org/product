# AWS IAM Identity Center OIDC

The OIDC API of AWS IAM Identity Center (formerly AWS Single Sign-On), a workforce identity service
from Amazon Web Services (AWS). It lets clients such as the AWS CLI obtain tokens through OAuth 2.0
flows.

## Key capabilities

- **Client registration:** Registers public clients with IAM Identity Center.
- **Device authorization:** Supports the OAuth 2.0 device authorization grant.
- **Token issuance:** Issues access and refresh tokens for authorized clients.
