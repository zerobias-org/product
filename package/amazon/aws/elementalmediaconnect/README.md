# AWS Elemental MediaConnect

AWS Elemental MediaConnect is a transport service for live video from Amazon Web Services (AWS). It
moves live video streams into, through and out of the AWS Cloud.

## Key capabilities

- **Live video transport:** Sends live video between sources and destinations over the AWS network.
- **Flows:** Uses flows with sources and outputs to route a stream to multiple destinations.
- **Entitlements:** Shares content with other AWS accounts through entitlements.
- **Encryption:** Supports encryption of content in transit.
