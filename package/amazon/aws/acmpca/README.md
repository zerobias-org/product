# AWS Private Certificate Authority

AWS Private Certificate Authority (AWS Private CA) is a managed service from Amazon Web Services
(AWS) for creating and running private certificate authority hierarchies.

## Key capabilities

- **Private CA hierarchies:** Creates root and subordinate certificate authorities.
- **Private certificates:** Issues private certificates for internal users, devices and services.
- **Revocation:** Supports certificate revocation through CRLs and OCSP.
- **Audit reports:** Produces reports of issued and revoked certificates.
