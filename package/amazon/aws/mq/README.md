# Amazon MQ

Amazon MQ is a managed message broker service from Amazon Web Services (AWS) for Apache ActiveMQ and
RabbitMQ.

## Key capabilities

- **Managed brokers:** Runs Apache ActiveMQ and RabbitMQ brokers.
- **Standard protocols:** Supports protocols such as AMQP, MQTT, OpenWire and STOMP.
- **High availability:** Supports Multi-AZ deployments.
- **Encryption:** Encrypts messages at rest and in transit.
