# AWS Elemental MediaTailor

AWS Elemental MediaTailor is a channel assembly and personalized ad insertion service from Amazon
Web Services (AWS).

## Key capabilities

- **Server-side ad insertion:** Inserts ads into video streams on the server side.
- **Channel assembly:** Creates linear channels from existing video-on-demand content.
- **Ad decision server integration:** Requests ads from an ad decision server for each viewer.
- **Reporting:** Reports ad tracking events to ad servers.
