# AWS Amplify

AWS Amplify is a set of tools and services from Amazon Web Services (AWS) for building, deploying
and hosting full-stack web and mobile applications.

## Key capabilities

- **Hosting:** Hosts static and server-side rendered web apps with Git-based deployments.
- **Backend building:** Sets up backends such as authentication, data and storage on AWS.
- **Client libraries:** Provides libraries for web and mobile frameworks.
- **UI components:** Provides UI components for common app features.
