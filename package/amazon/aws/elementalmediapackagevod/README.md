# AWS Elemental MediaPackage VOD

AWS Elemental MediaPackage VOD is the video-on-demand capability of AWS Elemental MediaPackage, from
Amazon Web Services (AWS). It packages stored video files for delivery to playback devices.

## Key capabilities

- **VOD packaging:** Packages file-based content into streaming formats on request.
- **Packaging groups:** Groups packaging configurations and applies them to assets.
- **Assets:** Ingests source content from Amazon S3 as assets.
- **Content protection:** Supports DRM encryption of packaged output.
