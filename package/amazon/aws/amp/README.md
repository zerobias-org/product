# Amazon Managed Service for Prometheus

Amazon Managed Service for Prometheus is a Prometheus-compatible monitoring service from Amazon Web
Services (AWS). It stores and queries metrics from containerized applications and infrastructure.

## Key capabilities

- **Prometheus compatibility:** Uses the open source Prometheus data model and PromQL query
  language.
- **Managed scaling:** Scales metric ingestion, storage and queries automatically.
- **Workspaces:** Isolates metrics in logical workspaces.
- **Alerting:** Runs recording and alerting rules with a managed alert manager.
