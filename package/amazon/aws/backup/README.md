# AWS Backup

AWS Backup is a fully managed service from Amazon Web Services (AWS) that centralizes and automates
data protection across AWS services and hybrid workloads.

## Key capabilities

- **Backup plans:** Defines backup schedules and retention policies.
- **Cross-account and cross-Region copies:** Copies backups to other accounts and Regions.
- **Backup Vault Lock:** Makes backups immutable with WORM protection.
- **Audit Manager:** Audits backup activity against defined controls.
