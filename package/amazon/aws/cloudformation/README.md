# AWS CloudFormation

AWS CloudFormation is an infrastructure as code service from Amazon Web Services (AWS). It
provisions and manages AWS resources from templates.

## Key capabilities

- **Templates:** Describes resources in JSON or YAML templates.
- **Stacks:** Creates, updates and deletes resources as a single unit.
- **Change sets:** Previews changes before they are applied.
- **StackSets:** Deploys stacks across multiple accounts and Regions.
- **Drift detection:** Detects changes made to resources outside CloudFormation.
