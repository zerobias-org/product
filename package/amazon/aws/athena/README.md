# Amazon Athena

Amazon Athena is a serverless, interactive query service from Amazon Web Services (AWS). It analyzes
data in Amazon S3 and other sources using SQL.

## Key capabilities

- **Serverless SQL:** Runs SQL queries without servers to manage.
- **Data formats:** Queries formats such as CSV, JSON, Parquet and ORC.
- **Federated queries:** Queries data sources outside S3 through connectors.
- **Apache Spark:** Runs interactive Apache Spark workloads.
