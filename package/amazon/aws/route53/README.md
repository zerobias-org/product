# Amazon Route 53

Amazon Route 53 is a DNS web service from Amazon Web Services (AWS).

## Key capabilities

- **Domain registration:** Registers domain names.
- **DNS hosting:** Hosts public and private DNS zones.
- **Routing policies:** Routes traffic by latency, geography, weight or failover.
- **Health checks:** Monitors endpoint health and routes around failures.
