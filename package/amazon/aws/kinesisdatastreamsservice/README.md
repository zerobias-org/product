# Amazon Kinesis Data Streams

Amazon Kinesis Data Streams is a serverless streaming data service from Amazon Web Services (AWS).
It captures, processes and stores data streams.

## Key capabilities

- **Data streams:** Ingests records into streams made of shards.
- **Capacity modes:** Supports on-demand and provisioned capacity modes.
- **Consumers:** Delivers data to consumers, including enhanced fan-out consumers.
- **Encryption:** Encrypts data at rest with AWS KMS keys.
