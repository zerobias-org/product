# Amazon EMR

Amazon EMR, formerly Amazon Elastic MapReduce, is a managed big data platform from Amazon Web
Services (AWS). It runs open source frameworks such as Apache Spark, Apache Hive and Presto.

## Key capabilities

- **Open source frameworks:** Runs Apache Spark, Hive, Presto and other big data frameworks.
- **Deployment options:** Runs on Amazon EC2, Amazon EKS or EMR Serverless.
- **Data access:** Reads and writes data in Amazon S3.
- **Security:** Supports encryption and fine-grained access control.
