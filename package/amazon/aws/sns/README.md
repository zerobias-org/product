# Amazon Simple Notification Service

Amazon Simple Notification Service (Amazon SNS) is a publish/subscribe messaging service from Amazon
Web Services (AWS).

## Key capabilities

- **Topics:** Delivers messages published to a topic to all its subscribers.
- **Application-to-application:** Delivers messages to Amazon SQS, AWS Lambda, HTTP/S endpoints and
  other subscribers.
- **Application-to-person:** Sends SMS, mobile push and email notifications.
- **Message filtering:** Filters messages per subscription with filter policies.
