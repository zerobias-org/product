# Amazon DynamoDB Accelerator (DAX)

Amazon DynamoDB Accelerator (DAX) is a fully managed in-memory cache for Amazon DynamoDB from Amazon
Web Services (AWS).

## Key capabilities

- **In-memory caching:** Caches DynamoDB reads in memory to reduce response times.
- **API compatibility:** Works with the DynamoDB API, so applications need few code changes.
- **Clusters:** Runs as a cluster with multiple nodes for availability.
- **Encryption:** Supports encryption at rest and in transit.
