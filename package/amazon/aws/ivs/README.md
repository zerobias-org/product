# Amazon Interactive Video Service

Amazon Interactive Video Service (Amazon IVS) is a managed live streaming service from Amazon Web
Services (AWS).

## Key capabilities

- **Low-latency streaming:** Streams live video to viewers with low latency.
- **Real-time streaming:** Hosts real-time video sessions with multiple participants.
- **Chat:** Adds chat rooms to live streams.
- **Recording:** Records streams to Amazon S3.
