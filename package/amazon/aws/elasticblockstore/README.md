# Amazon Elastic Block Store

Amazon Elastic Block Store (Amazon EBS) is a block storage service from Amazon Web Services (AWS)
for use with Amazon EC2 instances.

## Key capabilities

- **Volumes:** Provides persistent block storage volumes for EC2 instances.
- **Volume types:** Offers SSD and HDD volume types for different performance needs.
- **Snapshots:** Backs up volumes with point-in-time snapshots stored in Amazon S3.
- **Encryption:** Encrypts volumes and snapshots with AWS KMS keys.
