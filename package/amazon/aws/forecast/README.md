# Amazon Forecast

Amazon Forecast is a managed time series forecasting service from Amazon Web Services (AWS). It is
no longer available to new customers; existing customers can continue to use it.

## Key capabilities

- **Time series forecasting:** Builds forecasts from historical time series data.
- **Related data:** Uses related time series and item metadata to improve forecasts.
- **Predictors:** Trains predictors and evaluates their accuracy.
- **Forecast export:** Exports forecasts to Amazon S3.
