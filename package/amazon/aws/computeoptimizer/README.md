# AWS Compute Optimizer

AWS Compute Optimizer is a service from Amazon Web Services (AWS) that analyzes resource usage and
recommends optimal AWS resources to reduce cost and improve performance.

## Key capabilities

- **Rightsizing:** Recommends resource types and sizes based on utilization.
- **Supported resources:** Covers resources such as EC2 instances, Auto Scaling groups, EBS volumes
  and Lambda functions.
- **Savings estimates:** Estimates savings from recommendations.
- **Organization view:** Provides recommendations across accounts in AWS Organizations.
