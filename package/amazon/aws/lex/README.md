# Amazon Lex

Amazon Lex is a service from Amazon Web Services (AWS) for building conversational interfaces with
voice and text.

## Key capabilities

- **Bots:** Builds chatbots and voice bots.
- **Intents and slots:** Defines user intents and the data needed to fulfill them.
- **Speech and text:** Recognizes speech and understands natural language.
- **Integration:** Fulfills intents with AWS Lambda and connects to Amazon Connect.
