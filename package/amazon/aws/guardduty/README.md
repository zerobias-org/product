# Amazon GuardDuty

Amazon GuardDuty is a threat detection service from Amazon Web Services (AWS). It monitors AWS
accounts and workloads for malicious activity.

## Key capabilities

- **Threat detection:** Analyzes CloudTrail events, VPC Flow Logs and DNS logs.
- **Protection plans:** Extends detection to S3, EKS, RDS, Lambda and runtime monitoring.
- **Malware protection:** Scans EBS volumes and S3 objects for malware.
- **Multi-account:** Manages accounts centrally through AWS Organizations.
