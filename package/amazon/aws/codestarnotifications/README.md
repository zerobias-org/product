# AWS CodeStar Notifications

AWS CodeStar Notifications is a feature of the AWS Developer Tools console from Amazon Web Services
(AWS). It sends notifications about events in developer tools such as CodeCommit, CodeBuild,
CodeDeploy and CodePipeline.

## Key capabilities

- **Notification rules:** Defines which resource events send notifications.
- **Targets:** Sends notifications to Amazon SNS topics and chat clients.
- **Event types:** Covers events such as builds, deployments and pull requests.
