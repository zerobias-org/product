# AWS AppSync

AWS AppSync is a managed service from Amazon Web Services (AWS) for building serverless GraphQL and
Pub/Sub APIs.

## Key capabilities

- **GraphQL APIs:** Builds GraphQL APIs that connect to data sources such as DynamoDB, Lambda and
  HTTP endpoints.
- **Real-time data:** Pushes updates to clients through subscriptions.
- **Authorization:** Supports API keys, IAM, Amazon Cognito, OpenID Connect and Lambda
  authorization.
- **Caching:** Caches API responses on the server side.
