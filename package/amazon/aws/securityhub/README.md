# AWS Security Hub

AWS Security Hub is a security service from Amazon Web Services (AWS). It collects security findings
from AWS services and partner tools and checks AWS resources against security best practices.

## Key capabilities

- **Findings aggregation:** Collects findings from AWS services and partner products in one place.
- **Security standards:** Runs automated checks against standards such as the AWS Foundational
  Security Best Practices and CIS AWS Foundations Benchmark.
- **Multi-account:** Aggregates findings across accounts and Regions.
- **Automation:** Sends findings to Amazon EventBridge for response workflows.
