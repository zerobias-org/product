# Amazon Simple Email Service

Amazon Simple Email Service (Amazon SES) is an email sending and receiving service from Amazon Web
Services (AWS).

## Key capabilities

- **Sending:** Sends email through an API or SMTP interface.
- **Receiving:** Receives email and routes it to other AWS services.
- **Authentication:** Supports SPF, DKIM and DMARC for verified identities.
- **Deliverability tracking:** Tracks bounces, complaints and delivery events.
