# AWS End User Messaging

AWS End User Messaging is a communication service from Amazon Web Services (AWS). It sends SMS,
voice, push and WhatsApp messages from applications.

## Key capabilities

- **SMS and voice:** Sends SMS and voice messages to users.
- **Push notifications:** Sends mobile push notifications.
- **WhatsApp messaging:** Sends messages through WhatsApp Business accounts.
- **Origination identities:** Manages phone numbers and sender IDs used to send messages.
