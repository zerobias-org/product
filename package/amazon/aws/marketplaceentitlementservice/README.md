# AWS Marketplace Entitlement Service

The AWS Marketplace Entitlement Service is an API from Amazon Web Services (AWS) that lets sellers
retrieve customer entitlements for AWS Marketplace products.

## Key capabilities

- **Entitlement lookup:** Returns the entitlements a customer has for a product.
- **Contract products:** Supports products sold with contract pricing.
- **Filtering:** Filters entitlements by customer or dimension.
