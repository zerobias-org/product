# Amazon API Gateway Management API

The Amazon API Gateway Management API is part of Amazon API Gateway from Amazon Web Services (AWS).
Backend services use it to manage connections to WebSocket APIs.

## Key capabilities

- **Send messages:** Posts data to connected WebSocket clients.
- **Connection info:** Gets information about a connected client.
- **Disconnect clients:** Deletes a client connection from the backend.
