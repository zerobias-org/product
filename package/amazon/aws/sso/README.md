# AWS IAM Identity Center Portal

The portal API of AWS IAM Identity Center (formerly AWS Single Sign-On), a workforce identity
service from Amazon Web Services (AWS). The portal API serves the AWS access portal, where users
reach the accounts and roles assigned to them.

## Key capabilities

- **Account listing:** Lists the AWS accounts assigned to the signed-in user.
- **Role listing:** Lists the roles the user can assume in each account.
- **Role credentials:** Returns short-term credentials for an assigned role.
- **Sign-out:** Ends the user's access portal session.
