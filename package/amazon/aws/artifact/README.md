# AWS Artifact

AWS Artifact is a self-service portal from Amazon Web Services (AWS) that gives on-demand access to
AWS security and compliance reports and online agreements.

## Key capabilities

- **Compliance reports:** Provides AWS audit reports such as SOC and PCI reports and ISO
  certifications.
- **Agreements:** Lets customers review and accept agreements such as the Business Associate
  Addendum (BAA).
- **Third-party reports:** Provides compliance reports from independent software vendors in AWS
  Marketplace.
- **Notifications:** Sends notifications when new reports or agreements are available.
