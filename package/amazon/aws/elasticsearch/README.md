# Amazon OpenSearch Service

Amazon OpenSearch Service, formerly Amazon Elasticsearch Service, is a managed service from Amazon
Web Services (AWS) for deploying and running OpenSearch and legacy Elasticsearch clusters.

## Key capabilities

- **Managed clusters:** Runs OpenSearch and legacy Elasticsearch domains.
- **Search and analytics:** Supports full-text search, log analytics and vector search.
- **OpenSearch Dashboards:** Provides dashboards for visualizing data.
- **Serverless:** Offers a serverless option.
