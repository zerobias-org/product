# AWS Elemental MediaPackage

AWS Elemental MediaPackage is a video origination and packaging service from Amazon Web Services
(AWS). It prepares and protects video for delivery over the internet.

## Key capabilities

- **Packaging:** Packages video into formats such as HLS, DASH and CMAF.
- **Live and VOD:** Supports live streams and video-on-demand content.
- **Content protection:** Encrypts content with DRM.
- **Time-shifted viewing:** Supports start-over and catch-up viewing of live streams.
