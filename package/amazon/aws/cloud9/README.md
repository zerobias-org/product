# AWS Cloud9

AWS Cloud9 is a cloud-based integrated development environment (IDE) from Amazon Web Services (AWS).
AWS Cloud9 is no longer available to new customers; existing customers can continue to use it.

## Key capabilities

- **Browser-based IDE:** Provides a code editor, debugger and terminal in a web browser.
- **Environments:** Runs development environments on Amazon EC2 or your own servers over SSH.
- **Collaboration:** Lets users share environments and edit code together.
- **AWS integration:** Includes a preconfigured terminal for working with AWS services.
