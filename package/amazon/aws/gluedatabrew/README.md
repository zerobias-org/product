# AWS Glue DataBrew

AWS Glue DataBrew is a visual data preparation tool from Amazon Web Services (AWS). It cleans and
normalizes data without writing code.

## Key capabilities

- **Visual data preparation:** Applies transformations through a point-and-click interface.
- **Recipes:** Saves transformation steps as reusable recipes.
- **Data profiling:** Profiles datasets to show data quality statistics.
- **Jobs:** Runs recipe and profile jobs on datasets.
