# Amazon Mechanical Turk

Amazon Mechanical Turk (MTurk) is a crowdsourcing marketplace from Amazon. Requesters post tasks
that workers complete online.

## Key capabilities

- **Human Intelligence Tasks:** Posts tasks (HITs) for workers to complete.
- **Qualifications:** Restricts tasks to workers who meet qualifications.
- **Review and payment:** Reviews submitted work and pays workers.
- **API access:** Manages tasks through the MTurk API.
