# Amazon EC2 Auto Scaling

Amazon EC2 Auto Scaling is a service from Amazon Web Services (AWS) that keeps the right number of
Amazon EC2 instances running to handle application load.

## Key capabilities

- **Auto Scaling groups:** Manages groups of EC2 instances with minimum, maximum and desired sizes.
- **Health checks:** Replaces unhealthy instances automatically.
- **Scaling policies:** Scales with target tracking, step, scheduled and predictive scaling.
- **Mixed instances:** Combines instance types and On-Demand and Spot capacity.
