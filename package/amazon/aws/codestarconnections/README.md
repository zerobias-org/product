# AWS CodeConnections

AWS CodeConnections, formerly AWS CodeStar Connections, is a feature from Amazon Web Services (AWS)
that connects AWS services such as CodePipeline to third-party code repositories.

## Key capabilities

- **Repository connections:** Connects to providers such as GitHub, GitLab and Bitbucket.
- **Shared connections:** Lets several AWS services use the same connection resource.
- **Host connections:** Connects to self-managed repository installations.
