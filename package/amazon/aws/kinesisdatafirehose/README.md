# Amazon Data Firehose

Amazon Data Firehose is a managed service from Amazon Web Services (AWS) for delivering streaming
data to destinations. It was formerly called Amazon Kinesis Data Firehose.

## Key capabilities

- **Stream delivery:** Delivers streaming data to S3, Redshift, OpenSearch and HTTP endpoints.
- **Transformation:** Transforms records with AWS Lambda.
- **Format conversion:** Converts records to Apache Parquet or ORC.
- **Encryption:** Encrypts data with AWS KMS keys.
