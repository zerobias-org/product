# AWS Network Manager

AWS Network Manager is a service from Amazon Web Services (AWS) for managing and monitoring global
networks across AWS and on premises. It hosts AWS Cloud WAN and Transit Gateway Network Manager.

## Key capabilities

- **Global networks:** Groups network resources into a global network.
- **Cloud WAN:** Builds and manages wide area networks with AWS Cloud WAN.
- **Transit gateway registration:** Registers transit gateways and on-premises sites.
- **Monitoring:** Shows network topology, events and metrics.
