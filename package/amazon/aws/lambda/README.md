# AWS Lambda

AWS Lambda is a serverless compute service from Amazon Web Services (AWS). It runs code in response
to events without provisioning servers.

## Key capabilities

- **Event-driven functions:** Runs functions in response to events from AWS services.
- **Runtimes:** Supports managed runtimes and container images.
- **Automatic scaling:** Scales function instances with request volume.
- **Execution roles:** Grants functions permissions through IAM execution roles.
