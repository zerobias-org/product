# Amazon EventBridge

Amazon EventBridge is a serverless event bus service from Amazon Web Services (AWS). It was formerly
called Amazon CloudWatch Events.

## Key capabilities

- **Event buses:** Receives events from AWS services, applications and SaaS partners.
- **Rules:** Routes matching events to targets such as AWS Lambda and Amazon SQS.
- **Scheduler:** Runs scheduled tasks through EventBridge Scheduler.
- **Pipes:** Connects event sources to targets through EventBridge Pipes.
