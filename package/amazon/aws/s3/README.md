# Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service from Amazon Web Services
(AWS). It stores and retrieves any amount of data as objects in buckets.

## Key capabilities

- **Object storage:** Stores data as objects in buckets, each identified by a key.
- **Storage classes:** Offers storage classes for frequent, infrequent and archival access.
- **Access control:** Controls access with IAM policies, bucket policies and S3 Block Public Access.
- **Encryption:** Encrypts objects at rest by default.
