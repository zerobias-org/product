# AWS CodeArtifact

AWS CodeArtifact is a managed artifact repository service from Amazon Web Services (AWS) for storing
and sharing software packages.

## Key capabilities

- **Package formats:** Supports formats such as npm, PyPI, Maven, NuGet and generic packages.
- **Upstream repositories:** Fetches packages from public repositories on demand.
- **Domains:** Shares packages across repositories and accounts in a domain.
- **Access control:** Controls access with IAM and resource policies.
