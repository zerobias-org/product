# Elastic Load Balancing

Elastic Load Balancing from Amazon Web Services (AWS) distributes incoming traffic across targets
such as EC2 instances, containers, IP addresses and Lambda functions. This package covers the
version 2 API for Application, Network and Gateway Load Balancers.

## Key capabilities

- **Application Load Balancer:** Routes HTTP and HTTPS traffic based on request content.
- **Network Load Balancer:** Balances TCP, UDP and TLS traffic.
- **Gateway Load Balancer:** Deploys and scales third-party virtual appliances.
- **Health checks:** Routes traffic only to healthy targets.
