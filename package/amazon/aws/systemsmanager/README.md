# AWS Systems Manager

AWS Systems Manager is a service from Amazon Web Services (AWS) for viewing and managing nodes such
as Amazon EC2 instances, on-premises servers and virtual machines.

## Key capabilities

- **Node management:** Gives an inventory of managed nodes and their configuration.
- **Patch Manager:** Automates operating system and application patching.
- **Session Manager:** Provides shell access to nodes without opening inbound ports.
- **Parameter Store:** Stores configuration data and secrets as parameters.
- **Automation:** Runs runbooks for common operational tasks.
