# Amazon DevOps Guru

Amazon DevOps Guru is a service from Amazon Web Services (AWS) that uses machine learning to detect
operational issues in applications. It is no longer available to new customers, and AWS has
announced an end-of-support date for existing customers.

## Key capabilities

- **Anomaly detection:** Detects anomalous behavior in metrics, logs and events.
- **Insights:** Groups related anomalies into insights with recommendations.
- **Coverage:** Analyzes resources by account, CloudFormation stack or tag.
- **Notifications:** Sends insights to Amazon SNS.
