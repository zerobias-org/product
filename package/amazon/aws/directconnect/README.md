# AWS Direct Connect

AWS Direct Connect is a networking service from Amazon Web Services (AWS) that links on-premises
networks to AWS over a dedicated private connection.

## Key capabilities

- **Dedicated connections:** Provides physical Ethernet connections at Direct Connect locations.
- **Hosted connections:** Offers connections through AWS Direct Connect Partners.
- **Virtual interfaces:** Accesses VPCs and public AWS services through virtual interfaces.
- **MACsec:** Supports MACsec encryption on supported connections.
