# Amazon Kinesis Video Streams

Amazon Kinesis Video Streams is a managed service from Amazon Web Services (AWS) for streaming video
from connected devices to AWS.

## Key capabilities

- **Video ingestion:** Ingests video from devices into streams.
- **Storage and playback:** Stores video and plays it back with HLS and DASH.
- **WebRTC:** Supports two-way real-time media streaming with WebRTC.
- **Encryption:** Encrypts data at rest with AWS KMS keys.
