# Amazon CodeGuru Profiler

Amazon CodeGuru Profiler is a service from Amazon Web Services (AWS) that collects runtime
performance data from applications to find costly lines of code.

## Key capabilities

- **Continuous profiling:** Profiles applications in production with low overhead.
- **Visualizations:** Shows CPU usage and latency with flame graphs.
- **Recommendations:** Suggests fixes for performance issues.
- **Languages:** Supports applications on the JVM and Python.
