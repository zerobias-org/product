# Amazon EMR on EKS

Amazon EMR on EKS is a deployment option of Amazon EMR from Amazon Web Services (AWS). It runs open-
source big data frameworks on Amazon Elastic Kubernetes Service (Amazon EKS) clusters.

## Key capabilities

- **Spark on Kubernetes:** Runs Apache Spark jobs on Amazon EKS.
- **Virtual clusters:** Maps EMR virtual clusters to Kubernetes namespaces.
- **Job runs:** Submits and manages job runs through the EMR containers API.
- **Shared infrastructure:** Shares EKS clusters with other Kubernetes workloads.
