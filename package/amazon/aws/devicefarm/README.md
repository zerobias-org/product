# AWS Device Farm

AWS Device Farm is an application testing service from Amazon Web Services (AWS). It tests web and
mobile apps on real browsers and physical devices hosted by AWS.

## Key capabilities

- **Real devices:** Tests Android and iOS apps on physical phones and tablets.
- **Automated tests:** Runs tests with frameworks such as Appium and XCTest.
- **Remote access:** Lets users interact with devices from a browser.
- **Desktop browser testing:** Runs Selenium tests on desktop browsers.
