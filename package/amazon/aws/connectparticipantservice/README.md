# Amazon Connect Participant Service

The Amazon Connect Participant Service is an API of Amazon Connect Customer from Amazon Web Services
(AWS). It lets customers and agents take part in chat contacts.

## Key capabilities

- **Chat messaging:** Sends and receives chat messages and events.
- **Connections:** Creates participant connections for chat sessions.
- **Attachments:** Sends and retrieves attachments in chats.
- **Transcripts:** Retrieves chat transcripts.
