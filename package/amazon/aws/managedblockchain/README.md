# Amazon Managed Blockchain

Amazon Managed Blockchain is a managed blockchain service from Amazon Web Services (AWS). It is no
longer available to new customers; existing customers can use it until the end of support date on
the product page.

## Key capabilities

- **Hyperledger Fabric:** Creates and manages Hyperledger Fabric networks.
- **Ethereum nodes:** Runs Ethereum nodes.
- **Managed nodes:** Handles node provisioning and maintenance.
- **Access control:** Controls access with IAM.
