# AWS IoT Core

AWS IoT Core is a managed service from Amazon Web Services (AWS) that connects IoT devices to the
AWS Cloud.

## Key capabilities

- **Device connectivity:** Connects devices over MQTT, HTTPS and MQTT over WebSockets.
- **Message broker:** Routes messages between devices and applications.
- **Rules engine:** Sends device data to other AWS services.
- **Device authentication:** Authenticates devices with X.509 certificates and policies.
