# Amazon DynamoDB

Amazon DynamoDB is a serverless, fully managed NoSQL database service from Amazon Web Services (AWS)
for key-value and document data.

## Key capabilities

- **Serverless scaling:** Scales throughput and storage without servers to manage.
- **Global tables:** Replicates tables across Regions.
- **Backup and restore:** Provides on-demand backups and point-in-time recovery.
- **Encryption:** Encrypts data at rest by default.
- **Streams:** Captures item-level changes in a stream.
