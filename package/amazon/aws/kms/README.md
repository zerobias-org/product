# AWS Key Management Service

AWS Key Management Service (AWS KMS) is a managed service from Amazon Web Services (AWS) for
creating and controlling cryptographic keys.

## Key capabilities

- **Key management:** Creates, rotates and disables symmetric and asymmetric keys.
- **Service integration:** Encrypts data in many AWS services.
- **Key policies:** Controls key use with key policies, IAM policies and grants.
- **Auditing:** Logs key use in AWS CloudTrail.
