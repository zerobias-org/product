# AWS Transfer Family

AWS Transfer Family is a managed file transfer service from Amazon Web Services (AWS). It transfers
files into and out of Amazon S3 and Amazon EFS.

## Key capabilities

- **Protocols:** Supports SFTP, FTPS, FTP and AS2.
- **Storage backends:** Stores transferred files in Amazon S3 or Amazon EFS.
- **Identity providers:** Authenticates users with service-managed users, AWS Directory Service or a
  custom provider.
- **Managed workflows:** Runs post-upload processing steps.
