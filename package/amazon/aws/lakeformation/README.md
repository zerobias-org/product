# AWS Lake Formation

AWS Lake Formation is a service from Amazon Web Services (AWS) for building, securing and managing
data lakes.

## Key capabilities

- **Fine-grained permissions:** Grants access at database, table, column and row level.
- **Tag-based access:** Manages permissions with LF-Tags.
- **Data sharing:** Shares data across AWS accounts.
- **Data Catalog integration:** Works with the AWS Glue Data Catalog.
