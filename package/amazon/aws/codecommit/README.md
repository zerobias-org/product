# AWS CodeCommit

AWS CodeCommit is a managed source control service from Amazon Web Services (AWS) that hosts private
Git repositories.

## Key capabilities

- **Git repositories:** Hosts private Git repositories.
- **Pull requests:** Supports code review through pull requests and approval rules.
- **Encryption:** Encrypts repositories at rest and in transit.
- **Access control:** Controls access with IAM.
