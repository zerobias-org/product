# AWS IAM Access Analyzer

AWS IAM Access Analyzer is a feature of AWS Identity and Access Management (IAM) from Amazon Web
Services (AWS). It analyzes policies to find resource access that is shared outside your account or
organization, and unused access.

## Key capabilities

- **External access findings:** Reports resources shared with principals outside your zone of trust.
- **Unused access:** Finds unused roles, access keys, passwords and permissions.
- **Policy validation:** Checks IAM policies against grammar and best practices.
- **Policy generation:** Generates least-privilege policies from CloudTrail access activity.
