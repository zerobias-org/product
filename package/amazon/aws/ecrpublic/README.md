# Amazon ECR Public

Amazon ECR Public is the public container registry of Amazon Elastic Container Registry from Amazon
Web Services (AWS). It hosts container images for public download.

## Key capabilities

- **Public repositories:** Hosts container images that anyone can pull.
- **Amazon ECR Public Gallery:** Lets users browse and search public images.
- **Repository catalog:** Publishes descriptions and usage details for repositories.
