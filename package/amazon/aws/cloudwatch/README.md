# Amazon CloudWatch

Amazon CloudWatch is a monitoring and observability service from Amazon Web Services (AWS) for AWS
resources and the applications that run on them.

## Key capabilities

- **Metrics:** Collects and stores metrics from AWS services and applications.
- **Alarms:** Sends notifications or takes actions when metrics cross thresholds.
- **Dashboards:** Visualizes metrics and logs in dashboards.
- **Logs:** Collects, stores and queries log data.
