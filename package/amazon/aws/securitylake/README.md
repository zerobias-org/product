# Amazon Security Lake

Amazon Security Lake is a service from Amazon Web Services (AWS) that centralizes security data from
AWS, third-party and custom sources into a data lake in the customer's account.

## Key capabilities

- **Centralized collection:** Collects logs and events from AWS services and third-party sources.
- **OCSF normalization:** Converts data to the Open Cybersecurity Schema Framework (OCSF).
- **Customer-owned storage:** Stores the data in Amazon S3 in the customer's account.
- **Subscribers:** Gives analytics and security tools access to the data.
