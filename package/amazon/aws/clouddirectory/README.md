# Amazon Cloud Directory

Amazon Cloud Directory is a managed, hierarchical data store from Amazon Web Services (AWS). It is
no longer open to new customers and AWS has announced an end-of-support date for it.

## Key capabilities

- **Hierarchies:** Organizes objects in multiple hierarchies.
- **Schemas:** Defines object types and attributes with schemas.
- **Indexing:** Indexes object attributes for fast lookup.
