# Amazon CloudWatch Logs

Amazon CloudWatch Logs is a feature of Amazon CloudWatch from Amazon Web Services (AWS). It
centralizes logs from systems, applications and AWS services.

## Key capabilities

- **Log collection:** Collects logs from AWS services, EC2 instances and applications.
- **Logs Insights:** Queries and analyzes log data interactively.
- **Metric filters:** Turns log data into CloudWatch metrics.
- **Retention:** Sets retention periods and exports logs to Amazon S3.
- **Data protection:** Masks sensitive data in log events.
