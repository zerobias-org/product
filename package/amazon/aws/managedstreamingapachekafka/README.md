# Amazon Managed Streaming for Apache Kafka

Amazon Managed Streaming for Apache Kafka (Amazon MSK) is a managed Apache Kafka service from Amazon
Web Services (AWS).

## Key capabilities

- **Managed Kafka clusters:** Runs Apache Kafka clusters on AWS.
- **MSK Serverless:** Runs Kafka without managing cluster capacity.
- **MSK Connect:** Runs Kafka Connect connectors.
- **Security:** Supports IAM access control, TLS and encryption at rest.
