# Amazon Data Lifecycle Manager

Amazon Data Lifecycle Manager is a feature from Amazon Web Services (AWS) that automates the
creation, retention and deletion of EBS snapshots and EBS-backed AMIs.

## Key capabilities

- **Lifecycle policies:** Defines schedules for creating snapshots and AMIs.
- **Retention:** Deletes old snapshots and AMIs based on retention rules.
- **Cross-Region copies:** Copies snapshots to other Regions.
- **Tag targeting:** Selects resources by tags.
