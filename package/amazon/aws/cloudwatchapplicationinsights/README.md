# Amazon CloudWatch Application Insights

Amazon CloudWatch Application Insights is a feature of Amazon CloudWatch from Amazon Web Services
(AWS). It sets up monitoring for applications and their underlying AWS resources and detects common
problems.

## Key capabilities

- **Automated setup:** Recommends and configures metrics, logs and alarms for application
  components.
- **Problem detection:** Detects application problems and correlates related observations.
- **Supported workloads:** Supports workloads such as .NET, SQL Server, Java and SAP applications.
- **Dashboards:** Shows detected problems in automated dashboards.
