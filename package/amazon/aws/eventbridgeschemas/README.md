# Amazon EventBridge Schema Registry

Amazon EventBridge Schema Registry is a feature of Amazon EventBridge from Amazon Web Services
(AWS). It stores and discovers schemas for events.

## Key capabilities

- **Schema registries:** Stores event schemas in registries.
- **Schema discovery:** Discovers schemas from events sent to an event bus.
- **Code bindings:** Generates code bindings for event schemas.
- **AWS event schemas:** Provides schemas for events from AWS services.
