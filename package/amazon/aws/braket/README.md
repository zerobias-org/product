# Amazon Braket

Amazon Braket is a fully managed quantum computing service from Amazon Web Services (AWS). It gives
access to quantum hardware from several providers and to circuit simulators.

## Key capabilities

- **Quantum hardware access:** Runs quantum tasks on devices from multiple hardware providers.
- **Simulators:** Runs quantum circuits on managed simulators.
- **Braket SDK:** Provides an open source Python SDK for building quantum algorithms.
- **Hybrid jobs:** Runs hybrid quantum-classical algorithms.
