# Amazon Elastic Container Registry

Amazon Elastic Container Registry (Amazon ECR) is a managed container image registry from Amazon Web
Services (AWS).

## Key capabilities

- **Private repositories:** Stores and manages OCI and Docker container images.
- **Image scanning:** Scans images for software vulnerabilities.
- **Lifecycle policies:** Cleans up unused images automatically.
- **Replication:** Replicates images across Regions and accounts.
