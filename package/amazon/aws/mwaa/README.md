# Amazon Managed Workflows for Apache Airflow

Amazon Managed Workflows for Apache Airflow (Amazon MWAA) is a managed Apache Airflow service from
Amazon Web Services (AWS).

## Key capabilities

- **Managed Airflow:** Runs Apache Airflow environments without managing infrastructure.
- **DAG storage:** Loads workflows (DAGs) from Amazon S3.
- **Scaling:** Scales workers with workload.
- **Security:** Runs in a VPC and controls access with IAM.
