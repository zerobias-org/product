# AWS Identity and Access Management

AWS Identity and Access Management (IAM) is a service from Amazon Web Services (AWS) that controls
access to AWS resources.

## Key capabilities

- **Identities:** Manages users, groups and roles.
- **Policies:** Defines permissions with JSON policy documents.
- **Federation:** Grants access to identities from external identity providers.
- **Access Analyzer:** Identifies resources shared outside an account and unused access.
