# AWS IoT Wireless

AWS IoT Wireless is the API of AWS IoT Core from Amazon Web Services (AWS) for connecting low-power
wireless devices, including AWS IoT Core for LoRaWAN and Amazon Sidewalk devices.

## Key capabilities

- **LoRaWAN devices:** Connects LoRaWAN devices and gateways to AWS IoT Core.
- **Amazon Sidewalk:** Connects Amazon Sidewalk devices to AWS IoT Core.
- **Device profiles:** Defines device and service profiles for wireless devices.
- **FUOTA:** Updates device firmware over the air.
