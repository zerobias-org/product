# AWS License Manager

AWS License Manager is a service from Amazon Web Services (AWS) for managing software licenses
across AWS and on-premises environments.

## Key capabilities

- **License configurations:** Defines license rules based on vendor terms.
- **Usage tracking:** Tracks license usage across resources.
- **Enforcement:** Limits launches that exceed license rules.
- **Cross-account:** Manages licenses across accounts in AWS Organizations.
