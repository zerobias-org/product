# Amazon Simple Queue Service

Amazon Simple Queue Service (Amazon SQS) is a managed message queuing service from Amazon Web
Services (AWS).

## Key capabilities

- **Standard queues:** Provide at-least-once delivery with high throughput.
- **FIFO queues:** Preserve message order and process each message exactly once.
- **Dead-letter queues:** Hold messages that could not be processed.
- **Encryption:** Encrypts messages with server-side encryption.
