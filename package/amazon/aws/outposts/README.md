# AWS Outposts

AWS Outposts is a family of managed solutions from Amazon Web Services (AWS) that runs AWS
infrastructure and services on premises.

## Key capabilities

- **On-premises AWS:** Runs AWS-designed hardware in a customer data center.
- **Local services:** Runs services such as EC2, EBS and RDS locally.
- **Form factors:** Offers Outposts racks and servers.
- **Consistent APIs:** Uses the same APIs and tools as the AWS Region.
