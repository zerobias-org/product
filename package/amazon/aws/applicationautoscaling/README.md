# AWS Application Auto Scaling

Application Auto Scaling is a service from Amazon Web Services (AWS) that automatically scales
resources of AWS services beyond Amazon EC2, such as ECS services, DynamoDB tables and Aurora
replicas.

## Key capabilities

- **Target tracking:** Scales capacity to keep a metric at a target value.
- **Step scaling:** Scales capacity in steps based on CloudWatch alarms.
- **Scheduled scaling:** Changes capacity on a schedule.
- **Multiple services:** Scales resources across many AWS services from one API.
