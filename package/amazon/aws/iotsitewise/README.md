# AWS IoT SiteWise

AWS IoT SiteWise is a managed service from Amazon Web Services (AWS) for collecting, storing and
analyzing industrial equipment data.

## Key capabilities

- **Data collection:** Collects data from industrial equipment through gateways.
- **Asset models:** Models industrial assets and their properties.
- **Metrics:** Computes metrics and transforms from asset data.
- **Monitoring:** Visualizes data in SiteWise Monitor portals.
