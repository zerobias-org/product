# AWS Step Functions

AWS Step Functions is a workflow orchestration service from Amazon Web Services (AWS). Workflows are
defined as state machines that coordinate AWS services.

## Key capabilities

- **State machines:** Defines workflows in the Amazon States Language.
- **Service integrations:** Calls AWS services directly from workflow steps.
- **Standard and Express workflows:** Offers long-running and high-volume workflow types.
- **Error handling:** Supports retries and catch logic per step.
