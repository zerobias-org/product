# Amazon Connect Customer conversational analytics

Conversational analytics, formerly Contact Lens, is a feature of Amazon Connect Customer from Amazon
Web Services (AWS). It analyzes customer conversations in the contact center.

## Key capabilities

- **Conversation analysis:** Transcribes calls and analyzes conversations.
- **Sentiment:** Measures customer and agent sentiment.
- **Redaction:** Redacts sensitive data from transcripts.
- **Rules and alerts:** Categorizes contacts and alerts supervisors based on rules.
