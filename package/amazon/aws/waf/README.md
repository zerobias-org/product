# AWS WAF

AWS WAF is a web application firewall from Amazon Web Services (AWS). It filters HTTP(S) requests to
resources such as Amazon CloudFront, Application Load Balancer and Amazon API Gateway.

## Key capabilities

- **Web ACLs:** Applies rules that allow, block or count requests.
- **Managed rule groups:** Provides rule sets maintained by AWS and AWS Marketplace sellers.
- **Rate-based rules:** Limits requests from a source over time.
- **Bot Control:** Detects and manages bot traffic.
- **Logging:** Logs inspected requests.
