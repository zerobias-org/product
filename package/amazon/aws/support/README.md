# AWS Support

AWS Support provides technical support plans and support cases for Amazon Web Services (AWS)
customers. The AWS Support API gives programmatic access to support cases and AWS Trusted Advisor
checks.

## Key capabilities

- **Support cases:** Creates, updates and resolves support cases.
- **Trusted Advisor:** Returns AWS Trusted Advisor check results, with API access depending on the
  support plan.
- **Support plans:** Offers plans with different response times and services.
