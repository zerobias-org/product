# AWS Marketplace Catalog API

The AWS Marketplace Catalog API is an API from Amazon Web Services (AWS) for managing product
listings in AWS Marketplace.

## Key capabilities

- **Entities:** Lists and describes catalog entities such as products and offers.
- **Change sets:** Changes listings by submitting change sets.
- **Offers:** Creates and updates private offers.
- **Programmatic publishing:** Automates listing management for sellers.
