# AWS CodeDeploy

AWS CodeDeploy is a deployment service from Amazon Web Services (AWS) that automates application
deployments.

## Key capabilities

- **Compute targets:** Deploys to Amazon EC2, on-premises servers, AWS Lambda and Amazon ECS.
- **Deployment strategies:** Supports in-place and blue/green deployments.
- **Rollback:** Rolls back deployments automatically on failure or alarms.
- **Monitoring:** Tracks deployment status and history.
