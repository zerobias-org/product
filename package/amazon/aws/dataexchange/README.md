# AWS Data Exchange

AWS Data Exchange is a service from Amazon Web Services (AWS) for finding, subscribing to and using
third-party data in the cloud.

## Key capabilities

- **Data catalog:** Lists data products from data providers.
- **Delivery methods:** Delivers data as files, APIs, Amazon Redshift datashares and S3 access.
- **Subscriptions:** Manages subscriptions and entitlements.
- **Provider tools:** Lets data providers publish and license data products.
