# Amazon Fraud Detector

Amazon Fraud Detector is a managed fraud detection service from Amazon Web Services (AWS). It is no
longer accepting new customers.

## Key capabilities

- **Fraud models:** Trains machine learning models on historical event data.
- **Detectors:** Combines models and rules into detectors that evaluate events.
- **Rules and outcomes:** Maps rule results to outcomes such as approve or review.
- **Real-time predictions:** Returns fraud predictions through an API.
