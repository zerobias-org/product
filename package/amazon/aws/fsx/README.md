# Amazon FSx

Amazon FSx is a family of managed file storage services from Amazon Web Services (AWS). It provides
file systems built on commercial and open-source file systems.

## Key capabilities

- **File system choices:** Offers FSx for Windows File Server, NetApp ONTAP, OpenZFS and Lustre.
- **Managed operations:** Handles provisioning, patching and backups.
- **Encryption:** Encrypts data at rest and supports encryption in transit.
- **Backups:** Supports automatic and user-initiated backups.
