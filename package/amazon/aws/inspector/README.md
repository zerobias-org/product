# Amazon Inspector

Amazon Inspector is a vulnerability management service from Amazon Web Services (AWS). It scans AWS
workloads for software vulnerabilities and unintended network exposure.

## Key capabilities

- **Automated scanning:** Scans EC2 instances, container images and Lambda functions.
- **Vulnerability findings:** Reports findings with risk scores.
- **Network reachability:** Detects unintended network exposure of EC2 instances.
- **Multi-account:** Manages accounts centrally through AWS Organizations.
