# AWS Resource Access Manager

AWS Resource Access Manager (AWS RAM) is a service from Amazon Web Services (AWS) for sharing
resources across AWS accounts.

## Key capabilities

- **Resource shares:** Shares resources such as subnets and transit gateways.
- **Organization sharing:** Shares resources within AWS Organizations.
- **Managed permissions:** Controls what principals can do with shared resources.
- **Invitations:** Accepts or rejects shares from other accounts.
