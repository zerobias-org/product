# AWS IAM Identity Center Identity Store

The Identity Store is the user and group directory of AWS IAM Identity Center (formerly AWS Single
Sign-On), a workforce identity service from Amazon Web Services (AWS). Its API manages the users and
groups in that directory.

## Key capabilities

- **Users:** Creates, reads, updates and deletes users.
- **Groups:** Creates, reads, updates and deletes groups.
- **Group memberships:** Manages which users belong to which groups.
- **Lookup:** Finds users and groups by unique attributes.
