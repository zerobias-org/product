# Amazon EC2 Instance Connect

Amazon EC2 Instance Connect is a feature from Amazon Web Services (AWS) for connecting to Linux EC2
instances over SSH using short-lived keys.

## Key capabilities

- **Temporary SSH keys:** Pushes a one-time SSH public key to the instance for 60 seconds.
- **IAM access control:** Controls SSH access with IAM policies.
- **Auditing:** Logs connection requests in AWS CloudTrail.
- **Console access:** Connects from the EC2 console or the AWS CLI.
