# AWS Cloud Map

AWS Cloud Map is a cloud resource discovery service from Amazon Web Services (AWS). Applications use
it to find the locations of their dependencies.

## Key capabilities

- **Service registry:** Registers application resources with custom names.
- **DNS and API discovery:** Lets clients discover resources through DNS or API calls.
- **Health checking:** Returns only healthy resource locations.
- **Custom attributes:** Stores attributes used to filter discovery results.
