# Amazon CloudSearch

Amazon CloudSearch is a managed search service from Amazon Web Services (AWS) for websites and
applications. It is no longer available to new customers; existing customers can continue to use it.

## Key capabilities

- **Managed search domains:** Sets up and runs search domains without managing servers.
- **Search features:** Supports full-text search, faceting, highlighting and autocomplete.
- **Scaling:** Scales search instances with data and traffic.
- **Languages:** Supports text processing for many languages.
