# Service Quotas

Service Quotas is a service from Amazon Web Services (AWS) for viewing and managing the quotas
(limits) that apply to AWS services in an account.

## Key capabilities

- **Quota visibility:** Shows default and applied quota values for AWS services.
- **Increase requests:** Submits and tracks requests to raise quotas.
- **Quota templates:** Applies quota increase requests automatically to new accounts in AWS
  Organizations.
- **Monitoring:** Works with Amazon CloudWatch to alarm on usage nearing a quota.
