# Amazon Textract

Amazon Textract is a machine learning service from Amazon Web Services (AWS) that extracts text,
handwriting and data from scanned documents.

## Key capabilities

- **Text detection:** Extracts printed and handwritten text.
- **Forms and tables:** Extracts key-value pairs and table data.
- **Queries:** Answers natural-language questions about a document.
- **Specialized documents:** Analyzes invoices, receipts and identity documents.
