# Amazon Elastic Container Service

Amazon Elastic Container Service (Amazon ECS) is a fully managed container orchestration service
from Amazon Web Services (AWS).

## Key capabilities

- **Task definitions:** Describes containers to run in task definitions.
- **Services:** Keeps a set number of tasks running and integrates with load balancers.
- **Capacity options:** Runs containers on AWS Fargate or Amazon EC2.
- **IAM roles for tasks:** Assigns IAM permissions to individual tasks.
