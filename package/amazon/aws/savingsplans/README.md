# AWS Savings Plans

AWS Savings Plans is a pricing model from Amazon Web Services (AWS). Customers commit to a
consistent amount of compute usage, measured in dollars per hour, for a one- or three-year term in
exchange for lower prices.

## Key capabilities

- **Compute Savings Plans:** Apply to compute usage across instance families, Regions and services
  such as AWS Fargate and AWS Lambda.
- **EC2 Instance Savings Plans:** Apply to a specific instance family in a chosen Region.
- **Recommendations:** Suggests commitments based on past usage.
- **Reporting:** Reports utilization and coverage of active plans.
