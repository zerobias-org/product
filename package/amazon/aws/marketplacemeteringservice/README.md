# AWS Marketplace Metering Service

The AWS Marketplace Metering Service is an API from Amazon Web Services (AWS) that lets sellers
report usage for usage-based AWS Marketplace products.

## Key capabilities

- **Usage reporting:** Reports customer usage for billing.
- **Batch metering:** Submits usage records for multiple customers.
- **Registration:** Verifies that a customer is subscribed to a product.
- **Container products:** Supports metering for container-based products.
