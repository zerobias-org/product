# AWS Firewall Manager

AWS Firewall Manager is a security management service from Amazon Web Services (AWS). It configures
and manages firewall rules across accounts in AWS Organizations.

## Key capabilities

- **Central policies:** Applies security policies across accounts and resources.
- **Supported protections:** Manages AWS WAF, AWS Shield Advanced, security groups and AWS Network
  Firewall.
- **Automatic enforcement:** Applies policies to new resources as they are created.
- **Compliance view:** Reports resources that are not compliant with policies.
