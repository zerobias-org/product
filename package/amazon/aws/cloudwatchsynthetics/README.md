# Amazon CloudWatch Synthetics

Amazon CloudWatch Synthetics is a feature of Amazon CloudWatch from Amazon Web Services (AWS). It
runs canaries, scripts that monitor endpoints and APIs on a schedule.

## Key capabilities

- **Canaries:** Runs configurable scripts on a schedule to check endpoints and APIs.
- **Blueprints:** Provides canary templates for common checks such as heartbeats and broken links.
- **Screenshots and logs:** Captures screenshots, HAR files and logs from runs.
- **Alarms:** Integrates with CloudWatch metrics and alarms.
