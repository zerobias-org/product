# Amazon RDS Data API

The Amazon RDS Data API is an HTTPS API from Amazon Web Services (AWS) for running SQL statements on
Amazon Aurora databases.

## Key capabilities

- **SQL over HTTPS:** Runs SQL statements without managing database connections.
- **Transactions:** Supports transactions and batch statements.
- **Secrets Manager:** Authenticates with credentials stored in AWS Secrets Manager.
- **Serverless use:** Suits applications such as AWS Lambda functions.
