# Amazon OpenSearch Service

Amazon OpenSearch Service is a managed search and analytics service from Amazon Web Services (AWS).
It was formerly called Amazon Elasticsearch Service.

## Key capabilities

- **Managed clusters:** Runs OpenSearch and legacy Elasticsearch domains.
- **Serverless:** Runs search and analytics workloads with OpenSearch Serverless.
- **Dashboards:** Visualizes data with OpenSearch Dashboards.
- **Security:** Supports fine-grained access control and encryption.
