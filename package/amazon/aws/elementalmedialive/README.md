# AWS Elemental MediaLive

AWS Elemental MediaLive is a live video processing service from Amazon Web Services (AWS). It
encodes live video streams for broadcast and streaming delivery.

## Key capabilities

- **Live encoding:** Encodes live video for broadcast television and internet streaming.
- **Channels and inputs:** Processes video from inputs through channels to output groups.
- **Pipeline redundancy:** Supports standard channels with two pipelines for resilience.
- **Integration:** Sends output to services such as AWS Elemental MediaPackage.
