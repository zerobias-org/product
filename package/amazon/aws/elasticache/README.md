# Amazon ElastiCache

Amazon ElastiCache is a fully managed in-memory caching service from Amazon Web Services (AWS),
compatible with Valkey, Memcached and Redis OSS.

## Key capabilities

- **In-memory caching:** Stores data in memory for low-latency access.
- **Engines:** Supports Valkey, Memcached and Redis OSS.
- **Serverless:** Offers a serverless option that scales automatically.
- **High availability:** Supports replication and automatic failover.
