# AWS Shield Advanced

AWS Shield Advanced is a paid DDoS protection service from Amazon Web Services (AWS). It adds
protections on top of AWS Shield Standard for resources such as Amazon CloudFront, Elastic Load
Balancing, Amazon Route 53 and Elastic IP addresses.

## Key capabilities

- **DDoS detection and mitigation:** Detects and mitigates network- and application-layer DDoS
  events on protected resources.
- **Shield Response Team:** Gives access to the AWS Shield Response Team during events.
- **Visibility:** Reports attack metrics and event history.
- **Cost protection:** Offers protection against scaling charges caused by DDoS attacks.
