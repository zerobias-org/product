# Amazon Timestream

Amazon Timestream is a family of managed time-series database services from Amazon Web Services
(AWS). It includes Amazon Timestream for LiveAnalytics, which is no longer open to new customers,
and Amazon Timestream for InfluxDB.

## Key capabilities

- **Timestream for InfluxDB:** Runs managed InfluxDB databases.
- **Timestream for LiveAnalytics:** Stores and queries time-series data with SQL for existing
  customers.
- **Data tiering:** LiveAnalytics keeps recent data in memory and moves older data to a magnetic
  store.
