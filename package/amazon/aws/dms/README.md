# AWS Database Migration Service

AWS Database Migration Service (AWS DMS) is a managed service from Amazon Web Services (AWS) for
migrating and replicating databases and analytics workloads to AWS.

## Key capabilities

- **Homogeneous and heterogeneous migration:** Migrates between the same or different database
  engines.
- **Change data capture:** Replicates ongoing changes from the source.
- **Schema conversion:** Converts database schemas with DMS Schema Conversion.
- **Serverless:** Offers a serverless option that scales capacity automatically.
