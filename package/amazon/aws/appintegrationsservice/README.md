# Amazon AppIntegrations

Amazon AppIntegrations is a service from Amazon Web Services (AWS) for integrating external
applications and data with Amazon Connect Customer. Its API is documented with the Amazon Connect
Customer API.

## Key capabilities

- **Data integrations:** Defines integrations that bring external application data into Amazon
  Connect Customer.
- **Event integrations:** Sets up event integrations with sources such as Amazon EventBridge.
- **Application registration:** Registers third-party applications for use in the agent workspace.
