# AWS Data Pipeline

AWS Data Pipeline is a web service from Amazon Web Services (AWS) for automating the movement and
transformation of data. It is in maintenance mode and no longer available to new customers; existing
customers can continue to use it.

## Key capabilities

- **Pipeline definitions:** Defines data-driven workflows with scheduled activities.
- **Data movement:** Moves data between AWS compute and storage services and on-premises sources.
- **Retries:** Retries failed activities and sends failure notifications.
