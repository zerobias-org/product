# Amazon API Gateway

Amazon API Gateway is a fully managed service from Amazon Web Services (AWS) for creating,
publishing, securing and monitoring APIs at any scale.

## Key capabilities

- **API types:** Supports REST, HTTP and WebSocket APIs.
- **Access control:** Controls access with IAM, Lambda authorizers and Amazon Cognito.
- **Traffic management:** Applies throttling, quotas and usage plans.
- **Monitoring:** Integrates with CloudWatch metrics and logs.
