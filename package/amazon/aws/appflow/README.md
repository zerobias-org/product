# Amazon AppFlow

Amazon AppFlow is a fully managed integration service from Amazon Web Services (AWS). It transfers
data between SaaS applications and AWS services.

## Key capabilities

- **SaaS connectors:** Connects to SaaS applications such as Salesforce, ServiceNow and Slack.
- **Flow triggers:** Runs flows on demand, on a schedule or in response to events.
- **Data transformation:** Maps, filters and validates fields during transfer.
- **Encryption:** Encrypts data in transit and at rest.
