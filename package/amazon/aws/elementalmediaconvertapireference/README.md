# AWS Elemental MediaConvert

AWS Elemental MediaConvert is a file-based video transcoding service from Amazon Web Services (AWS).
It converts media files into formats for broadcast and multiscreen delivery.

## Key capabilities

- **File-based transcoding:** Converts source video files into output formats and packages.
- **Jobs and queues:** Runs transcoding jobs that are managed through queues.
- **Job templates and presets:** Reuses settings through job templates and output presets.
- **API access:** Exposes transcoding through an API, SDKs and the AWS CLI.
