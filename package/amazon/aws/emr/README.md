# Amazon EMR

Amazon EMR is a managed big data platform from Amazon Web Services (AWS). It runs open-source
frameworks such as Apache Spark, Apache Hive and Presto.

## Key capabilities

- **Managed clusters:** Provisions and manages clusters on Amazon EC2.
- **Deployment options:** Runs on EC2, on Amazon EKS and as EMR Serverless.
- **Open-source frameworks:** Supports Apache Spark, Hive, HBase, Presto and other frameworks.
- **Data storage:** Reads and writes data in Amazon S3 and HDFS.
