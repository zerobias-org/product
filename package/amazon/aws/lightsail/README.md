# Amazon Lightsail

Amazon Lightsail is a service from Amazon Web Services (AWS) that offers virtual servers, storage,
databases and networking at a fixed monthly price.

## Key capabilities

- **Instances:** Runs virtual private servers from preconfigured blueprints.
- **Managed databases:** Provides managed MySQL and PostgreSQL databases.
- **Containers:** Runs container services.
- **Networking:** Includes load balancers, static IPs, DNS and a content delivery network.
