# Amazon Managed Service for Apache Flink

Amazon Managed Service for Apache Flink is a managed service from Amazon Web Services (AWS) for
processing streaming data with Apache Flink. It was formerly called Amazon Kinesis Data Analytics.

## Key capabilities

- **Managed Apache Flink:** Runs Apache Flink applications without managing servers.
- **Streaming sources:** Reads from Amazon Kinesis Data Streams and Amazon MSK.
- **Scaling:** Scales application capacity with Kinesis Processing Units.
- **Snapshots:** Saves application state with snapshots.
