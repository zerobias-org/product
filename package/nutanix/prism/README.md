# Nutanix Prism

Nutanix Prism is the management plane for Nutanix infrastructure from Nutanix. It manages clusters,
virtual machines and storage from one interface.

## Key capabilities

- **Prism Element:** Manages a single Nutanix cluster.
- **Prism Central:** Manages multiple clusters from one console.
- **Monitoring and alerts:** Shows performance data and raises alerts with configurable policies.
- **APIs:** Exposes REST APIs for automation.
