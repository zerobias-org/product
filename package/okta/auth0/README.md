# Auth0

Auth0 is a customer identity and access management platform from Okta. Developers use it to add
authentication and authorization to applications.

## Key capabilities

- **Universal Login:** Provides a hosted login page.
- **Connections:** Supports social, enterprise and database connections.
- **Multi-factor authentication:** Adds MFA to logins.
- **Management API:** Manages users, applications and settings through an API.
