# Okta

Okta is an identity platform from Okta. Its Workforce Identity products manage employee access to
applications.

## Key capabilities

- **Single sign-on:** Provides SSO to cloud and on-premises applications.
- **Multi-factor authentication:** Adds adaptive MFA to sign-ins.
- **Lifecycle management:** Provisions and deprovisions users in connected applications.
- **Universal Directory:** Stores users and groups in one directory.
