# ConnectWise PSA

ConnectWise PSA is a professional services automation product from ConnectWise for managed service
providers and technology solution providers.

## Key capabilities

- **Service desk:** Manages service tickets and SLAs.
- **Project management:** Tracks projects, tasks and resources.
- **Time and billing:** Tracks time and creates invoices.
- **Sales and CRM:** Manages opportunities, quotes and contacts.
- **API:** Provides a REST API.
