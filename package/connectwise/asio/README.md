# ConnectWise Platform

The ConnectWise Platform (previously branded ConnectWise Asio) is the IT management platform from
ConnectWise for managed service providers (MSPs). It connects ConnectWise products such as PSA, RMM
and remote access.

## Key capabilities

- **Service management:** Includes professional services automation (PSA).
- **Endpoint management:** Includes remote monitoring and management (RMM).
- **Remote access:** Includes ScreenConnect remote access.
- **Security:** Includes SIEM and other cybersecurity services.
