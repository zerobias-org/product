# Falco

Falco is an open source runtime security tool for hosts, containers, Kubernetes and cloud
environments. It is a graduated project of the Cloud Native Computing Foundation (CNCF).

## Key capabilities

- **Runtime detection:** Detects suspicious behavior by watching system calls and other events.
- **Rules:** Uses configurable rules to define what to alert on.
- **Kubernetes context:** Adds container and Kubernetes metadata to alerts.
- **Plugins:** Extends event sources with plugins.
