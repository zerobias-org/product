# Iru

Iru (formerly Kandji) is an IT and security platform from Iru for managing and securing devices. It
started as an Apple device management product and keeps the Kandji API endpoints.

## Key capabilities

- **Device management:** Enrolls and configures Apple devices with Blueprints and Library items.
- **Compliance:** Applies security baselines and tracks device compliance.
- **Identity:** Connects device management with user identity.
- **API:** Exposes device data through a REST API.
