# Open Cybersecurity Schema Framework

The Open Cybersecurity Schema Framework (OCSF) is an open-source, vendor-neutral schema for
cybersecurity event and finding data.

## Key capabilities

- **Event classes:** Defines event classes grouped into categories.
- **Attributes and objects:** Defines a shared dictionary of attributes and objects.
- **Profiles and extensions:** Supports profiles and vendor extensions.
- **Schema browser:** Publishes the schema in a browsable server.
