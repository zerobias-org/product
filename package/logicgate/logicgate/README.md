# LogicGate Risk Cloud

Risk Cloud is a governance, risk and compliance (GRC) platform from LogicGate. Organizations use it
to build and run risk and compliance programs.

## Key capabilities

- **Risk management:** Tracks risks, assessments and mitigation work.
- **Compliance management:** Maps controls to frameworks and tracks compliance.
- **Third-party risk:** Runs vendor risk assessments.
- **No-code workflows:** Builds GRC applications and workflows without code.
- **API:** Exposes data through a REST API.
