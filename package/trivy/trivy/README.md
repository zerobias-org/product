# Trivy

Trivy is an open-source security scanner from Aqua Security. It scans many kinds of targets for
vulnerabilities and misconfigurations.

## Key capabilities

- **Vulnerability scanning:** Finds known vulnerabilities (CVEs) in packages and dependencies.
- **Misconfiguration scanning:** Checks infrastructure as code and Kubernetes for misconfigurations.
- **Many targets:** Scans container images, file systems, code repositories and Kubernetes clusters.
- **SBOM and secrets:** Generates software bills of materials and detects secrets.
