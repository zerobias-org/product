# KarmaCheck

KarmaCheck is a background check platform from KarmaCheck, Inc. Employers use it to run
pre-employment screening.

## Key capabilities

- **Background checks:** Runs criminal, employment, education and other screening checks.
- **Candidate experience:** Lets candidates complete checks on mobile or web.
- **Integrations:** Connects with applicant tracking and HR systems.
