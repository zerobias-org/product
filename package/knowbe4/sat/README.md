# KnowBe4 Security Awareness Training

KnowBe4 Security Awareness Training is a security awareness and simulated phishing platform from
KnowBe4. It trains employees to spot social engineering attacks.

## Key capabilities

- **Training library:** Provides a library of security awareness training content.
- **Simulated phishing:** Sends simulated phishing emails to test users.
- **Phish Alert Button:** Lets users report suspicious emails from their mail client.
- **Reporting:** Reports on training completion and phishing results.
