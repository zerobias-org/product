# Tanium Platform

The Tanium Platform is an endpoint management and security platform from Tanium. It collects
real-time data from endpoints and acts on it at scale.

## Key capabilities

- **Asset visibility:** Inventories endpoints, software and hardware in real time.
- **Patch and vulnerability management:** Finds and remediates vulnerabilities and missing patches.
- **Endpoint control:** Deploys software and enforces configurations.
- **Incident response:** Investigates and responds to threats on endpoints.
