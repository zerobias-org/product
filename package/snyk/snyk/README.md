# Snyk

Snyk is a developer security platform from Snyk. It finds and helps fix security issues in code,
dependencies, containers and infrastructure as code.

## Key capabilities

- **Snyk Code:** Scans application source code for security issues.
- **Snyk Open Source:** Finds vulnerabilities and license issues in dependencies.
- **Snyk Container:** Scans container images.
- **Snyk IaC:** Checks infrastructure as code for misconfigurations.
