# NAVEX IRM

NAVEX IRM (formerly Lockpath) is an integrated risk management platform from NAVEX.

## Key capabilities

- **Risk data aggregation:** Collects data from assessments, audits, authoritative sources and other
  systems.
- **Correlation:** Connects risk data to show dependencies.
- **Out-of-the-box content:** Provides prebuilt personas, dashboards, reports and templates.
