# Linear

Linear is a project and issue tracking tool from Linear Orbit, Inc. Software teams use it to plan
and track issues, projects and cycles.

## Key capabilities

- **Issue tracking:** Tracks issues with statuses, priorities and labels.
- **Projects and cycles:** Groups work into projects and time-boxed cycles.
- **Integrations:** Connects with GitHub, GitLab, Slack and other tools.
- **API:** Exposes data through a GraphQL API and webhooks.
