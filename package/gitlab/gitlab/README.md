# GitLab

GitLab is a DevSecOps platform from GitLab Inc. It combines source code management, CI/CD and
security testing in one application.

## Key capabilities

- **Source code management:** Hosts Git repositories with merge requests and code review.
- **CI/CD:** Runs pipelines defined in a configuration file.
- **Security testing:** Provides SAST, dependency scanning and other scanners.
- **Planning:** Tracks work with issues, epics and boards.
- **Deployment:** Available as a SaaS offering and self-managed.
