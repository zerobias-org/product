# Zoho CRM

Zoho CRM is a customer relationship management application from Zoho Corporation. It is included in
the Zoho One suite.

## Key capabilities

- **Sales management:** Manages leads, contacts, accounts and deals.
- **Automation:** Automates sales processes with workflows.
- **Analytics:** Provides reports and dashboards.
- **APIs:** Offers REST APIs for integrations.
