# Zoho Creator

Zoho Creator is a low-code application development platform from Zoho Corporation. It is included in
the Zoho One suite.

## Key capabilities

- **Low-code apps:** Builds business apps with forms, reports and workflows.
- **Automation:** Automates processes with workflows and Deluge scripting.
- **Integrations:** Connects to other Zoho apps and external services.
