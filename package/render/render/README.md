# Render

Render is a cloud platform from Render for building and running web applications, services
and websites.

## Key capabilities

- **Managed hosting:** Runs web services, static sites, background workers and cron jobs.
- **Git deploys:** Deploys automatically from Git repositories.
- **Managed data stores:** Offers managed PostgreSQL and key-value stores.
- **Networking:** Provides TLS certificates, a CDN for static sites and private networking.
