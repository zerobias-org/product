# HCPCS Level II

HCPCS Level II is the alphanumeric code set of the Healthcare Common Procedure Coding System,
maintained by the Centers for Medicare & Medicaid Services (CMS). It covers products, supplies and
services not included in CPT codes, such as durable medical equipment, ambulance services and
certain drugs.

## Key capabilities

- **Standardized codes:** Identifies products, supplies and services for claims processing.
- **Quarterly updates:** CMS publishes updated code files on a quarterly schedule.
- **Public files:** Code files are available for download from CMS.
