# Hudu

Hudu is IT documentation software from Hudu Technologies. IT teams and managed service providers
(MSPs) use it to keep company, asset and password records in one place.

## Key capabilities

- **IT documentation:** Stores articles, procedures and asset records per company.
- **Password management:** Keeps shared credentials in an access-controlled vault.
- **Integrations:** Syncs data from PSA, RMM and other IT tools.
- **REST API:** Exposes documentation and assets through a REST API.
