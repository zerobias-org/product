# Shortcut

Shortcut is a project management tool for software teams. It combines issue tracking, planning and
documentation.

## Key capabilities

- **Issue tracking:** Tracks work as stories, epics and objectives.
- **Sprint planning:** Plans work in iterations.
- **Docs:** Keeps documents next to the work they describe.
- **API:** Offers a REST API for integrations.
