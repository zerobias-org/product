# Snipe-IT

Snipe-IT is an open source IT asset management application made by Grokability. It is available
self-hosted or as a hosted service.

## Key capabilities

- **Asset tracking:** Tracks hardware assets and who they are checked out to.
- **Licenses and consumables:** Tracks software licenses, accessories, consumables and components.
- **Audit history:** Keeps a history of check-outs, check-ins and changes.
- **REST API:** Exposes assets and other records through a REST API.
