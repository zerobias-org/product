# EasyConnect Jaguar

EasyConnect Jaguar is a healthcare interface engine from Iatric Systems. It moves and transforms
data between EHRs and other clinical systems.

## Key capabilities

- **Interface engine:** Routes messages between EHR, lab, radiology and other clinical systems.
- **EHR-agnostic:** Works with different EHR products rather than a single vendor.
- **Visual configuration:** Builds filters, templates and data mappings with drag-and-drop tools.
- **Monitoring:** Includes iAlert monitoring to detect interface problems.
