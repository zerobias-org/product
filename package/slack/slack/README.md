# Slack

Slack is a messaging and collaboration platform for teams, owned by Salesforce.

## Key capabilities

- **Channels:** Organizes conversations by team, project or topic.
- **Messaging and huddles:** Supports direct messages, audio and video huddles.
- **Integrations:** Connects with other apps and offers workflow automation.
- **APIs:** Offers APIs for building Slack apps.
