# Access It!

Access It! is on-premises access control software, originally from RS2 Technologies and now offered
by Acre Security. It runs on non-proprietary Mercury controller hardware.

## Key capabilities

- **Access control:** Manages doors, credentials and access rights.
- **Monitoring:** Provides real-time monitoring and command functions.
- **Desktop and web clients:** Offers desktop, web and mobile access.
- **API:** Provides a RESTful API for integrations.
