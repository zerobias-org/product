# monday.com Work Management

monday.com Work Management is a work management platform from monday.com. Teams use it to plan,
track and manage projects and workflows.

## Key capabilities

- **Boards:** Organizes work in boards with customizable columns.
- **Views:** Shows work as tables, kanban, timelines, calendars and dashboards.
- **Automations:** Automates repetitive steps with rule-based recipes.
- **Integrations:** Connects to other tools and provides a GraphQL API.
