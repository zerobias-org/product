# ServiceNow Governance, Risk, and Compliance

ServiceNow Governance, Risk, and Compliance (GRC) is a set of applications from ServiceNow that run
on the ServiceNow AI Platform. It helps organizations manage policies, risks, controls and audits.

## Key capabilities

- **Policy and compliance:** Manages policies, control objectives and compliance status.
- **Risk management:** Identifies, assesses and tracks risks.
- **Audit management:** Plans and runs internal audits.
- **Platform integration:** Uses data and workflows from the wider ServiceNow platform.
