# ServiceNow

ServiceNow is a cloud platform from ServiceNow, Inc. for digital workflows across IT, employee and
customer services.

## Key capabilities

- **IT service management:** Handles incidents, problems, changes and requests.
- **Workflow automation:** Builds and runs workflows across departments.
- **Configuration management:** Tracks IT assets and services in a configuration management database.
- **App development:** Lets teams build custom apps on the platform.
