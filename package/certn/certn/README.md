# Certn

Certn is a background screening platform from Certn for employers and property managers.

## Key capabilities

- **Background checks:** Runs criminal record, international and public records checks.
- **Verifications:** Verifies identity, employment, education and credentials.
- **Ongoing monitoring:** Re-checks results after hire.
- **API and integrations:** Provides a screening API and integrations with ATS and HR tools.
