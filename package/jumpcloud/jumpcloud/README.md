# JumpCloud

JumpCloud is a cloud directory platform from JumpCloud Inc. It manages user identities, access and
devices from one console.

## Key capabilities

- **Cloud directory:** Stores users and groups and connects them to systems and apps.
- **Single sign-on:** Provides SSO to SAML and OIDC applications.
- **Multi-factor authentication:** Adds MFA to logins for devices and apps.
- **Device management:** Manages Windows, macOS and Linux devices with policies.
- **APIs:** Exposes directory and device data through REST APIs.
