# Workday Human Capital Management

Workday Human Capital Management (HCM) is a cloud HR application suite from Workday, Inc.

## Key capabilities

- **Core HR:** Manages workers, organizations and HR records.
- **Talent:** Supports recruiting, performance and learning.
- **Workforce planning:** Supports headcount planning and analytics.
