# ZenGRC

ZenGRC is a governance, risk and compliance (GRC) software platform. It helps organizations manage
compliance frameworks, risk and audits.

## Key capabilities

- **Compliance:** Collects evidence and maps controls across frameworks.
- **Audit management:** Runs assessments, requests and issue tracking for audits.
- **Risk management:** Tracks risks with dashboards and reporting.
- **Vendor management:** Assesses third-party risk with questionnaires.
