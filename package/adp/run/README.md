# RUN Powered by ADP

RUN Powered by ADP is a payroll and HR platform from ADP for small businesses.

## Key capabilities

- **Payroll:** Runs payroll and pays employees.
- **Payroll taxes:** Calculates and files payroll taxes.
- **HR tools:** Provides HR features such as employee records and onboarding.
- **Integrations:** Connects to other business apps through the ADP Marketplace.
