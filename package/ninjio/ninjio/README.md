# NINJIO

NINJIO is a cybersecurity awareness training platform from NINJIO. It uses short animated episodes
based on real incidents to train employees.

## Key capabilities

- **Awareness training:** Delivers microlearning episodes (NINJIO AWARE).
- **Phishing simulation:** Runs phishing simulations (NINJIO PHISH3D).
- **Personalized coaching:** Coaches users based on their susceptibility profile (NINJIO SENSE).
- **Phish reporting:** Lets users report suspected phishing to responders (NINJIO ALERT).
