# Allgress

Allgress is a governance, risk and compliance (GRC) platform from Allgress. It helps organizations
manage security compliance, risk and vendor assessments.

## Key capabilities

- **Compliance management:** Tracks compliance with security and privacy frameworks.
- **Risk register:** Records and manages risks in a central register.
- **Vendor risk management:** Assesses and tracks third-party vendor risk.
- **Policy management:** Manages policies and analyzes policy gaps.
