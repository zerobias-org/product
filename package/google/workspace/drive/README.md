# Google Drive

Google Drive is the cloud file storage and sharing service in Google Workspace.

## Key capabilities

- **File storage:** Stores files in the cloud and syncs them across devices.
- **Sharing:** Shares files and folders with users, groups and links.
- **Shared drives:** Stores team files that belong to the organization rather than a person.
- **Drive API:** Lets applications read, write and manage files.
