# Google Workspace Admin console

The Google Workspace Admin console is where administrators manage users, services, devices and
security settings for a Google Workspace organization. The Admin SDK provides API access to the same
administration tasks.

## Key capabilities

- **User and group management:** Creates and manages user accounts, groups and organizational units.
- **Service settings:** Turns Google Workspace services on or off and configures them.
- **Security settings:** Configures 2-Step Verification, SSO and other security controls.
- **Admin SDK:** Exposes directory, reports and other admin APIs.
