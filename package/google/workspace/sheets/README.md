# Google Sheets

Google Sheets is the online spreadsheet application in Google Workspace.

## Key capabilities

- **Spreadsheets:** Creates and edits spreadsheets in the browser and on mobile.
- **Collaboration:** Lets several people edit the same spreadsheet at once.
- **Functions and charts:** Calculates with formulas and visualizes data with charts.
- **Sheets API:** Lets applications read and write spreadsheet data.
