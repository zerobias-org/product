# Cloud Key Management Service

Cloud Key Management Service (Cloud KMS) is a Google Cloud service for creating and managing
cryptographic keys.

## Key capabilities

- **Key management:** Creates, rotates and destroys symmetric and asymmetric keys.
- **Protection levels:** Stores keys in software, in Cloud HSM or in an external key manager.
- **Customer-managed encryption keys:** Encrypts data in other Google Cloud services with your keys.
- **Access control and logging:** Controls key use with IAM and records it in Cloud Audit Logs.
