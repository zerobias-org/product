# Cloud Scheduler

Cloud Scheduler is a managed cron job service from Google Cloud.

## Key capabilities

- **Cron schedules:** Runs jobs on schedules written in unix-cron format.
- **Targets:** Calls HTTP endpoints, publishes Pub/Sub messages or calls App Engine.
- **Retries:** Retries failed jobs with configurable backoff.
