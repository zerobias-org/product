# Assured Workloads

Assured Workloads is a Google Cloud service for running workloads that must meet regulatory and data
residency requirements.

## Key capabilities

- **Control packages:** Applies controls for compliance programs such as FedRAMP and CJIS.
- **Data residency:** Restricts resource locations.
- **Personnel controls:** Limits access by Google personnel.
- **Monitoring:** Detects changes that violate the workload's controls.
