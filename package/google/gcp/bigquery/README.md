# BigQuery

BigQuery is a serverless data warehouse from Google Cloud.

## Key capabilities

- **SQL analytics:** Runs SQL queries over large datasets.
- **Managed storage:** Stores data in managed, columnar storage.
- **Data ingestion:** Loads data in batch or streams it in.
- **BigQuery ML:** Creates and runs machine learning models with SQL.
- **Access control:** Controls access with IAM at the dataset, table, column and row level.
