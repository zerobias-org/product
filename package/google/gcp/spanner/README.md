# Spanner

Spanner is a fully managed, horizontally scalable relational database from Google Cloud with strong
consistency.

## Key capabilities

- **Horizontal scaling:** Adds compute capacity to scale reads and writes.
- **Strong consistency:** Provides externally consistent transactions.
- **SQL dialects:** Supports GoogleSQL and PostgreSQL dialects.
- **Multi-region configurations:** Replicates data across regions for availability.
