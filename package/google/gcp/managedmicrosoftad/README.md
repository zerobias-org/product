# Managed Service for Microsoft Active Directory

Managed Service for Microsoft Active Directory (Managed Microsoft AD) is a Google Cloud service that
runs Microsoft Active Directory domain controllers for you.

## Key capabilities

- **Managed domain controllers:** Runs highly available Active Directory domain controllers.
- **Trusts:** Connects to on-premises Active Directory domains through trusts.
- **AD-dependent workloads:** Supports Windows workloads that need Active Directory.
