# Eventarc

Eventarc is a Google Cloud service for routing events from Google Cloud services, SaaS applications
and your own applications to event targets.

## Key capabilities

- **Event routing:** Delivers events to targets such as Cloud Run services and Workflows.
- **Event sources:** Receives events from Google Cloud services, Cloud Audit Logs and Pub/Sub.
- **CloudEvents format:** Delivers events in the CloudEvents format.
