# Apigee

Apigee is an API management platform from Google Cloud.

## Key capabilities

- **API proxies:** Puts proxies in front of backend services.
- **Policies:** Applies security, traffic and transformation policies.
- **Developer portal:** Publishes APIs to developers.
- **Analytics:** Reports on API traffic and performance.
