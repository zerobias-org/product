# Cloud Billing

Cloud Billing is the Google Cloud service for managing how Google Cloud usage is paid for. Cloud
Billing accounts are linked to projects and track their costs.

## Key capabilities

- **Billing accounts:** Links projects to Cloud Billing accounts that pay for their usage.
- **Budgets and alerts:** Sets budgets and sends alerts when spending reaches thresholds.
- **Cost reports and export:** Shows cost reports and exports billing data to BigQuery.
- **Billing API:** Manages billing accounts and project billing links programmatically.
