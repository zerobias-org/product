# Dataproc Metastore

Dataproc Metastore is a fully managed Apache Hive metastore service from Google Cloud.

## Key capabilities

- **Managed Hive metastore:** Runs a Hive metastore without managing servers.
- **Shared metadata:** Stores table metadata used by Spark, Hive and other data processing engines.
- **Backups:** Backs up and restores metastore data.
