# Resource Manager

Resource Manager is the Google Cloud service for managing the resource hierarchy of organizations,
folders and projects.

## Key capabilities

- **Resource hierarchy:** Organizes projects under folders and an organization.
- **Policy inheritance:** Applies IAM and organization policies down the hierarchy.
- **Tags:** Attaches tags to resources for policy and billing use.
- **Project lifecycle:** Creates, moves and deletes projects.
