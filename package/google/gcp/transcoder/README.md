# Transcoder API

The Transcoder API is a Google Cloud service for converting video files into formats for streaming
and playback.

## Key capabilities

- **Transcoding jobs:** Converts input videos into one or more output formats.
- **Streaming formats:** Creates HLS and MPEG-DASH output.
- **Job templates:** Reuses job configurations through templates.
