# Cloud Talent Solution

Cloud Talent Solution is a Google Cloud API for job search and job matching on career sites and job
boards.

## Key capabilities

- **Job search:** Searches job listings using machine learning models of job titles and skills.
- **Job and company data:** Stores and manages job postings and company records.
- **Search filters:** Filters jobs by location, commute time and other attributes.
