# Memorystore

Memorystore is a Google Cloud family of managed in-memory data store services.

## Key capabilities

- **Managed engines:** Runs managed Valkey, Redis and Memcached instances.
- **High availability:** Replicates data and fails over automatically on supported tiers.
- **Private networking:** Connects to instances over private VPC networking.
