# Video Intelligence API

The Video Intelligence API is a Google Cloud service that uses machine learning to analyze video
content.

## Key capabilities

- **Label detection:** Identifies objects, places and activities in video.
- **Shot change detection:** Detects shot changes in a video.
- **Text and object tracking:** Detects text and tracks objects across frames.
- **Explicit content detection:** Flags explicit content in video.
