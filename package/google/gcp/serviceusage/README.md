# Service Usage

Service Usage is the Google Cloud service for listing, enabling and disabling the APIs and services
that projects use.

## Key capabilities

- **API enablement:** Enables and disables services for a project.
- **Service listing:** Lists available and enabled services.
- **Quota management:** Views and manages service quotas.
