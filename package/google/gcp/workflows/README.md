# Workflows

Workflows is a Google Cloud orchestration service that runs a series of steps, such as calls to
Google Cloud services and HTTP APIs, in a defined order.

## Key capabilities

- **Workflow definitions:** Defines steps in YAML or JSON.
- **Service connectors:** Calls Google Cloud APIs through built-in connectors.
- **Executions:** Runs workflows and tracks each execution and its result.
- **Error handling:** Retries steps and catches errors.
