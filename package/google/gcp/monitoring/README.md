# Cloud Monitoring

Cloud Monitoring is a Google Cloud Observability service that collects metrics and lets you chart
and alert on them.

## Key capabilities

- **Metrics collection:** Collects metrics from Google Cloud services, VMs and applications.
- **Dashboards:** Charts metrics on predefined and custom dashboards.
- **Alerting:** Sends notifications when metrics meet alerting policy conditions.
- **Uptime checks:** Checks the availability of public and private endpoints.
