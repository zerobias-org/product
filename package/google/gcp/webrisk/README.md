# Web Risk

Web Risk is a Google Cloud service that lets applications check URLs against Google's lists of
unsafe web resources.

## Key capabilities

- **URL checks:** Checks URLs against lists of malware, social engineering and unwanted software
  sites.
- **Local lists:** Downloads hashed threat lists for checks on the client side.
- **Submission:** Submits suspected unsafe URLs to Google for review.
