# Cloud Tasks

Cloud Tasks is a managed Google Cloud service for queuing and dispatching asynchronous work.

## Key capabilities

- **Task queues:** Adds tasks to queues for later execution.
- **HTTP targets:** Dispatches tasks to HTTP endpoints and App Engine.
- **Rate and retry control:** Configures dispatch rates and retry behavior per queue.
