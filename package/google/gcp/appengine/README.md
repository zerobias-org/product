# App Engine

App Engine is a managed application platform from Google Cloud. The App Engine Admin API manages App
Engine applications and their services, versions and instances.

## Key capabilities

- **Managed runtime:** Runs applications without managing servers.
- **Environments:** Offers standard and flexible environments.
- **Versions and traffic:** Deploys versions and splits traffic between them.
- **Admin API:** Manages applications programmatically.
