# Document AI

Document AI is a Google Cloud service that uses machine learning to extract structured data from
documents.

## Key capabilities

- **Processors:** Offers prebuilt processors for OCR, forms and specialized document types.
- **Custom extraction:** Trains custom processors to extract fields from your documents.
- **Document classification:** Classifies and splits documents by type.
