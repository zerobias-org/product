# Dataflow

Dataflow is a managed Google Cloud service for running batch and streaming data pipelines built with
Apache Beam.

## Key capabilities

- **Apache Beam pipelines:** Runs pipelines written with the Apache Beam SDKs.
- **Batch and streaming:** Processes bounded and unbounded data with the same programming model.
- **Autoscaling:** Adjusts the number of workers based on the workload.
- **Templates:** Provides templates for common data movement tasks.
