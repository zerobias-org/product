# Network Intelligence Center

Network Intelligence Center is a Google Cloud service for monitoring, verifying and troubleshooting
Google Cloud networks.

## Key capabilities

- **Connectivity Tests:** Checks whether traffic can reach an endpoint and why it may be blocked.
- **Network Topology:** Shows network topology and traffic between resources.
- **Performance Dashboard:** Shows packet loss and latency metrics.
- **Firewall Insights:** Reports on firewall rule usage and misconfigurations.
