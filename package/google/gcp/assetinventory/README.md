# Cloud Asset Inventory

Cloud Asset Inventory is a Google Cloud service that provides inventory services for Google Cloud
resources and policies.

## Key capabilities

- **Asset search:** Searches resources and IAM policies across projects, folders and organizations.
- **History:** Keeps a history of asset metadata.
- **Export:** Exports asset snapshots to Cloud Storage or BigQuery.
- **Change notifications:** Sends asset change notifications through Pub/Sub.
