# Cloud Data Fusion

Cloud Data Fusion is a managed Google Cloud data integration service for building ETL and ELT
pipelines. It is based on the open source CDAP project.

## Key capabilities

- **Visual pipeline design:** Builds data pipelines in a graphical interface.
- **Connectors:** Provides connectors and transformations for many data sources and sinks.
- **Lineage:** Tracks dataset and field-level lineage.
