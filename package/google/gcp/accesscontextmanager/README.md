# Access Context Manager

Access Context Manager is a Google Cloud service for defining fine-grained, attribute-based access
control for Google Cloud resources.

## Key capabilities

- **Access levels:** Defines access conditions based on attributes such as IP address and device.
- **Service perimeters:** Defines VPC Service Controls perimeters around resources.
- **Access policies:** Groups access levels and perimeters in an organization-level policy.
