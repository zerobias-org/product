# Cloud Logging

Cloud Logging is a Google Cloud Observability service for storing, searching, analyzing and alerting
on log data.

## Key capabilities

- **Log collection:** Collects logs from Google Cloud services, VMs and applications.
- **Log routing:** Routes logs to log buckets, BigQuery, Cloud Storage or Pub/Sub.
- **Logs Explorer:** Searches and filters logs with the Logging query language.
- **Audit logs:** Stores Cloud Audit Logs for administrative and data access activity.
