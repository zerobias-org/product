# Cloud Domains

Cloud Domains is a Google Cloud service for registering and managing domain names inside a Google
Cloud project. Squarespace is the registrar of record for domains registered through it.

## Key capabilities

- **Domain registration:** Registers and renews domain names from a Google Cloud project.
- **DNS integration:** Uses Cloud DNS as the DNS provider for registered domains.
- **API access:** Manages registrations through the Cloud Domains API.
