# Cloud Run functions

Cloud Run functions (formerly Cloud Functions) is the Google Cloud service for running
single-purpose functions in response to HTTP requests and events.

## Key capabilities

- **Event-driven functions:** Runs code in response to HTTP requests and Google Cloud events.
- **Language runtimes:** Supports Node.js, Python, Go, Java, .NET, Ruby and PHP.
- **Automatic scaling:** Scales instances with the request load, down to zero.
