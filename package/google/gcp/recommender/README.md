# Recommender

Recommender is a Google Cloud service, part of Active Assist, that gives recommendations and
insights about the use of Google Cloud resources.

## Key capabilities

- **Recommendations:** Suggests changes such as resizing or removing idle resources.
- **Insights:** Reports usage patterns behind recommendations.
- **IAM recommendations:** Suggests removing unused permissions.
- **API access:** Lists and updates recommendations through the Recommender API.
