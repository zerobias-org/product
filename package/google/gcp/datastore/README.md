# Firestore in Datastore mode

Firestore in Datastore mode is a NoSQL document database from Google Cloud that keeps the Cloud
Datastore API and data model.

## Key capabilities

- **Entity data model:** Stores data as entities with kinds, keys and properties.
- **Queries and indexes:** Runs queries backed by built-in and composite indexes.
- **Transactions:** Supports ACID transactions.
- **Scaling:** Scales automatically with no servers to manage.
