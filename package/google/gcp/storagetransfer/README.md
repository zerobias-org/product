# Storage Transfer Service

Storage Transfer Service is a Google Cloud service for moving large amounts of data into, out of and
within Cloud Storage.

## Key capabilities

- **Cloud-to-cloud transfers:** Copies data from Amazon S3, Azure Blob Storage and other sources.
- **On-premises transfers:** Moves data from file systems using transfer agents.
- **Scheduled transfers:** Runs one-time or recurring transfer jobs.
