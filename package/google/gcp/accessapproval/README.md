# Access Approval

Access Approval is a Google Cloud service that requires customer approval before Google personnel
can access customer content.

## Key capabilities

- **Approval requests:** Sends requests that the customer approves or dismisses.
- **Notifications:** Notifies approvers of new requests.
- **Scoped enrollment:** Applies to selected services at the project, folder or organization level.
- **Signed approvals:** Can sign approvals with a customer-managed key.
