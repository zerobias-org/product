# Firestore

Firestore is a serverless NoSQL document database from Google Cloud for mobile, web and server
applications.

## Key capabilities

- **Document model:** Stores data as documents in collections.
- **Real-time updates:** Sends listeners updates when data changes.
- **Offline support:** Lets mobile and web clients work offline and sync later.
- **Security rules:** Controls client access with Firestore Security Rules and IAM.
