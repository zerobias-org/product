# Bigtable

Bigtable is a fully managed NoSQL wide-column database from Google Cloud, built for large analytical
and operational workloads with low-latency reads and writes.

## Key capabilities

- **Wide-column storage:** Stores data in tables of rows and column families, indexed by a row key.
- **Scaling:** Adds or removes nodes in a cluster to change throughput.
- **Replication:** Replicates data across clusters in different zones or regions.
- **Access control:** Controls access to instances and tables with IAM.
