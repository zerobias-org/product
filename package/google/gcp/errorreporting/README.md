# Error Reporting

Error Reporting is a Google Cloud Observability service that groups and tracks errors from running
applications.

## Key capabilities

- **Error grouping:** Groups similar errors and stack traces together.
- **Notifications:** Notifies you when new errors appear.
- **Log integration:** Reads errors from Cloud Logging entries.
