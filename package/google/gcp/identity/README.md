# Cloud Identity

Cloud Identity is Google's identity as a service (IDaaS) offering for managing users, groups and
devices.

## Key capabilities

- **User and group management:** Manages user accounts and groups from the Google Admin console.
- **Single sign-on:** Provides SSO to SAML and OIDC applications.
- **Multi-factor authentication:** Enforces 2-Step Verification for users.
- **Device management:** Manages and secures mobile and desktop devices.
