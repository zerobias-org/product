# Security Command Center

Security Command Center is the Google Cloud security and risk management platform.

## Key capabilities

- **Asset inventory:** Lists Google Cloud assets and their security state.
- **Misconfiguration detection:** Finds misconfigurations and compliance violations.
- **Threat detection:** Detects threats in logs, VMs and containers.
- **Findings:** Reports findings for review and export.
