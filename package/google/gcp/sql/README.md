# Cloud SQL

Cloud SQL is a fully managed relational database service from Google Cloud for MySQL, PostgreSQL and
SQL Server.

## Key capabilities

- **Managed databases:** Runs MySQL, PostgreSQL and SQL Server instances.
- **High availability:** Fails over to a standby instance in another zone.
- **Backups and recovery:** Takes automated backups and supports point-in-time recovery.
- **Security:** Encrypts data at rest and supports private IP and IAM database authentication.
