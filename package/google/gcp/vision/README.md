# Cloud Vision API

The Cloud Vision API is a Google Cloud service that uses machine learning to analyze images.

## Key capabilities

- **Label detection:** Identifies objects and concepts in images.
- **Text detection:** Extracts printed and handwritten text with OCR.
- **Face and landmark detection:** Detects faces and well-known landmarks.
- **SafeSearch:** Flags explicit content in images.
