# AI Commerce Search

AI Commerce Search is a Google Cloud product for search, browse and recommendations on commerce
websites and apps. It is part of Gemini Enterprise for Customer Experience.

## Key capabilities

- **Product search:** Provides search over an uploaded product catalog.
- **Recommendations:** Gives personalized product recommendations.
- **Dynamic filters:** Adjusts filters to each query and the product attributes in the results.
- **Conversational filtering:** Narrows broad searches through guided dialogue.
