# Artifact Registry

Artifact Registry is a Google Cloud service for storing and managing container images and language
packages.

## Key capabilities

- **Formats:** Stores Docker images and packages such as Maven, npm and Python.
- **Repository types:** Supports standard, remote and virtual repositories.
- **Access control:** Controls access with IAM.
- **Vulnerability scanning:** Scans images with Artifact Analysis.
