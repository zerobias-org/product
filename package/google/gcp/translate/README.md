# Cloud Translation

Cloud Translation is a Google Cloud API that translates text and documents between languages.

## Key capabilities

- **Text translation:** Translates text between supported languages.
- **Language detection:** Detects the language of input text.
- **Document translation:** Translates formatted documents.
- **Glossaries:** Keeps domain-specific terms consistent with glossaries.
