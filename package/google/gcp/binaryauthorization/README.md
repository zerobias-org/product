# Binary Authorization

Binary Authorization is a Google Cloud service that enforces deploy-time policies so that only
trusted container images are deployed.

## Key capabilities

- **Deploy-time policy:** Allows or blocks container image deployments based on a policy.
- **Attestations:** Requires images to be signed by trusted attestors before they can be deployed.
- **Platform support:** Works with Google Kubernetes Engine and Cloud Run, among others.
- **Audit logging:** Records policy decisions in Cloud Audit Logs.
