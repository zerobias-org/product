# Cloud Shell

Cloud Shell is a browser-based shell environment for managing Google Cloud resources.

## Key capabilities

- **Browser shell:** Opens a terminal on a temporary VM from the Google Cloud console.
- **Preinstalled tools:** Includes the gcloud CLI and other common tools.
- **Persistent home directory:** Keeps a home directory between sessions.
- **Code editor:** Includes Cloud Shell Editor for editing files.
