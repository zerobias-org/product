# Google Kubernetes Engine (GKE)

Google Kubernetes Engine (GKE) is a managed Kubernetes service from Google Cloud.

## Key capabilities

- **Managed Kubernetes:** Runs Kubernetes clusters with a Google-managed control plane.
- **Autopilot mode:** Manages nodes and their configuration for you.
- **Autoscaling:** Scales Pods and nodes with the workload.
- **Security:** Supports Workload Identity Federation, Shielded GKE Nodes and Binary Authorization.
