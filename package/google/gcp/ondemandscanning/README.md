# On-Demand Scanning

On-Demand Scanning is a feature of Google Cloud Artifact Analysis that scans container images for
vulnerabilities when you request it.

## Key capabilities

- **Local and registry scans:** Scans images stored locally or in Artifact Registry.
- **CLI scanning:** Runs scans from the gcloud CLI.
- **CI/CD use:** Checks images for vulnerabilities in Cloud Build pipelines.

## Official resources

- Documentation: https://docs.cloud.google.com/artifact-analysis/docs/scan-os-on-demand
