# Artifact Analysis

Artifact Analysis (formerly Container Analysis) is a Google Cloud service that scans artifacts for
vulnerabilities and stores metadata about them.

## Key capabilities

- **Vulnerability scanning:** Scans container images in Artifact Registry for known vulnerabilities.
- **Metadata storage:** Stores notes and occurrences about artifacts through the Container Analysis
  API.
- **On-demand scanning:** Scans images locally or in a registry when requested.
- **Policy integration:** Supplies metadata used by Binary Authorization policies.
