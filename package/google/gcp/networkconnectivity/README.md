# Network Connectivity Center

Network Connectivity Center is a Google Cloud hub-and-spoke service for connecting VPC networks and
on-premises or other-cloud networks.

## Key capabilities

- **Hub and spokes:** Connects networks as spokes attached to a central hub.
- **VPC connectivity:** Connects multiple VPC networks to each other.
- **Hybrid connectivity:** Uses Cloud VPN, Cloud Interconnect and router appliances as spokes.
