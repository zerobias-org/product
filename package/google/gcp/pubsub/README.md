# Pub/Sub

Pub/Sub is an asynchronous messaging service from Google Cloud that decouples services that produce
messages from services that process them.

## Key capabilities

- **Topics and subscriptions:** Publishes messages to topics and delivers them to subscriptions.
- **Delivery types:** Supports pull, push and export subscriptions.
- **Message ordering:** Delivers messages with the same ordering key in order.
- **Dead-letter topics:** Moves undeliverable messages to a dead-letter topic.
