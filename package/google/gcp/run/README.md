# Cloud Run

Cloud Run is a managed Google Cloud platform for running containers, functions and jobs without
managing servers.

## Key capabilities

- **Services:** Runs containers that respond to HTTP requests and events.
- **Jobs:** Runs containers that do work and then exit.
- **Automatic scaling:** Scales instances with load, down to zero.
- **Access control:** Controls who can invoke services with IAM.
