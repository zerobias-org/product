# Sensitive Data Protection

Sensitive Data Protection is a Google Cloud service for finding, classifying and protecting
sensitive data. It includes the Cloud Data Loss Prevention (DLP) API.

## Key capabilities

- **Inspection:** Detects sensitive data such as personal and financial information.
- **Discovery:** Profiles data across BigQuery, Cloud Storage and other sources.
- **De-identification:** Masks, tokenizes or redacts sensitive values.
- **Risk analysis:** Measures re-identification risk in datasets.
