# Cloud Natural Language

Cloud Natural Language is a Google Cloud API that uses machine learning to analyze text.

## Key capabilities

- **Entity analysis:** Identifies people, places, organizations and other entities in text.
- **Sentiment analysis:** Measures the overall and per-sentence sentiment of text.
- **Content classification:** Assigns text to content categories.
- **Syntax analysis:** Breaks text into sentences and tokens with linguistic information.
