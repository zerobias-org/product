# Cloud TPU

Cloud TPU is a Google Cloud service that provides Tensor Processing Units (TPUs), Google's custom
accelerators for machine learning workloads.

## Key capabilities

- **TPU VMs:** Runs workloads on VMs attached to TPU hardware.
- **Framework support:** Supports JAX, PyTorch and TensorFlow.
- **Scaling:** Runs training and inference across slices of many TPU chips.
