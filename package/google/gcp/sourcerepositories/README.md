# Cloud Source Repositories

Cloud Source Repositories is a private Git repository service from Google Cloud. Since June 17, 2024
it is not available to new customers; Google publishes migration guides for existing users.

## Key capabilities

- **Private Git repositories:** Hosts private Git repositories in Google Cloud projects.
- **Repository mirroring:** Mirrors repositories from GitHub and Bitbucket.
- **Access control:** Controls repository access with IAM.

## Official resources

- Documentation: https://docs.cloud.google.com/source-repositories/docs
