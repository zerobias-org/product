# Cloud Storage

Cloud Storage is the Google Cloud object storage service for storing data as objects in buckets.

## Key capabilities

- **Object storage:** Stores objects of any type in buckets.
- **Storage classes:** Offers Standard, Nearline, Coldline and Archive storage classes.
- **Access control:** Controls access with IAM and uniform bucket-level access.
- **Encryption:** Encrypts data at rest by default, with optional customer-managed keys.
