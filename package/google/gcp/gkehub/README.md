# GKE Hub API

The GKE Hub API is the Google Cloud API for fleet management. It registers Kubernetes clusters to a
fleet and manages fleet-level features for them.

## Key capabilities

- **Fleet membership:** Registers GKE and other Kubernetes clusters as fleet members.
- **Fleet features:** Enables and configures features across the clusters in a fleet.
- **Multi-cluster management:** Manages groups of clusters as one unit.
