# Identity-Aware Proxy

Identity-Aware Proxy (IAP) is a Google Cloud service that controls access to applications and VMs
based on user identity and context.

## Key capabilities

- **Application access:** Checks identity and IAM permissions before requests reach an application.
- **TCP forwarding:** Gives SSH and RDP access to VMs without public IP addresses.
- **Context-aware access:** Applies access levels based on attributes such as device and IP address.
