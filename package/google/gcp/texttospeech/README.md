# Text-to-Speech

Text-to-Speech is a Google Cloud API that converts text into natural-sounding speech.

## Key capabilities

- **Voices:** Offers many voices across languages and variants.
- **SSML support:** Controls pronunciation, pauses and emphasis with SSML.
- **Audio formats:** Returns audio in formats such as MP3, LINEAR16 and OGG_OPUS.
