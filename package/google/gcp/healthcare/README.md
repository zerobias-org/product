# Cloud Healthcare API

The Cloud Healthcare API is a Google Cloud service for storing and exchanging healthcare data in
standard formats.

## Key capabilities

- **FHIR stores:** Stores and serves clinical data with the HL7 FHIR standard.
- **HL7v2 stores:** Ingests and stores HL7 version 2 messages.
- **DICOM stores:** Stores medical images using the DICOMweb standard.
- **De-identification:** Removes identifying information from healthcare data.
