# API Keys API

The API Keys API is a Google Cloud service for creating and managing API keys for Google Cloud
projects.

## Key capabilities

- **Key management:** Creates, lists, updates and deletes API keys.
- **Restrictions:** Restricts keys to specific APIs, applications, IP addresses or referrers.
- **Key lookup:** Finds the project that owns a key.
