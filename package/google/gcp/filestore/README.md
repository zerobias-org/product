# Filestore

Filestore is a managed network file storage service from Google Cloud that provides NFS file shares.

## Key capabilities

- **NFS file shares:** Provides file shares that Compute Engine VMs and GKE clusters can mount.
- **Service tiers:** Offers tiers with different capacity, performance and availability.
- **Backups and snapshots:** Backs up file shares and restores them.
