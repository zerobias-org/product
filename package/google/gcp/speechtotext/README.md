# Speech-to-Text

Speech-to-Text is a Google Cloud API that converts audio into text using speech recognition models.

## Key capabilities

- **Batch transcription:** Transcribes recorded audio files.
- **Streaming recognition:** Transcribes audio in real time.
- **Languages:** Supports many languages and dialects.
- **Model adaptation:** Improves recognition of specific words and phrases.
