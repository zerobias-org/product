# Dialogflow

Dialogflow is a Google Cloud platform for building conversational agents such as chatbots and voice
bots. It comes in two editions, Dialogflow CX and Dialogflow ES.

## Key capabilities

- **Conversational agents:** Builds agents that understand user input and respond in text or voice.
- **Intent detection:** Matches user input to intents and extracts parameters.
- **Flows and pages:** Models complex conversations as flows in Dialogflow CX.
- **Integrations:** Connects agents to telephony and messaging channels.
