# Cloud Profiler

Cloud Profiler is a Google Cloud Observability service that continuously collects CPU and memory
profiles from running applications with low overhead.

## Key capabilities

- **Continuous profiling:** Collects profiles from production applications on an ongoing basis.
- **Profile types:** Captures CPU time, heap and other profile types, depending on the language.
- **Language agents:** Provides profiling agents for Go, Java, Node.js and Python.
- **Flame graphs:** Shows profiles as flame graphs to find costly code paths.
