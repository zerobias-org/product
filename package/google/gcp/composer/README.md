# Managed Service for Apache Airflow

Managed Service for Apache Airflow (formerly Cloud Composer) is a Google Cloud workflow
orchestration service built on Apache Airflow.

## Key capabilities

- **Managed Airflow:** Runs Apache Airflow environments without managing the underlying
  infrastructure.
- **DAG workflows:** Schedules and runs workflows defined as Python DAGs.
- **Integrations:** Connects to Google Cloud and other services through Airflow operators.
- **Access control:** Controls access to environments with IAM.
