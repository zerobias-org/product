# Secret Manager

Secret Manager is a Google Cloud service for storing and accessing API keys, passwords, certificates
and other secrets.

## Key capabilities

- **Secret versions:** Stores secrets as versioned, immutable values.
- **Access control:** Controls access to each secret with IAM.
- **Encryption:** Encrypts secrets at rest, with optional customer-managed keys.
- **Audit logging:** Records secret access in Cloud Audit Logs.
