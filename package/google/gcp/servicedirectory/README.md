# Service Directory

Service Directory is a managed Google Cloud service registry for publishing, discovering and
connecting services.

## Key capabilities

- **Service registry:** Registers services and their endpoints in namespaces.
- **Service discovery:** Looks up services through an API or DNS.
- **Access control:** Controls access to namespaces and services with IAM.
