# Agent Platform Workbench

Agent Platform Workbench is a Jupyter notebook environment in Google Cloud's Gemini Enterprise Agent
Platform. Its instances are managed through the Notebooks API.

## Key capabilities

- **Managed Jupyter instances:** Runs JupyterLab instances on Compute Engine VMs.
- **Google Cloud integration:** Connects notebooks to BigQuery, Cloud Storage and other services.
- **Scheduled runs:** Runs notebook files on a schedule.
