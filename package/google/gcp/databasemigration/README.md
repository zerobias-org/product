# Database Migration Service

Database Migration Service is a Google Cloud service for migrating databases to Cloud SQL and
AlloyDB for PostgreSQL.

## Key capabilities

- **Homogeneous migrations:** Migrates MySQL, PostgreSQL and SQL Server databases to Cloud SQL.
- **Heterogeneous migrations:** Converts and migrates Oracle and SQL Server databases to PostgreSQL
  targets.
- **Continuous replication:** Replicates changes from the source to keep downtime low.
