# Channel Services

Channel Services is the Google Cloud offering for partners that resell Google Cloud and Google
Workspace. The Cloud Channel API automates customer and order management for these partners.

## Key capabilities

- **Customer management:** Creates and manages reseller customer accounts.
- **Entitlements:** Provisions and changes product entitlements for customers.
- **Offers and pricing:** Lists the offers and SKUs a partner can sell.
