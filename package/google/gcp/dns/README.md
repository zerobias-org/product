# Cloud DNS

Cloud DNS is a managed authoritative Domain Name System (DNS) service from Google Cloud.

## Key capabilities

- **Public zones:** Hosts DNS records for domains visible on the internet.
- **Private zones:** Serves DNS records only to selected VPC networks.
- **DNSSEC:** Signs public zones with DNSSEC.
- **DNS policies:** Controls name resolution with forwarding, peering and response policies.
