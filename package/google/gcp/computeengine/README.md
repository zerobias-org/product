# Compute Engine

Compute Engine is the Google Cloud service for creating and running virtual machines on Google
infrastructure.

## Key capabilities

- **Virtual machines:** Runs VMs from predefined or custom machine types.
- **Storage:** Attaches Persistent Disk, Hyperdisk and Local SSD storage to VMs.
- **Managed instance groups:** Runs groups of identical VMs with autoscaling and autohealing.
- **Security:** Offers Shielded VM and Confidential VM options.
