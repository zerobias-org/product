# Service Infrastructure

Service Infrastructure is the Google Cloud foundational platform for creating, managing, securing
and consuming APIs and services.

## Key capabilities

- **Service Management:** Manages service configurations and rollouts.
- **Service Control:** Checks API calls and reports usage for services.
- **Service Consumer Management:** Manages tenant projects for service producers.
