# Managed Service for Apache Spark

Managed Service for Apache Spark (formerly Dataproc) is a Google Cloud service for running Apache
Spark, Apache Hadoop and related open source data processing tools.

## Key capabilities

- **Managed clusters:** Creates and resizes clusters for Spark, Hadoop and related tools.
- **Serverless Spark:** Runs Spark workloads without managing clusters.
- **Storage integration:** Reads and writes data in Cloud Storage and BigQuery.
- **Access control:** Controls access to clusters and jobs with IAM.
