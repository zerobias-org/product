# Cloud Trace

Cloud Trace is a Google Cloud Observability service for collecting and analyzing distributed traces
from applications.

## Key capabilities

- **Distributed tracing:** Collects latency data for requests across services.
- **Trace analysis:** Shows trace spans and latency distributions.
- **OpenTelemetry support:** Receives trace data sent with OpenTelemetry.
