# BigQuery Data Transfer Service

BigQuery Data Transfer Service is a Google Cloud service that loads data into BigQuery on a schedule
or on demand. It is part of BigQuery.

## Key capabilities

- **Scheduled transfers:** Runs recurring data loads into BigQuery datasets on a set schedule.
- **Data source connectors:** Loads data from Google SaaS apps, cloud storage services and data
  warehouses.
- **Backfills:** Runs transfers for past dates to fill gaps in loaded data.
