# API Gateway

API Gateway is a Google Cloud service for creating, securing and monitoring APIs for serverless
backends such as Cloud Run functions, Cloud Run and App Engine.

## Key capabilities

- **API definitions:** Defines APIs with OpenAPI specifications.
- **Authentication:** Secures APIs with API keys and JSON Web Tokens.
- **Monitoring:** Reports API metrics and logs.
- **Managed gateway:** Runs the gateway as a managed service.
