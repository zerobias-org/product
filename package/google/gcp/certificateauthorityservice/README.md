# Certificate Authority Service

Certificate Authority Service (CA Service) is a managed Google Cloud service for creating and
running private certificate authorities.

## Key capabilities

- **Private CAs:** Creates root and subordinate certificate authorities.
- **Certificate issuance:** Issues and revokes certificates through the console, CLI or API.
- **Key protection:** Stores CA keys in Cloud HSM.
- **Access control:** Controls who can request and manage certificates with IAM.
