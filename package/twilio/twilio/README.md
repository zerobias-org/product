# Twilio

Twilio is a cloud communications platform from Twilio Inc. Developers use its APIs to add
messaging, voice, video and email to applications.

## Key capabilities

- **Messaging:** Sends and receives SMS, MMS and other message channels.
- **Voice:** Makes and receives phone calls programmatically.
- **Verification:** Verifies users with one-time codes.
- **APIs and SDKs:** Offers REST APIs and SDKs for many languages.
