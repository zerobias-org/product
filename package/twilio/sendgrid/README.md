# Twilio SendGrid

Twilio SendGrid is a cloud email delivery service from Twilio. It sends transactional and marketing
email.

## Key capabilities

- **Email API:** Sends email through a web API and SMTP relay.
- **Marketing campaigns:** Builds and sends marketing email campaigns.
- **Deliverability:** Provides sender authentication and delivery analytics.
