# FortiGate

FortiGate is a next-generation firewall (NGFW) product line from Fortinet, running the FortiOS
operating system.

## Key capabilities

- **Firewall:** Filters traffic with security policies.
- **Threat protection:** Provides intrusion prevention, antivirus and web filtering.
- **VPN:** Supports IPsec and SSL VPN.
- **SD-WAN:** Includes SD-WAN functions.
- **Deployment:** Available as hardware, virtual machines and cloud instances.
