# Smartsheet

Smartsheet is a software-as-a-service platform for collaboration and work management from Smartsheet
Inc.

## Key capabilities

- **Sheets:** Tracks work in a spreadsheet-like interface.
- **Views:** Shows work as grids, Gantt charts, cards and calendars.
- **Automation:** Automates alerts, approvals and updates.
- **API:** Offers an API for integrations.
